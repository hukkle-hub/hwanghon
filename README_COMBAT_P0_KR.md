# 황혼 v12 — 전투 질감 P0

실제 전투 녹화 `Screen_Recording_20260927_114302.mp4`에서 가장 크게 보인 프로토타입 느낌 네 가지를 먼저 줄이는 패스.

## 1. 플레이어 낫 궤적
- 일반 0.11 s / 큰 공격 0.17 s 시간 기반 잔상.
- 날 바깥 구간만 얇게 그림.
- 저FPS에서 tip 이동을 최대 0.22 m 단위로 재표본화해 큰 삼각형을 방지.
- 보스 큰 기술용 0.3 s 링 잔상과 플레이어 무기 잔상을 분리.

## 2. 보스 피격
- 공격·예고·회복 중에도 판정을 취소하지 않고 additive recoil을 항상 표시.
- 평타 < 3타/치명 < 스매시 강도.
- 플레이어가 때린 좌/우 방향에 따라 척추 반동 방향이 달라짐.

## 3. 피격 플래시
- 일반 hit의 전체 빨강 emissive를 제거.
- 3타/치명/스매시만 0.055 s의 약한 따뜻한 emissive.
- stagger는 0.10 s, BREAK/카운터 상위 연출은 기존 위계를 유지.

## 4. d01 조명
- 전체를 무작정 밝히기보다 노출·환경광을 조금 올리고 캐릭터/보스 전용 fill을 강화.
- 붉은 역광은 2.6 → 1.8로 줄여 단색 빨강 실루엣을 완화.
- 안개 밀도도 소폭 낮춰 근접전 몸통/무기 가독성을 우선.

## 금지
`js/combat.js` 피해/판정/무적/스태미나/보스 패턴 수치는 변경하지 않는다.
