# 황혼 v12 — P5 접점 지지발

## 문제
기존 `replant()`는 시네마 레이어가 이번 프레임에 추가한 골반 이동만 되돌린다.
원본 attack clip 자체가 프레임 사이에 발을 조금 움직이는 것은 그대로 남는다.
실기에서는 이게 “상체는 무거운 무기를 휘두르는데 발은 얼음 위에서 흐르는” 느낌을 만든다.

## 수정
- 아인의 `attack1/2/3/smash`만 대상.
- 접점 직전~직후의 짧은 창에서만 작동.
- 매 프레임 좌/우 발 이동량을 보고 **덜 움직이는 한쪽 발**을 지지발로 자동 선택.
- 그 발의 월드 위치를 짧게 anchor로 잡고 다리 IK로만 보정.
- 두 발을 동시에 고정하지 않아 골반 회전/무릎 꼬임을 줄임.
- smash는 접점 뒤 presentation lunge와 충돌하지 않게 post lock을 0.045s로 짧게 둠.

## 창
- 기본 3타: 접점 전 0.085s / 후 0.075s
- smash: 접점 전 0.14s / 후 0.045s

## 진단
`character-cinema` diagnostics:
- `plantWeight`
- `plantSide`
- `plantError`

- 공격 판정
- 이동 거리
- 스태미나/피해
- 원본 GLB
