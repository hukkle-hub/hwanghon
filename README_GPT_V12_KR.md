# 황혼 GPT v12 — 전투 조작·HUD 가독성

기준: 2026-09-27 최신 `main` `eae2d8f250e795f4e41e6fa34a3307d713733519` (전투 코드 기준은 `2adbed663ac5e10bb9d0657372ccc33fcc442efd` 이후 변경 없음).

실제 폰 전투 녹화에서 기능 수보다 조작 완결성과 전투 가독성이 먼저라는 결론으로 범위를 줄였다.

## 변경

- 모바일 점프를 **독립 버튼**으로 추가. 회피 버튼 스와이프 방식은 회피 입력을 늦출 수 있어 사용하지 않는다.
- 점프 입력은 `battle.input('jump')`와 함께 `tw:input {type:'jump'}`를 발행한다.
- 점프 쿨다운 0.8초를 버튼 원형 쿨로 표시하고, 공중에서 공격·가드 버튼 피드백을 막는다.
- 첫 `jumpOnly` 예고에서 점프 버튼을 1초 강조한다.
- 사거리 원 투명도 하한: 범위 밖 0.06, 범위 안 0.10, 훈련장은 각각 +0.03.
- 모바일에서 보스 머리가 화면 상단 22%에 들어오면 카운터 배너를 화면 72% 위치로 내린다.

## 변경하지 않음

`js/combat.js`, 판정, 피해, 회피/점프 무적 시간, 카메라, 조명, VFX, 모션은 건드리지 않는다. 전투 질감 패스는 Claude 작업과 분리한다.
