# 황혼 v12 — 전투 질감 P1

P0(낫 궤적·보스 피격·플래시·조명) 위에 적용.

## 아인 전신 공격
- 보조 전신 연기 레이어를 각 행동의 실제 `hitAt`에 동기화.
- 1타: 읽히는 감기/가속.
- 2타: 감기를 줄이고 1타 끝에서 반대 방향으로 바로 되받아치기.
- 3타: `snap/follow/drop`을 가장 크게 해 마무리 실루엣.
- 골반 구동 비중을 올리고 접점에서 앞쪽 압축을 추가.
- 기존 `replant()`를 유지하므로 골반 이동 뒤 발 위치를 다시 고정.

## 근접 카메라
- 락온 상태에서 2.1 m 이내부터 부드럽게 근접 보정.
- 최대 근접에서 PC +0.58 m / 모바일 +0.45 m 뒤로.
- 카메라 높이·어깨 오프셋을 조금 올려 플레이어/보스를 좌우로 분리.
- 자동 회전 정지 반경 1.2 → 1.6 m.
- FOV는 최대 +1.5°만 추가해 멀미를 억제.

## 규칙
전투 피해·판정·무적·스태미나·보스 패턴은 변경하지 않는다.
클립 자체 교체는 이 패스 뒤 실기 20초 영상에서 남는 문제를 보고 결정한다.
