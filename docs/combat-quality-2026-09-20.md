## 검수 결과

- `npm test`: 178개 통과, 실패 0개.
- `node --check js/game3d.js`, `node --check js/party-online.js`: 통과.
- `git diff --check`: 오류 없음. Windows 줄바꿈 경고만 존재.
- 원본 메시의 UV·인덱스·클립 보존 및 아인 59,999 삼각형 유지 테스트 통과.
- 기본 3타·내려찍기·카운터·처형: 세 가지 훈련장 핵 위치에서 실제 낫날 삼각형과 반경 0.39m 표적의 교차 확인.
- 양손 그립·손목 각도·팔다리 길이 보존·240구간 관절 연속성 테스트 통과. 관절 샘플 간 최대 변화 약 7.84도(기존 상한 8도).
- 서버 여섯 던전 전투 테스트 통과. 짧아진 사거리에 맞춰 테스트 플레이어가 부위에 접근하고, 위험 범위를 피하며, 긴 기술은 빈틈에만 쓰도록 수정했다. 보스 체력/피해량을 낮춰 통과시키지 않았다.
- 로컬 게임 화면에서 기본 공격 접촉 확인: 날 표면과 핵 중심 거리 0.283m, 표적 반경 0.390m. 검수 화면의 흰 구는 판정 표시이며 실제 타격 FX가 아니다.

## 남은 검증과 한계

- 서버 판정은 측정한 기본 자세의 부위 중심을 이용하는 2.5D 범위 판정이다. 애니메이션 중인 모든 삼각형을 서버에서 충돌 검사하는 구현은 아니다.
- 실제 낫날 메시 교차 검수는 명시된 훈련장 표적/자세에 대한 결과다. 모든 보스·거리·높이·동작 전체의 완전 일치를 보증하지 않는다.
- 허수아비 외 보스의 부위별 기본 위치는 측정해 공통 판정에 반영했으나, 새 몸동작 예고와 파괴 후 자세 연출을 모든 보스에 새로 제작한 것은 아니다.
- 온라인 서버 테스트와 코드 연결은 확인했으나, 이번 검수에서 여러 실제 기기가 동시에 접속하는 플레이 테스트는 수행하지 않았다.
- S25 Ultra 실기기 프레임·발열·터치 체감은 아직 측정하지 않았다. 자동 테스트 통과를 상용 게임 수준의 미술/애니메이션 완성도로 간주하지 않는다.
