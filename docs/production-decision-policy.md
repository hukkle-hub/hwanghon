# 황혼 제작 방식 선택 원칙

사용자 지시: 2026-09-20. 반복 교정 자체가 목표가 아니다. 검수 가능한 결과를 빠르고 정확하게 만드는 방식을 선택한다.

1. 작업 전에 현재 문제와 합격 기준을 정한다. 예: 손 그립, 실제 무기 접점, 타격 타이밍, Android 성능.
2. 기존 자산 조정 / 새 생성 / 에셋 구매를 비교한다. 작업 시간뿐 아니라 리깅·리타깃·재질·라이선스·모바일 최적화·기존 코드 연결·검수 비용까지 포함한다.
3. 조사 결과와 작은 샘플 검증을 근거로 가장 짧고 신뢰할 수 있는 경로를 선택한다. 생성이 조정보다 빠르고 정확하면 생성한다. 생성도 불안정하면 적합한 기성 에셋을 검토한다.
4. 교정이 반복되는데 품질이 개선되지 않으면 같은 작업을 무한 반복하지 말고 세 경로를 다시 비교한다. 모델을 새로 만든다는 이유만으로 기존 자산을 폐기하지 않는다.
5. 유료 생성·구매 전에는 구체적인 상품/서비스, 비용, 라이선스, 적용 범위를 제시하고 승인을 받는다. 기존 API 키가 있다는 사실은 지출 승인이 아니다.
6. 코드 테스트 후 사용자에게 검수 가능한 배포본을 제공한다. Render의 배포 완료, 대상 커밋, 실제 페이지/자산 제공을 확인한다. 로컬 테스트만으로 사용자가 검수할 수 있다고 간주하지 않는다.
7. 아인+허수아비에서 검증한 파이프라인을 다른 캐릭터/보스에 확장한다. 완성도와 실기기 성능을 측정하기 전에는 상용 게임 수준이라고 단정하지 않는다.

이번 선택: 테스트를 통과한 기존 교정본을 우선 배포해 비교 기준을 만든다. 아직 필요성이 검증되지 않은 새 생성이나 구매로 배포를 지연하지 않는다. 배포본 검수에서 남는 문제를 기준으로 후속 제작 방식을 재선정한다.
