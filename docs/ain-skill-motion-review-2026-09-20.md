# 아인 스킬·카운터 로컬 검수

상태: 로컬 구현, 미커밋·미배포. 최종 아트 승인/실기 검수 완료 아님.

## 구현

- 기존 기획의 낫베기, 그림자걸음, 피의회전, 결의, 낫의황혼에 각각 별도 양손 낫 경로 적용.
- 피의회전은 기존 궁극기의 전신 회전 클립을 복제/리타이밍. 타격 clip contact .55에서 정면으로 복귀하도록 원본 .98 지점을 정렬. 시간 변환 꺾임에 키를 삽입해 희소 키 보간 지연 방지.
- 결의는 guard 자세, 궁극기는 smash 자세를 복제하고 대상 duration 유지. 원본 GLB/클립/텍스처 불변.
- 온라인 그림자걸음/결의에 서버 snapshot 기반 gesture 추가. 이동·방어·공격·피격에 양보하며 별도 공격 판정/행동 잠금/무적은 추가하지 않음.
- 일반 카운터는 자루 방어→버티기→반격 궤적. 퍼펙트 카운터는 후속 베기 확장. 기존 판정 시간·배율 유지.
- 이전 턴의 느린 공격 스킬 프로필 유지.

## 검증

- npm test: 140 통과 / 0 실패. git diff --check 통과.
- 15개 클립/변형 × 241 샘플 관절/양손 접촉 검사: 최대 접촉 오차 0.0003mm, 인접 관절 회전 7.220°, 손목 방향 굽힘 6.92°. 이는 기하학적 검사이지 미적 완성 지표가 아님.
- 원본 클립 불변, 서로 다른 5개 경로, 전신 360° 및 실제 접점 정면, 온라인 utility 시작/만료/사망/공격 우선순위 테스트 추가. 일반 경로 중복/utility 누락 음성 대조 포함.
- 브라우저: 5개 스킬 정면 시트, 회전기 손 확대·측후면, 카운터 전신 시트 확인. 타격 때 등을 보이던 회전기 문제를 발견해 교정.
- 스크린샷: 워크스페이스 output/ain-grip-release/ain-skill3-fullbody-review.png 및 ain-counter-review.png.

## 남은 검수와 한계

- 손가락별 뼈는 없음. 기존 그립 모프와 IK 유지; 개별 손가락 리깅 완성으로 부르지 않음.
- 정적 포즈 시트는 발 고정 보정 미적용. 연속 전투 중 발 접지/슬라이딩, 공격 사이 블렌드, 의상 관통은 최종 승인되지 않음.
- 검수 페이지 그림자걸음/카운터는 원본 클립 길이로 표시되며 실제 게임 이동/반격 타이밍과 다름. 게임의 판정 시간은 변경하지 않음.
- 온라인은 서버/아바타 자동 테스트 완료, 실제 2인 브라우저 세션 및 S25 Ultra 실기 테스트 미수행.
- Render/Pages에 아직 반영되지 않음. 서버 변경 포함이므로 온라인 반영에는 Render 재배포 필요.
