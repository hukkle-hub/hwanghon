# 낫 접점 세부 교정 — 기준 거리 검증

로컬 수정, 미배포. 이전 `ain-live-contact-review-2026-09-20.md`의 불합격 자세를 교정했다.

## 원인과 변경

1. 공격 클립 Hips의 수평 이동이 게임 위치와 중첩. 공격·반격 등의 Hips X/Z를 bind 위치로 고정하고 높이·회전과 다리 동작은 유지했다. 원본 GLB 불변.
2. 핵은 아인 로컬 약 y=2.4m인데 베기의 날끝은 0.87m 부근을 지나갔다. 낫베기·회전기·궁극기의 타격 자세를 높은 표적용으로 조정했다. 회전기 전신 회전은 유지한다.
3. 날끝과 핵의 거리만으로 접촉 여부를 판단하는 것은 잘못이다. `measureAinBladeContact`로 실제 날 삼각형 표면의 최근접점을 측정한다. 자루는 높이/반경 필터로 제외한다. QA 전용이며 매 프레임 비용은 없다.
4. 반복 교정 중 관절 변화 8° 검사에 실패한 자세는 후속 동작 길이/진폭을 수정해 재통과시켰다. 기준을 완화하지 않았다.

## 검증 범위

훈련장 1단계, 적 중심 거리 1.20m, 핵 표적 반경 0.390m.
고정된 측정 표적과 실제 GLB를 쓰는 자동 테스트에서 날 표면→핵 거리:

- 낫베기 0.2436m
- 피의회전 0.2276m
- 궁극기 0.3238m

세 공격 모두 0.390m 내부. 실제 브라우저에서는 보스의 idle/피격 자세에 따라 값이 달라지며 회전기 0.336m, 궁극기 0.344m를 확인했다.
최종 낫베기 브라우저 측정은 0.279m. 증거 이미지: output/ain-grip-release/ain-live-contact-corrected.png.
원래의 날끝 2.05m 오차와 이 표면 거리는 서로 다른 지표이므로 직접 감소율로 비교하지 않는다.

전체 테스트 143 통과. 접촉 검사에는 3m 위로 옮긴 표적이 실패하는 음성 대조 포함.
양손 오차 최대 0.0003mm, 손목 굽힘 최대 6.92°, 241 샘플 인접 관절 변화 최대 7.839°.

## 완료로 확대 해석하지 않을 범위

- 이 결과는 특정 거리/표적의 공격 접점 검증이다. 모든 거리·방향·보스 단계·부위에 대한 보장이 아니다.
- 기본 공격/카운터/처형은 이번 높은 핵 접점 재설계 대상이 아니다.
- 실제 피해 판정은 기존 거리/각도/시야 기반이다. 서버/솔로에 swept-mesh 충돌을 적용한 것이 아니다.
- 온라인 2인 실플레이, Android 기기 검수, 배포는 미수행.
- 로컬 QA의 정지 프레임에서만 광원/타격 FX를 숨기고 기존 핵 반경을 녹색 wireframe으로 표시한다. 모델/표적 위치·반경을 숨겨서 이동하거나 키우지 않는다.
