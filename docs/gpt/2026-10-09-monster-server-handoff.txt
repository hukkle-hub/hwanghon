구현한 것 (로컬)
- Field.ecologies: 방문 지역마다 Ecology 하나. 원본 map.json 전체와 동일 createCollide, 서버 RNG/시각, hubOwner 사용.
- tickBosses의 기존 20 Hz 경로에서 tickEcologies 호출. HP/damage는 Field.mobStates, 생사/리스폰은 Ecology.defeat. 사망 처리는 한 번만.
- field와 fieldJoined의 mobs 배열: [id,catalogId,x,z,alive,anim,generation,hpPercent,seq]. v2의 앞 8칸 그대로 + 9번째 seq. alive는 참/거짓, hpPercent는 여덟 번째(숫자 0~100), seq는 아홉 번째(정수). 앞 일곱 칸은 Ecology.snapshot과 정확히 같음을 시험했다. 반경 28m, 가까운 순 최대 20개. anim은 idle/walk/attack/hit/die 문자열이다. 원래 Ecology.snapshot 객체는 변경하지 않았다.
- seq는 세대마다 0에서 시작, 예고 시작 및 피격 때 증가한다. 같은 attack/hit 사이 패킷을 놓쳐도 순번 차이로 재생한다. attack은 피해 순간이 아니라 600ms 예고 시작에 바뀐다. 피해·회복 구간은 그 공격의 같은 seq를 유지한다.
- fieldHit {mob,generation?}, fieldSkill {skill,mob,generation?}. generation은 새 클라이언트에서 꼭 보내는 것을 권장한다. boss와 mob을 동시에 보내면 타격하지 않는다.
- mobHit 응답: mob/catalogId/generation/dmg/crit/down/hp/reward. hp는 0~100 백분율이다. skill 타격이면 skill/ok/ready/name도 포함한다. 재사용 대기 중 유효한 몬스터 대상에는 mobHit {mob,generation,skill,ok:false,ready,name}; 피해 없음. 비공격·버프/회피 스킬이나 타격 실패는 기존 skillUsed다.
- 화면의 nearest 2.8m는 서버 최대 3.0m 안이다. 지형/안전 지대 검사는 그대로이며 벽 너머 타격은 허용하지 않는다.
- 기본 타격 HIT_GAP 350ms(대상 교체 우회도 방지), 서버 스킬 배율·쿨다운·critNext. 클라이언트 damage/mult/xp/items는 무시한다.
- 몬스터 공격은 bossStrike를 그대로 호출한다. hurt[2]는 mobs[i][0]과 같은 몬스터 id, hurt[6]은 판정한 서버 시각. 피해는 N01의 절대 피해를 maxHp로 나누어 같은 방어·무적·버프 공식에 전달한다.
- 순수 field-mob-combat.cjs: 기본 추적, 예고 600ms, 공격, 회복, 경직, 귀환. 클라이언트/서버가 같은 CJS 모듈을 사용한다.
- store.mutate + addItems + profile.gold/xp 지급 통로 및 본인 profile 갱신. 외부 응답 reward.items는 [{id,n}]이다. 내부 승인 정책은 기존 store 입력대로 [[id,n]]. 보스 장비용 bossLoot는 사용하지 않는다. 지급 후 같은 세대의 추가 타격으로 재지급되지 않는다.
- 임시 DB 실패는 같은 보상으로 메모리 재시도(틱당 최대 두 건, 1초 간격). 보상 재추첨 없음. 이 큐는 재시작 내구성을 보장하는 영구 보상 우편함은 아니다.

보류/미완료 (완성으로 오해하지 말 것)
- 디렉터의 몬스터 드롭 표·경험치 곡선은 미정이다. 기본 mobRewards=null → 지급 없음, reward.status=pending_policy. 시험의 1~5 XP/골드는 검증용 주입값일 뿐 게임 표가 아니다.
- N01 여섯 종의 HP/피해/이속/쿨다운은 기존 tools/ue/node-combat-rules.cjs STATS와 동일. 다른 종은 draft=true인 보행형 기본값이다. 갈고리손 끌어당김·종별 전용 기술 68종은 아직 구현하지 않았다. 고등급 고유 전투를 일반 근접 AI로 완성했다고 하지 않는다.
- Field.setEcologyContext(zone,{night,invasion})는 서버 사건 연결용이다. 클라이언트는 바꿀 수 없다. 확정되지 않은 일주기/침공 일정을 만들지 않았다. 현재 기본값은 false/false다.
- G2 지배형 기존 강함/등장 주기/이름은 그대로다. 이 지시서에서 미정 수치를 정하지 않았다.
- 갈고리손은 승인용 이미지 v1만 생성. 감독 승인, visualH, GLB, 리깅·5개 클립, 확대/포즈 시트, 휴대폰 LOD 검수는 아직 없다. Hi3D 생성/다운로드/크레딧 지출 없음.
- Claude 문서 209·210의 2D·3D 혼자 연습 및 온라인 패킷 그리기는 최신 작업본에 반영했다. js/mmo/field-mobs.js, mmo.html, world3d.html을 별도로 수정하지 않았다. 실제 서버 패킷을 현재 mobsFromPacket으로 해독하고 두 실제 소켓의 체력/세대/타격/피격 id를 시험했다. 실제 브라우저 2인 플레이·혼자 연습 몬스터 반격·모바일 FPS는 Claude 후속 검수다. Pages에 문서 210 빌드가 반영됐는지 확인한 뒤 서버를 합친다.
- 공개 version.json 조회 결과: build b077bc1, at 2026-10-09T06:19:18Z. 확정 v2 해독기·경량 몬스터 몸의 Pages 배포는 확인했다. GitHub Pages/Android 워크플로는 main만 대상으로 하므로 이번 별도 브랜치 push로 실행하지 않는다. 이 확인은 실제 Render 서비스의 자동 배포 여부 증명이 아니다.
- 공유는 gpt/monster-server-v10 브랜치만. Render 재배포/main push 없음. render.yaml의 free /tmp/hwanghon / EPHEMERAL_STORAGE=1은 재배포 초기화 위험이 있다. 실제 자동 배포 설정은 Render 작업공간 확인 전 조회 불가; 켜졌다고 단정하지 않는다. 데이터 보존 확인/초기화 허용 전 main에 합치지 않는다.

브라우저 연결 (Claude)
- loadCjs('/server/field-ecology.cjs'), loadCjs('/server/field-mob-combat.cjs'). 실제 HTTP/실제 cjs-browser.js로 로드 검증.
- 서버 공개 파일은 이 두 모듈, field-ecology-route.cjs, field-ecology-patrols.json만 명시 허용. field.cjs/store/index/rpg-store 등 서버 소스는 여전히 404.
- 공유 CJS의 Ecology 생성자는 원본 캐논 형식 {MonsterId,Grade,...}을 받는다. Claude의 기존 ecologyCatalog(CATALOG)를 쓰면 된다. 해당 함수/원본 캐논 일치 시험은 유지한다. 감독 캐논을 별도로 재해석하지 않는다.
- 온라인은 현재 mobsFromPacket(rows)를 그대로 사용한다. [id,catalogId,x,z,alive,anim,generation,hpPercent,seq]를 실제 함수로 해독하여 HP/생사/순번을 검증했다. 8번째 체력을 순번으로 오해하지 않고 9번째 순번으로 연속 attack/hit을 다시 재생한다. attack/hit이라는 동작 이름은 확정된 연결 규약이다. 아직 실제 갈고리손 클립이 생성됐다는 뜻은 아니다.
- generation이 바뀌면 옛 엔티티의 HP/클립/락온을 버리고 새 개체로 취급한다. 매 패킷에 mobs=[]도 보내므로 AOI 밖/시체 만료 제거를 처리한다.
