카인 무기 이탈 수정 — 2026-10-09

문제와 실제 재현
- world3d.html 실제 Animated 캐릭터 경로, 원본/휴대폰 LOD 둘 다 렌더했다.
- 원본 GLB의 손 정점으로 계산한 주먹 중심과 LOD 정점으로 다시 추정한 중심이 다르다.
  오른손 6.82 cm, 왼손 6.35 cm(손 뼈 로컬). 캐릭터 배율 1.14에서는 약 7.8 / 7.2 cm.
- LOD의 드문 정점으로 손바닥 6 mm 구간을 다시 재면서 손잡이 중심이 바깥으로 옮겨졌고,
  엄지 후보 정점도 부족해 thumb=null이었다. 무기를 손에 연결한 뼈 좌표 시험은 통과하던 결함이다.

수정
- js/kain-grip-reference.js: 원본 손의 주먹 중심, 감기 틀, 엄지 보정을 보존한다.
  원본 손 bind matrix와 손 슬롯 축이 일치하는 리그에만 적용한다. 다른 리그는 기존 추정으로 돌아간다.
- js/hand-grip.js: 손 메시 모프/무기 anchor/왼손 IK가 같은 원본 기준을 쓴다.
- sw.js: 새 모듈도 오프라인 코드 캐시에 포함한다.
- 원본 몸체/의상/무기 GLB와 스킨 웨이트, 스킬 시간/판정, 서버 코드는 변경하지 않았다.

검증
- tests/kain-lod-grip.test.mjs: 원본 SHA, 원본 재추정과 보존 기준 일치, 다른 리그 거절,
  양손 LOD 기준 보존과 엄지 보존, 실제 Animated 장착 및 IK의 원본/LOD 일치를 검사한다.
- 부정 검증: 이전 LOD 재추정 결과를 넣으면 주먹 중심 검사가 실패하는 것을 assert.throws로 확인했다.
- LOD 손가락/엄지 모서리 늘어남도 검사했다. 최대 손가락 3.34 mm, 엄지 마디 9.78 mm,
  손 보간까지 포함한 카인 LOD 몸체 24,212 삼각형. 실기기 FPS를 이 수치로 보증하지 않는다.
- 대기/달리기/평타1·2·3/스매시/skill1/카운터/궁극기 9자세 × 원본/LOD,
  실제 필드 클라이언트에서 확대·전신 렌더. 브라우저 오류 0.
- 정해진 프레임을 샘플링한 검수이며, 실시간 전체 영상 또는 S25 Ultra 실기기 FPS 검증은 아니다.
- 대기/달리기는 기존 한손 자세를 보존했다. 왼손을 언제나 대검에 고정했다고 주장하지 않는다.
- 전체 스킬 모션/손목 피부 변형의 완성 승인과 이번 무기 기준점 수정은 별개다.

배포/협업 주의
- 이 수정만 별도 커밋으로 main에 적용할 수 있다. 기존 몬스터 서버 브랜치 전체를 합칠 필요 없다.
- Pages 환경은 main만 허용한다는 것을 GitHub API로 읽어 확인했다.
- Render 연결은 작업공간 미선택으로 실제 autoDeploy 설정을 확인하지 못했다.
  render.yaml에는 commit 자동 배포와 /tmp 저장소가 명시되어 있으므로 데이터 초기화 안전을 단정하지 않는다.
- Render 재배포, main push, 계정 설정 변경 없이 별도 수정 브랜치로 전달한다.
- GitHub 브랜치: gpt/kain-weapon-grip (최신 main에서 카인 수정만 분리, 서버 파일 변경 0).
- 로컬 확인: tools/serve.cjs를 실행하고 world3d.html?offline=1&zone=daejeon&char=kain&lod=1.
  검수 도구도 Pages와 같이 순수 CJS 파일을 읽을 수 있는 로컬 정적 호스트를 사용한다.
