# GPT 지시서 (초안 — 디렉터 승인 전) · 3D 필드 에셋 키트: 폐허 건물 외벽 · 잔해 (2026-10-09, Claude)

## 배경
디렉터 결정: 필드는 이제 **3D(`world3d.html`)만** 한다. 3D 필드 장면은 원래 위에서 내려다보는 2D 지도 굽기용 장면 빌더를 그대로 쓴다 — 3인칭으로 가까이 보면 건물은 상자, 바위는 다면체. Claude 가 모양을 다듬어 봤지만(문서 215) 한계가 분명하다 → **3D 용 모델 키트**가 필요하다. 모델은 GPT 몫.

## 만들 것 (첫 묶음 — 적게, 여러 번 쓰는 것)
| # | 이름(안) | 용도 | 크기·한도 |
|---|---|---|---|
| 1 | 무너진 건물 외벽 조각 3종 (3·6·10 m 폭) | 건물 상자 겉면에 덧대기 · 창틀·철근·깨진 모서리 | 각 ≤ 3천 삼각형 · 텍스처 1K |
| 2 | 콘크리트 잔해 더미 3종 (작음·중간·큼) | 지금의 상자 더미 대신 | 각 ≤ 1.5천 |
| 3 | 바위 3종 | 지금의 다면체 바위 대신 | 각 ≤ 800 |
| 4 | 폐차 2종 · 바리케이드 · 전봇대 쓰러진 것 | 거리 소품 | 각 ≤ 2천 |
| 5 | 나무 2종 (잎 덩어리 + 줄기) | 지금의 정이십면체 잎 대신 | 각 ≤ 1.5천 |

- 형식: GLB · Y 위 · 1 단위 = 1 m · 바닥이 y=0 · 원점은 바닥 가운데 · 재질은 PBR(금속성 0~0.2 — 쇳덩이처럼 보이지 않게, 규약 §1).
- 휴대폰 LOD: 각 모델 ¼ 삼각형판도 같이 (`art/3d/lod/` 규칙, `tools/2d/make-lod.mjs` 로 만들어도 된다).
- 놓을 곳: `art/3d/props/field/` (새 폴더). 이름은 영어 소문자 `_`.

## 연결 (Claude 가 한다 — 당신은 모델만)
- 장면 빌더 `js/mmo/env-lib.js` 의 `dress()`(바위·덤불·잔해) · `trees()` · `buildings()` 가 3D 일 때(`setView3d`) 이 모델을 인스턴스로 쓴다. 자리·막이는 지금 그대로(서버 지도 `map.json` 과 맞아야 한다).
- 무게 기준: 지역당 삼각형 증가 +20% 안 (지금 대전 77만 · Pixel 7 가로).

## 지켜 줄 것
- 서버·지도·게임 규칙은 건드리지 않는다. 모델 파일과 그 출처·생성 기록만.
- Hi3D 자격증명은 환경변수로만, 웹 세션 흔적은 밖으로 내보내지 않는다.
