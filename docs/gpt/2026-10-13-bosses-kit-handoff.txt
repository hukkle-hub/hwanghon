기준: origin/main 2ecf4dab3. 던전 지형·조명·차량 변경을 rebase로 보존했다.
수치는 전투 검수용 튜닝이며 미정 드롭·경험치·일주기·침공 정책은 변경하지 않았다.

구현
- 레비아탄: 수압 연타 / 근접 아가미 충격 / 단계 전환 광역 수압.
- 에이지스: 조준 포격 / 근접 부채꼴 / 단계 전환 장벽 밀치기.
- 셀레스티얼: 하강 공격 / 두 번의 돌풍 / 세 방향 연속 공격. 비행 높이 3.4m를 착지 시 상쇄하고 복귀한다.
- 아스널: 지연 3연 포격 / 근접 압력파 / 일찍 고정되는 표적 사격.
- 노바: 안쪽 안전 구역이 있는 고리 / 위치 고정 결정 사출 / 단계 전환 중심 폭발.
- 예비·접점·후딜을 동일한 서버 시계로 그린다. 마지막 타 카운터, 중단 시 잔여 피해 제거, 단계 기술 한 번, recovery 보장을 시험했다.
- 고정 4종은 자리·몸 방향을 보존하고 판정/효과 방향만 바꾼다. 기존 다른 보스는 유지.
- 새 효과는 크기가 제한된 풀. 바닥 타이머는 재도입하지 않음. 공격 발생 볼륨/공중 표적/코어 예열만 표시.
- 기계형에 기존 번개·원형 효과가 중복되지 않게 했고, 셀레스티얼 효과 높이를 실제 body lift와 맞췄다.
- 공격 원통의 끝면과 과도한 불투명도를 제거해 카메라가 공격축에 있을 때 시야 전체를 덮지 않게 했다.

실제 코드에서 발견한 접속 조건
- world3d.html의 gl.animations.length 안에 setupKitMotion이 있어서 완전 정지 GLB는 AI만 넣어도 화면에 연결되지 않았다.
- 보호 파일 world3d.html은 수정하지 않았다. 원본 정점·재질·텍스처 binary prefix를 그대로 두고 부모 노드에 idle/stagger/기술3개를 추가했다.
- 네 GLB의 움직임은 작은 강체 예열/반동이다. 포탑 분할 리깅·날개 관절·생물형 척추 리깅을 완료했다고 해석하면 안 된다.
- 노바는 지시서와 달리 이미 15클립/스킨이 있었다. 기존 몸체를 수정하지 않고 atk_spin/atk_bolt/atk_slam을 사용했다.

- 검수 도구에서만 HP를 100만으로 올린다. maxHp 및 피해 계산은 그대로. 일반 플레이 검수와 구분해야 한다.
- 30초 녹화는 실제 world3d 캔버스이며 UI는 영상에 포함되지 않는다. 서버 8795는 loopback 전용이다.
- 보스 전체 보기 버튼은 QA 카메라다. 일반 플레이 카메라가 해결됐다는 증거로 사용하면 안 된다.

현재 시각 검수에서 확인한 남은 사항 (병합/배포 전 확인)
1. 레비아탄: 실제 터널 AI/피해/클립 연결. 몸이 긴 가로 방향이고 코어 효과는 중심 앵커라 입·포구 정합은 추가 교정 필요.
2. 아스널: 주 격납고 상자와 몸체가 플레이 카메라를 가리고 충돌 카메라가 발 쪽으로 당겨진다. 지형/카메라 소유 파일은 건드리지 않았음.
3. 노바: 세로 412×915에서 입구 경사로 벽·보가 보스를 가린다. 기존 몸은 사지 있는 결정형 리그이며 원작 '결정 산' 일치 여부 별도 확인 필요.
4. 셀레스티얼: 높이 변화와 피해 연결은 확인. 플레이 카메라 위로 몸이 벗어나는 구간과 날개 최소 강체 모션은 추가 조정 대상.
5. 휴대폰 크기 915×412 / 412×915는 데스크톱 브라우저 viewport 검사다. 실제 Pixel 7 하드웨어 성능 검수나 전체 확대 모션 합격은 아님.
6. 전체 영상 파일과 2fps 샘플을 남겼다. 샘플 이미지·수치만으로 전체 모션 합격을 선언하지 않았다. 2인 온라인은 Claude 검수 전.
