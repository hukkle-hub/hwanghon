# 아인 공격 스킬 무게감 — 로컬 검수본

공속 100%, 적중 히트스톱을 제외한 시간. 원본 GLB/스킬 피해량/쿨타임/이동/회피/버프/기본 연타는 변경하지 않음.

| 동작 | 이전 타격/전체 | 교정 타격/전체 | 회피 캔슬 가능 |
|---|---|---|---|
| 낫 베기 skill1 | 0.42 / 1.00초 | 0.58 / 1.32초 | 1.02초 |
| 피의 회전 skill3 | 0.42 / 1.00초 | 0.64 / 1.42초 | 1.10초 |
| 궁극기 ult | 0.55 / 1.20초 | 0.80 / 1.62초 | 1.38초 |

준비를 조금 더 길게 두고 타격 뒤 회수를 늘린 타이밍 조정이다. 이번 변경은 새로운 전신 모션이나 공격 궤적 제작이 아니다. 공격이 길어진 만큼 행동 구속과 지속 DPS에도 영향이 있다. 회피 자체의 속도/무적시간은 유지하되 공격 중 회피 허용 시점은 회수 구간에 맞춰 늦춘다.

RULES.motion.characterProfiles.ain을 솔로와 온라인 서버가 함께 참조한다. 렌더러는 서버/전투 action의 hitAt/duration을 기존 방식대로 읽어 몸통 클립과 낫 경로를 같은 판정 시각에 맞춘다. 기존 온라인 공격 스킬은 smash 분기로 처리돼 솔로와 시간이 달랐으나, 아인의 해당 두 스킬은 이제 같은 시간표를 사용한다.

검수 페이지에 이전/교정 박자 선택 추가. 변경된 세 스킬은 공속 100% 실전 타이밍으로 재생하며 클립의 원래 길이와 구별한다. 실제 피해 피드백/히트스톱은 없는 프리뷰다. 다른 동작은 기존 클립 시간으로 재생한다.

검증: npm test 138/138. 공속 70/100/160에서 솔로·온라인 타격/전체/캔슬/clipHit 일치, 판정 전 피해 없음, 단일 타격 처리, 클립 접점 정렬, 이전 시간표를 구별하는 음성 대조, 다른 캐릭터 및 이동/버프 변경 없음. 브라우저에서 이전 1.00초와 변경 1.32초 비교, 스킬3 1.42초, 궁극기 1.62초 재생 확인. 브라우저 오류 없음.

상태: 로컬 적용·검수 완료. 공개 Pages/Render는 아직 1358b54이며 이 변경은 배포하지 않았다. 배포 시 js/dungeons.js와 server/raid.cjs를 함께 반영해야 한다.
