## 0-2. 전투의 공통 문법

1. 관찰 — 발, 실루엣, 호흡, 진동, 발광, 힘의 경로를 읽는다.
2. 유도 — 원하는 공격을 꺼내게 하거나 위치를 바꾼다.
3. 고정 — 카인이 적의 무게와 박자를 잠깐 멈춘다.
4. 동시 — 류가 두 지점을 한 박자에 처리한다.
5. 봉쇄 — 세라가 열 수 없거나 재생되는 경로를 막는다.
6. 파괴 — 아인이 스위트 스폿에서 결절을 끊는다.
7. 회수 — 결정·기록·소재·증거를 전투 후 실제로 챙긴다.
8. 귀환 — 다음 출격 전 허브의 사람·장비·기능이 변화한다.

**공통 금지:** 전투를 단순 HP 깎기로 바꾸지 않는다. 약점은 UI보다 몸·소리·파괴 후 기능 상실로 먼저 보인다.

## 0-3. 파티 역할 잠금

- **카인 / 고정** — 타이밍 가드, 적의 일격을 물어 공격 창 생성.
- **류 / 동시** — 두 지점을 같은 박자에 마킹/처리. 신경 가속과 잔상.
- **아인 / 파괴** — 거리·각도·스위트 스폿 기반 정밀 절단.
- **세라 / 봉쇄** — 재생·복구·닫힘을 촉매/결계로 잠근다.

## 0-4. 생산용 연속성 잠금

1. **EP03의 B**는 아인·카인의 개인 전투등급 B로 고정.
2. **EP12의 B 장면**은 개인 재승급이 아니라 ‘정식 팀/계약 전력 B 등록’으로 제작한다.
3. **EP18 한 장인 사망**은 유지한다.
4. EP28 귀환 군중의 한 장인 표기는 제거하고 **공방 제자/정비 인력**으로 대체한다.
5. 지역 번호는 제작 데이터에서 사용하지 않는다. `Gangnam / Namsan / Yeouido / HanRiver / Namtaeryeong / Pangyo / Valley / Gyeryong / Goheung` 장소명으로만 관리한다.
6. EP21 안내인 사망 이후 전투 핵심 인원은 **4인**으로 고정한다.
7. 2·3부의 정답은 만들지 않는다. EP28의 ‘하늘의 응답’까지만 제1부 엔딩으로 잠근다.

# EP01 — 황혼 아래 사신의 낫

**Map:** `MAP_Gangnam_Bunker` / `MAP_Gangnam_Training`  
**핵심 기능:** 세계 소개 + 아인/카인 + 거리/박자/부위파괴 튜토리얼 + C 등록

### 스토리
남은 문서와 폐허 서울의 상태를 짧게 제시한다. 아인과 카인이 강남 벙커의 생활권으로 들어오고 평가·등록 절차를 거친다. 훈련장의 허수아비가 단순 시험물이 아니라 실제 위협으로 발현한다. 전투 후 결정을 회수하고 두 사람은 C등급으로 정식 등록된다. 마지막은 출격문 너머 붉은 안개와 카인의 ‘반보 뒤’ 위치로 끝낸다.

### 플레이
`Bunker Entrance → Registration → Equipment Check → Training Hall → Dummy Battle → Crystal Recovery → Deployment Gate`.
초반은 걷기/상호작용으로 조작을 최소 노출한다. 훈련전에서 이동, 거리 확인, 가드/카운터, 부위 파괴를 순서대로 열어 준다.

### 보스/전투
**각성 허수아비.**
- 몸통을 계속 때리면 해결되지 않는다.
- 예비동작 → 카인 고정 → 아인 스위트 스폿 절단.
- 첫 전투부터 “보이는 궤적과 판정이 같아야 한다”는 기준을 잠근다.

### 환경
벙커는 생활 흔적이 있는 군·민간 혼합 지하시설. 훈련장은 오래된 문양, 금속 바닥, 누수, 차가운 작업등. 출격문 쪽으로 갈수록 따뜻한 생활광이 끊기고 붉은 외부광이 들어온다.

### 애니메이션
- 아인: 기본 이동, 낫 휴대/전개, 거리 재기, 짧은 회피, 스위트 스폿 절단.
- 카인: 반보 뒤 대기, 장검 가드, 퍼펙트 가드 고정.
- 허수아비: 무생물 idle → 미세 호흡 같은 발현 → 5단 예비동작 → 파손.
- 회수: 결정 집기, 통증 잔존, 장비 정리.

### Sequencer
- `SQ_EP01_Opening_Documents`
- `SQ_EP01_Bunker_Entrance`
- `SQ_EP01_Dummy_Awaken`
- `SQ_EP01_Crystal_Recovery`
- `SQ_EP01_DeploymentGate_Outro`

### 필요 에셋
강남 벙커 모듈러 세트, 등록 데스크, CRT/문서 소품, 훈련장, 허수아비 3단 파손 메시, 결정, 아인 낫, 카인 장검, 출격문, 붉은 안개 VFX.

# EP02 — 어둠에 잠긴 강남역

**Map:** `MAP_Gangnam_Station`  
**핵심 기능:** 첫 실전·총기 무용·클레이브 관찰·패퇴

### 스토리
아인·카인은 현장 동행자와 강남역으로 진입한다. 총기가 위협을 멈추지 못한다는 사실을 실제 현장에서 본다. 클레이브와 처음 조우하지만 약점 구조를 이해하지 못한 채 퇴각한다. “살아 돌아온 패배”를 첫 실전 결과로 남긴다.

### 플레이
지상 접근 → 지하상가 정찰 → 민간 흔적 조사 → 소규모 적 → 총기 무용 연출 → 클레이브 첫 조우 → 관찰 미션 → 강제 퇴각.
보스전 목표는 처치가 아니라 **3개의 예비동작을 읽고 생존해 탈출**하는 것.

### 보스/전투
**클레이브 Phase 0.**
- 어깨 장갑이 서로 닫히며 결절을 숨긴다.
- 현재 파티엔 류가 없어서 양쪽을 동시에 열 수 없다.
- 성공 조건: 공격 패턴 데이터 축적 + 생존 + 탈출.

### 환경
정전된 지하상가, 깨진 간판, 물 고인 승강장, 비어 있는 선로. 지상 하늘에는 새가 없다.

### 애니메이션
클레이브 중량 이동, 장갑 폐쇄, 바닥 긁기, 대형 처형기. 플레이어는 ‘맞고 버티기’보다 피하고 읽는 모션 중심.

### Sequencer
`SQ_EP02_Station_Descent`  
`SQ_EP02_Gunfire_Fails`  
`SQ_EP02_Cleave_FirstReveal`  
`SQ_EP02_ForcedRetreat`

### 필요 에셋
강남역 모듈러, 지하상가 셔터, 파손 유리, 침수 데칼, 클레이브 보스 리그/장갑 파츠, 현장 총기 소품.

**핵심 기능:** 관찰→가설→검증→격파 표준 보스 루프

- 반복 시 보스가 한쪽 장갑을 미끼로 사용하는 변형 패턴 추가.

# EP06 — 여의도 금융가의 유령들

**Map:** `MAP_Yeouido_Fog`  
**핵심 기능:** 시야 제한·절차 붕괴·에이지스-07 패퇴

### 플레이

금융가 고층 빌딩, 지하 주차/로비, 시야 10~20m 안개, 반사 유리.

### 애니메이션
에이지스 소켓 전개/재폐쇄, 안개 속 실루엣 공격, 류 잔상 흔적.

# 29. 전권 공통 제작 체크리스트

## 스토리
- 각 EP의 핵심 사건이 28화 캐논 순서를 벗어나지 않았는가.
- 설명 자막이 행동으로 보여 줄 수 있는 정보를 대신하지 않는가.
- 2·3부 보호 영역을 임의로 확정하지 않았는가.

## 플레이
- 매 화에 플레이어가 새로 배우거나 기존 답을 다시 의심할 이유가 있는가.
- 실패 원인이 거리/각도/타이밍/순서 중 무엇인지 설명 가능한가.
- 승리가 HP 0 하나로 환원되지 않는가.

## 보스/전투
- 약점은 몸·소리·기능으로 먼저 읽히는가.
- 부위 파괴 뒤 실제 기술/이동/방어 기능이 사라지는가.
- 4인 역할 중 하나가 결손되거나 뒤집히는 긴장이 있는가.

## 환경
- 지역마다 한눈에 구별되는 실루엣이 있는가.
- 전투 뒤 환경이 원상복구되지 않고 결과를 남기는가.
- 생활 공간은 사람의 습관과 손실을 보여 주는가.

## 애니메이션
- 이동→예비동작→공격→접촉→회복이 판정과 정확히 맞는가.
- 손/무기/발 위치가 디자인시트와 일치하는가.
- 파괴 상태별로 적의 행동이 실제로 달라지는가.

## Sequencer
- 전투 판단이 필요한 순간에 입력을 빼앗지 않는가.
- 컷신은 장면 의미를 바꾸는 순간에만 사용되는가.
- 마지막 프레임이 다음 플레이 시작점과 공간적으로 이어지는가.

## SaveFlag
- EP 종료 조건이 명확한가.
- 사망/합류/허브 손상/보스 상태가 재접속 후에도 유지되는가.
- 다음 EP가 이전 플래그 없이 직접 열리지 않는가.
