「파티 모집 화면도 시트대로 만들어.」

## 1. 이 시트만 구현이 없었다

## 2. 시트의 3열을 그대로

```
┌ 파티 모집 / 인력사무실 ──────────────────── 75,300 · 접속 N/100 ┐
│           파티 찾기  |  내 파티                                  │
├ 임무 목록 ─┬ 파티 정보 · 코드 · 평균 전투력 ─┬ 임무 상세 ────────┤
│ 지하 훈련장│  ┌1P─┐┌2P─┐┌3P─┐┌4P─┐          │ 보스 아트         │
│ 갈대습지 S │  │초상││초상││모집││모집│          │ 격파 대상         │
│ 2경구 정화장│ │이름││이름││ 중 ││ 중 │          │ 임무 목표         │
│ …  7곳     │  │Lv·전투력  │    │    │          │ 주요 적 · 보수    │
│            │  파티 채팅 ──────────────       ├ 파티 모집 설정 ───┤
│            │  [준비 완료][모집 시작][나가기]  │ 방식·목적·만들기  │
└ 로비 · 인력 사무소 · 쉘터 · 파티 모집 · 상점 · 창고 ──────────────┘
```

- **임무 목록**(좌): 던전 7곳. 고르면 오른쪽 상세와 «새 파티» 의 출격 지역이
  따라간다. 줄마다 그 지역에 **공개 모집이 몇 개 있는지**를 배지로 보여 준다.
- **파티 찾기**: 고른 지역의 모집 목록. 그 지역에 없으면 전체를 보여 주고
  그렇다고 말한다 — 빈 화면을 주지 않는다.
- **내 파티**: 4인 카드. 초상은 전신 아트, 아래에 이름·캐릭터·**Lv·전투력**,
  머리에 `1P~4P` 와 상태(파티장 / 준비 완료 / 준비 중 / 재접속 대기).
  빈 칸은 점선으로 「방 코드를 전달해 동료를 부르세요」.
- 파티에 들어가면 **내 파티** 탭으로 저절로 넘어간다. 출격하면 전투 화면
  (`party.html`)으로 넘긴다.

## 3. 서버 — 한 필드만 더했다

방 프로토콜(`create`/`join`/`ready`/`start`/`leave`/`board`/`partyPurpose`)은
**이미 다 있었다.** 시트가 보여 주는 것 중 서버에 없던 건 파티원의
**레벨·전투력** 하나였다.

```js
const POWER=st=>Math.round((st?.atk||0)*6+(st?.hp||0)*0.3);
function roomState(room){const lobby=!room.raid; … lobby?lobbyInfo(id):{} …}
```

**대기 중인 방에서만** 프로필을 읽는다. 전투 중에는 방 상태가 초당 20회까지
방송되므로 거기서 DB 를 읽으면 안 된다.

> 시트의 카드에는 카운터·부위파괴·정제·드랍·제작 **5줄 등급표**도 있다.
> 그 등급은 지금 로컬 저장(`TW_GRADE`)에만 있고 서버에는 없다. 없는 값을
> 지어내지 않고 **레벨·전투력까지만** 실었다. 넣으려면 서버가 등급을
> 계산해 내려보내야 한다 — 지시를 받고 한다.

## 4. 만들면서 밟은 것 셋

1. **합류해도 2P 칸이 계속 «모집 중» 이었다.** 방 상태는 «바뀐 곳만» 보내는
   패치(`party-wire`)로 오는데 `recruit.html` 이 그 스크립트를 안 읽고 있었다.
   패치를 못 풀어 상태가 영영 갱신되지 않았다.
2. **`hidden` 속성이 안 먹고 있었다.** `.btn` 이 `display:inline-flex` 를 정해
   버려서 「코드 복사」·「파티 나가기」, 쉘터의 「공개 모집」·「공지 저장」이
   숨겨지지 않고 계속 보였다. `ui.css` 에 `[hidden]{display:none!important}`.
3. 그 `!important` 가 **내가 방금 넣은 인라인 `display:grid`를 이겼다** —
   파티 칸이 통째로 안 보였다. display 를 스타일시트로 옮겨 해결.
   (2번을 고치자마자 3번이 났다. 고친 뒤 반드시 다시 돌려 봐야 한다.)

`.field` 안의 `select` 에 규칙이 없어 「공개 — 모집 목록에 올린다」가 잘리던
것도 같이 고쳤다.
