# 197 · 거점 점령 — 기획 초안 (GPT 와 상의용, 2026-10-07)

디렉터: «리니지에서 성을 먹는다면 우리는 거점을 먹는 방법을 쓸거야. 아이온처럼 보스가 거점을 먹고 있는걸 뺐는다는 설정이야»
→ «지피티와 한번 상의해보게 하나 써봐».
화면·맵 쪽은 이미 만들어 배포했다(문서 192 §8). 이 문서는 **규칙**을 정하려는 초안이다. 숫자는 전부 제안값이고, 표의 «정할 것» 은 디렉터·GPT 가 고른다.

## 1. 한 장으로

```
보스가 거점을 차지 ──(누구나 언제든 공격)──▶ 보스 처치: 기여도 1위 «길드» 가 주인
        ▲                                            │
        │ 탈환전에서 아무도 못 잡음                    ▼
        └──────────── 주 1회 탈환전 (60분) ◀── 길드의 거점 (깃발·칭호·혜택)
                       보스가 돌아온다 — 그때 기여도 1위 길드가 새 주인 (수비든 도전이든)
```

PvP 없이 «길드끼리 보스 딜 경쟁» 으로 주인이 바뀐다. 지금 서버에 PvP 가 없고(때리기는 보스만), 휴대폰 소규모 서버에서 길드전 PvP 는 사람이 모자라 열리지 않을 위험이 크다.

## 2. 참고 — 리니지 · 아이온 · 황혼

| | 리니지 공성 | 아이온 요새전 | **황혼 거점 점령 (제안)** |
|---|---|---|---|
| 대상 | 성 | 요새 | 거점(대전역 · 부산역 · 전주 · 제주시 …). 강남 벙커는 시작 마을이라 뺀다 |
| 처음 주인 | NPC 성주 | 발라우르(제3 세력) | **거점을 먹은 보스** |
| 빼앗는 법 | 혈맹이 수호탑을 부수고 군주가 면류관 | 요새 수호신장 처치 | 거점 보스 처치 → 기여도 1위 길드 |
| 시간 | 정해진 공성 시간 | 정해진 시간 | 보스 점령 중엔 언제든, 길드 거점이 되면 주 1회 탈환전 |
| 싸움 | PvP 중심 | PvP + PvE | **PvE 경쟁** (딜 합산) |
| 주인 몫 | 세금 · 성 던전 | 보상 · 지역 혜택 | 정할 것 (§5) |

## 3. 이미 있는 것

| 쪽 | 있는 것 |
|---|---|
| 화면 (내가 만듦) | 점령 지점 깃발 · 땅 고리 · 마을 이름표(보스 점령지 위험 S ↔ 길드의 안전 지대) · 전국 지도 주인 표시. `hubState` / `hubStates` 메시지를 받으면 바로 바뀐다(문서 192 §8 규격) |
| 맵 (내가 만듦) | 거점마다 `map.json` areas 에 `kind: 'siege'` 원(마을 한가운데 맨땅). 서버가 이미 `map.json` 을 읽는다 |
| 서버 (GPT) | 보스 주기 창(`boss-cycle`), 처치 때 기여도 순위(피해 비율 `share`), 처치 기록(`boss_kills`), 길드(`guilds` · `guild_members` 한 사람 한 길드 · `guild_roles`), 알림(`announce`) |
| 없는 것 | PvP, 안전 지대 서버 판정(지금은 화면 표시뿐), 거점 주인 저장, 주간 고정 시각 창 |

## 4. 규칙 초안

**4.1 거점 보스** — 거점마다 하나. 모습·이름은 GPT 가 다시 만드는 보스 작업에 맞춘다. 점령 지점에 선다. 체력바는 안 보인다(디렉터 결정 그대로).

**4.2 처음 빼앗기** — 보스가 차지한 동안은 늘 점령 지점에 있다(주기 출현 아님 — «거점을 깔고 앉아 있다»). 처치하면:
- 길드원들의 피해를 **길드별로 더해** 1위 길드가 주인. 길드 없는 사람의 피해는 어느 길드에도 안 들어간다(장비 줍기 우선권 등 개인 보상은 지금처럼).
- 아무 길드도 안 때렸으면(전원 무소속) → «주인 없음», 다음 탈환전 때 보스가 돌아온다.
- 알림: «[황혼] 이 대전역을 되찾았다».

**4.3 탈환전** — 주 1회, 거점마다 다른 요일 21:00 (KST) 60분. 예) 대전 화 · 부산 목 · 전주 토 · 제주 일.
- 보스가 점령 지점에 돌아온다. 창 안에 잡으면 **그때 기여도 1위 길드**가 주인 — 지키던 길드가 1위면 유지, 다른 길드가 1위면 넘어간다.
- 창이 끝날 때까지 못 잡으면 보스가 거점을 되찾는다(마을이 다시 위험 S).
- 30분 전 · 시작 · 끝에 전국 알림.

**4.4 소규모 서버 안전장치** (정할 것)
- 수비 가산 — 지키는 길드 피해 ×1.1? (지키는 쪽이 유리해야 «지킨다» 는 의미가 생긴다 / 반대로 독점이 굳는다)
- 독점 막기 — 한 길드가 동시에 가질 수 있는 거점 수 상한(예: 2)? 연속으로 지킬수록 돌아오는 보스가 강해진다?
- 길드가 하나뿐인 서버에서도 재미있게 — 탈환전 보스가 «못 잡으면 뺏긴다» 자체가 도전이 되게 체력을 길드 규모에 맞춰 조정?

**4.5 보스 점령 중 마을** — 마을도 위험(이미 화면이 위험 S 로 보여 줌). 거점 상점·길잡이 쉼터는 닫힌다? 보스의 졸개가 마을에 나온다? (정할 것)

## 5. 주인 혜택 — 후보

| 묶음 | 내용 | 내 의견 |
|---|---|---|
| **자랑** | 깃발 · 전국 지도 · 마을 이름표(이미 됨), 칭호 «대전역의 주인», 길드원 이름 색 | **먼저** — 비용이 거의 없고 «보여 주기» 시스템(문서 188)과 맞는다 |
| **편의** | 거점에서 부활, 길잡이 이동 할인·무료, 거점 창고 | **먼저** — 길드에 들어갈 이유가 된다 |
| 경제 | 거점 상점 세금 일부(리니지 세율) | 상점 경제가 생긴 뒤 |
| 성장 | 근처 필드 경험치 +5% (길드원) | 작게만 — 성장을 거점에 묶으면 무소속·소규모가 밀려난다 |

## 6. 서버 일 (GPT)

- 저장: `hub_owners(zone PRIMARY KEY, kind TEXT, guild TEXT NULL, since INTEGER, next_siege INTEGER)` — Render 의 지워지지 않는 디스크 문제(DEPLOY-PENDING §5)와 같이 간다.
- 처치 때 길드 합산: 기여도 순위 × `guild_members` 조인.
- 탈환전 창: 지금 `boss-cycle` 은 «주기 + 시작·끝 오프셋» — «매주 화 21:00~22:00» 같은 **주간 고정 시각** 창이 필요하다(KST 기준).
- 메시지: `hubState`(그 지역) · `hubStates`(전국 지도) — 문서 192 §8 규격 그대로. 화면은 받을 준비가 끝났다.
- 알림: `announce` 에 `kind: 'hubTaken' | 'hubLost' | 'siegeSoon' | 'siegeStart' | 'siegeEnd'`.
- 안전 지대: PvP 가 없으니 지금은 «몬스터·졸개가 길드 마을에 안 나온다» 정도. PvP 를 넣게 되면 서버가 막아야 한다.

## 7. 화면·맵 일 (나) — 규칙이 정해지면

- 거점 보스 등장(점령 지점), 탈환전 남은 시간 · 진행 중 표시, 전국 지도에 다음 탈환전 시각.
- 칭호 · 길드원 이름 색 표시.
- 대기 중인 거점(부산역 · 전주 · 제주시) 굽기 — 맵 둘 곳(문서 193)이 정해진 뒤.

## 8. GPT 와 정할 것

1. **흐름이 맞나?** 보스 점령 중엔 언제든 · 길드 거점이 되면 주 1회 탈환전 · PvE 딜 경쟁.
2. **탈환전 요일·시각·길이** — 거점마다 다른 요일 21:00, 60분이 맞나?
3. **무소속 피해** — 안 세는 게 맞나? (길드 가입 동기 vs 혼자 노는 사람)
4. **수비 가산 · 독점 막기** — §4.4 중 무엇을?
5. **주인 혜택** — §5 에서 처음에 넣을 것.
6. **보스 점령 중 마을** — 상점·쉼터 닫기, 졸개 출현?
7. **강남 벙커 제외** — 맞나?
8. **거점 보스 모습** — GPT 의 새 보스 작업에서 거점마다 하나씩 나올 수 있나?
