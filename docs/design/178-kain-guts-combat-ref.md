# 178 — 카인 스킬 동작·보스전 참고: 붉은사막 «가츠 드래곤슬레이어» (2026-10-03)

디렉터: «카인 스킬모션 잡을 때 전투 참고해. 이런식이면 좋겠어. 보스도 참고하고»

- 영상: <https://youtube.com/shorts/IqlSJv89q0w>
  - 「붉은사막 가츠 드래곤슬레이어」, 46초, 세로 영상.
  - 설명: 붉은사막에서 가츠 코스프레(드래곤슬레이어 + 광전사의 갑주)로 사도를 잡는 장면.
- 본 방법
  - 크롬 창이 가려져 있어서 영상이 재생되지 않았다.
  - 그래서 유튜브의 1초 간격 미리보기 장면 47장(101×180)을 이어 붙여 봤다.
  - 큰 흐름과 구도는 읽히지만 프레임 단위 박자는 읽히지 않는다. 박자는 아래 «주문서»에서 우리가 정한다.
- 생각만 가져온다. 화면과 동작을 베끼지 않는다.

## 1. 영상에서 읽은 것 (초 단위)

| 초 | 장면 | 가져올 점 |
|---|---|---|
| 0–3 | 높은 3인칭 카메라, 물가 폐허를 달려 들어감 | 카메라가 높고 멀다. 대검의 긴 궤적이 화면 안에 다 들어온다 |
| 4 | 화면 전체가 흐려지며 뛰어올라 내려찍기 | **도약 내려찍기**: 공중에서 카메라가 같이 떨어진다 |
| 5–6 | 크게 가로로 벤 뒤 화면이 붉게 번쩍임 | 적중 순간 **붉은 섬광 한 프레임** + 멈춤 |
| 7–9 | 잔해가 튀고, 흰 먼지 폭발 | 바닥 타격 뒤 **흰 먼지 원형 폭발**과 파편 |
| 10–11 | 검을 등에 메고 걷기 | **크기가 서 있는 실루엣에서 읽힌다**(검이 키만 하다) |
| 12–23 | 성 안뜰, 병사 여럿을 상대 | **한 번 휘두르면 여럿이 맞고 날아간다**. 계단 위로 나뒹군다(17–19). 앞으로 파고들기(20–21), 붉은 궤적의 가로 베기(22) |
| 24–32 | 더 무거운 타격, 화면 보랏빛(25), 흰 폭발(28) | 큰 기술 때 **화면 색이 잠깐 바뀐다**. 카메라가 등 뒤에 바짝 붙는다 |
| 33–38 | 보스(사도) 등장, 대사 자막 | 보스전 **들어가기 전 짧은 대화 컷** |
| 39–40 | 대검 클로즈업, 불티 | **마무리 직전 무기 클로즈업 한 컷** |
| 41–43 | 보스에게 연타 → 빛줄기·입자 폭발 | **마무리 타격 → 보스가 빛으로 터짐** |
| 44–46 | 보스 대사 → 흰 화면 | 끝맺음 컷 |

## 2. 카인에게 옮길 원칙

1. **무게**: 길게 끌어올리고, 짧고 빠르게 휘두르고, 길게 회복한다. 한 번 휘두르는 데 몸 전체가 따라간다(발 디딤, 허리 회전).
2. **멈춤과 흔들림**: 적중 순간 히트스톱은 지금 카인 배율 1.28을 유지한다. 큰 기술은 붉은 섬광 1프레임과 카메라 흔들림을 더한다.
3. **여럿을 쓸어낸다**: 가로 베기는 부채꼴 범위로 여러 명을 맞히고, 맞은 적은 뒤로 날아간다(넉백·띄우기).
4. **바닥이 반응한다**: 내려찍기는 흰 먼지 원형 폭발, 갈라짐, 파편이 함께 난다. 문서의 «철괴 압축형» 처형과 같은 방향이다.
5. **크기를 보여 준다**: 대기·걷기 때 검을 어깨나 등에 멘다. 검 길이가 키에 가깝게 읽혀야 한다.

## 3. 다섯 칸 주문서 (지금 Mixamo 클립 → 바꿀 방향)

| 칸 | 지금 | 바꿀 동작 | 박자(안) |
|---|---|---|---|
| 1 | Great Sword Attack | 비스듬히 내려 베기 한 방 | 끌어올림 0.45 s → 휘두름 0.12 s → 멈춤 0.10 s → 회복 0.5 s |
| 2 | Standing Block | 대검을 앞에 세워 **방패처럼** 막기 | 세우기 0.15 s, 막는 순간 불꽃 + 뒤로 밀림 |
| 3 | Melee Attack 360 High | 한 바퀴 크게 쓸어 베기. 주변 전부 맞고 날아감 | 몸 감기 0.4 s → 회전 0.35 s → 멈춤 0.13 s |
| 4 | Melee Attack Downward | **뛰어올라 내려찍기**(도약 → 낙하) | 도약 0.35 s → 공중 정점 0.1 s 정지 → 낙하 0.12 s → 흰 먼지 폭발 + 멈춤 0.18 s |
| 궁극 | Melee Combo Ver. 2 | 3연타 → 무기 클로즈업 1컷 → 마지막 내려찍기 | 마지막 타 전 «멈춤이 가장 긴» 한 컷(문서 기존 결정) |

- Mixamo 기본 클립만으로는 이 무게가 나오지 않는다.
- 동작 소스는 문서 기존 선택지를 따라 다음 순서로 시험한다.
  1. 텍스트로 동작 만들기(Kimodo): «두 손 대검 도약 내려찍기» 같은 문장으로 만든다.
  2. 직접 찍기(Rokoko Vision): 막대를 들고 촬영한다.
  3. 키프레임 손질: 끌어올림을 붙잡고, 휘두름을 압축하고, 회복을 늘린다.
- 모든 타격 프레임은 숫자로 기록하고, 장면 캡처로 확인한다(문서 157 주문서 형식).

## 4. 보스전에 옮길 것

1. **입장 컷**: 보스 앞에서 짧은 대사 1–2줄. 전투는 그 뒤에 시작한다.
2. **마무리 연출**
   - 보스 체력이 바닥나면 카인 대검 클로즈업 1컷(0.6 s)을 넣는다.
   - 그다음 마지막 일격을 넣는다.
   - 보스는 빛줄기와 입자로 터진다(1.5 s).
   - 흰 화면으로 넘어간다.
3. **보스 피격 반응**
   - 큰 보스(8인 공격대 크기)는 밀려나지 않는다.
   - 대신 붉은 섬광, 짧은 멈춤, 부위가 휘청이는 동작으로 «맞았다»를 보여 준다.

## 5. 다음 순서

1. 허수아비 상대로 4번(도약 내려찍기)부터 만든다. 무게가 가장 잘 드러나는 기술이다.
2. 박자표대로 손질한 동작과 흰 먼지 폭발을 붙인다.
3. 장면 캡처 6장(끌어올림, 정점, 낙하, 적중, 폭발, 회복)으로 디렉터 확인을 받는다.
