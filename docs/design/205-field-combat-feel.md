# 205 — 필드 손맛: 접점 시각 · 히트스톱 · 무기 궤적 · 불꽃 (2026-10-08)

디렉터: «진행해» — GPT 는 UE 에서 스킬 모션(v11, 스텔라 블레이드 방향)을, Claude 는 **겹치지 않게** 웹 필드(`mmo.html`)에 이미 있는 손맛 모듈을 붙인다.
감사(v10/v11 대조)에서 나온 빈칸: 솔로(game3d)·UE 에는 히트스톱·궤적·접점 효과가 다 있는데, **지배형과 싸우는 필드 화면에는 흔들림 하나뿐**이었다.
지배형을 때리면 숫자만 떴다 (소리·충격·반응 없음 — `sharedBossImpact` 가 클레이브 아닌 보스는 그냥 돌아갔다).

## 1. 무엇을 — `js/mmo/field-feel.js`

| | 규칙 (v11 + 솔로 표) | 값 |
|---|---|---|
| 접점 시각 | 누르는 순간이 아니라 **날이 닿는 프레임**에 숫자·불꽃·소리·히트스톱·대상 반응을 한 덩어리로 | 솔로 표 `RULES.motion.clipContacts(ByChar)` — 아인 평타 0.427 s · 피의 회전 0.596/0.867 s |
| 히트스톱 | 나와 맞은 쪽이 같이 멈춘다 — **화면만**. 서버 시계·위치 보정은 그대로 | 솔로 표 `RULES.hitstop` × 무기 리듬: 평타 .09 · 대검 ×1.28 · 기술 .21 · 반격 .24 |
| 무기 궤적 | 내 영웅만 (v11 MMO 주의). 날 끝을 따른다 | `weapon-trail.js` 그대로 · 구간 = `combat-quality.trailActive` (접점 60% ~ +0.22 s) |
| 불꽃 | 접점 중심, 작고 짧게 (평타 0.11~0.28 s) | 반격·치명은 조금 크게. 움직임 줄이기 설정이면 끔 |
| 대상 반응 | 지배형이 맞은 방향으로 14 cm 움찔 0.2 s — 몸만, 자리는 서버 것 | `flinchDominator` |

- 시간은 전부 **게임 시간**. 접점 예약(`atContact`)은 휘두름 «자체의 시계» 로 잰다 — 처음엔 벽시계로 셌더니 1타 히트스톱(.21 s)만큼 피의 회전 2타가 0.23 s 앞당겨졌다 (60 fps 걸음 촬영으로 발견 → 시험).
- 서버 판정 시각은 안 바꿨다 (누를 때 보낸다 — 클레이브 반격 창을 바꾸지 않는다). 온라인 `bossHit` 답은 남은 접점 시각까지 기다렸다 보이고, 답이 접점보다 늦으면 바로.
- **낫 장착을 솔로와 같게** (`mountAinScythe`): 필드는 Hi3D 낫 GLB 를 그대로 달아 궤적이 «자루» 를 따라 곧은 판이 됐다. 솔로처럼 자루를 손 축에 맞추고 날 시작·끝 표식을 달자 날 끝 호를 그린다.

## 2. 검수

- 헤드리스는 초당 1~2프레임이고 한 프레임 = 게임 0.05 s 라서 궤적이 직선 몇 토막으로 보인다 → 검수용 `__MMO.dtCap = 1/60` (한 프레임 = 1/60 s), 찍는 동안 `__MMO.hold = true` (스크린샷 한 장에 몇 프레임이 지나가 접점을 놓쳤다).
- `tests/field-feel.test.mjs` — 표 일치 · 접점보다 먼저 안 나옴 · 둘 다 멈춤 · 히트스톱 중 휘두름 시계 정지 · 2타 시각 · 늦은 답은 바로 · 움직임 줄이기 · `mmo.html` 배선. 돌연변이 4종(예약 무시 · 대상 안 멈춤 · 시계 안 멈춤 · 접점 무시)이 모두 실패함을 확인.

## 3. 남은 것

- 대검 궤적은 위에서 보면 넓다 — 솔로와 같은 리본이라 바꾸려면 솔로까지 같이 본다.
- 완벽 회피 연출(솔로의 잔상·슬로모)은 필드에 아직 없다 — 온라인은 서버가 회피를 판정한 뒤에야 알 수 있어 «예측 연출» 을 정해야 한다.
- 다른 플레이어 궤적·불꽃은 일부러 뺐다 (중요도 계층 — v10 Significance).
