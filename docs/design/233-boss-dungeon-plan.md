## 16. 정지 보스 다섯의 기술표 (2026-10-14, 디렉터 «지피티가 한계라 지금 진행이 안돼» — GPT 몫을 대신)

`docs/gpt/2026-10-13-bosses-all.md` §2.1 이 GPT 에게 맡긴 «정지 모델 다섯에 기술표형 AI» 를 `server/field-boss-kit.cjs` `KITS` 에 넣었다. 몸에 뼈·클립이 없으므로 **몸은 그대로, 판정·준비 동작(windup)·가슴 빛·낙뢰·고리만** — `js/mmo/kit-motion.js` 는 클립이 없으면 `play()` 가 null 을 돌려 주고 나머지는 그대로 그린다. `world3d.html` 은 그동안 `gl.animations.length` 가 0 이면 KIT 을 안 붙였는데, 이제 `KITS` 에 있으면 클립이 없어도 붙인다. 서버 `field.cjs` 는 원래부터 모든 보스에 `KIT.setup/tick/view` 를 부르므로 **Render 재배포만 되면 온라인도 같은 박자**.

새 규칙 둘 (`field-boss-kit.cjs`): `fixed: true` 는 자리도 방향도 바꾸지 않는 보스(탑·산) — 판정은 전부 «대상 자리»(atTarget) 또는 «둘레 고리»(`shape:'ring'`, inner 안쪽은 안전). `guard` 는 에이지스의 보이지 않는 벽 — `hitMul(o, p, now)` 를 서버 `hit()` 과 혼자 연습 `strike()` 가 같이 부른다.
