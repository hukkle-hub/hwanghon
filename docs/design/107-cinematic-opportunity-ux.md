# 107 — 시네마틱 기회 UX v06 · 처형/카운터 후속 입력 (2026-09-26)

기준: `e6280d554362793d5e7408c608958bd010dfb3ab` + GPT 전투 피드백 HUD v05.

## 문제

전투가 영화처럼 보이기 시작했지만, 자세 붕괴 순간에 화면 하단 중앙의 큰 `F · 처형` 사각 버튼이 튀어나오고 카운터 후속 입력은 별도 원형 버튼이 강하게 맥동했다. 둘 다 기능은 맞지만 **전투 장면 위에 개발용 상호작용 UI가 얹힌 인상**이 남았다.

## 변경

### 1. 처형 = 월드 공간 기회 표식

- 기존 `#exp-interact` DOM과 클릭/키보드 계약은 그대로 유지한다.
- 탐색 중에는 기존 조사 버튼으로 동작한다.
- 보스가 처형 가능하고 사거리 안이면 `.is-exec`가 붙고 **보스 core 위 월드 좌표를 현재 전투 카메라로 투영**한다.
- 화면 가장자리로 튀지 않도록 PC/모바일 별 clamp를 둔다.
- PC는 작은 `F` 코어, 모바일은 탭을 뜻하는 `✦` 코어를 보여 준다.
- `F · 처형` 텍스트 상자를 없애고 `처형` 한 단어만 보스 옆에 남긴다.
- L2/L3 시네마틱 동안은 표식을 숨긴다.

판정은 그대로다. 실제 처형 가능 여부는 기존 `executeReady()`와 `battle.input('execute')`만 사용한다.

### 2. 카운터 후속 기회 = 같은 시각 언어

- `부위 파괴`/`붙잡기` 후속 버튼을 `파괴`/`제압`으로 짧게 정리한다.
- 지속 시간은 원형 SVG 스트로크가 줄어드는 방식으로 보인다.
- 매번 `탭!` 문장을 띄우지 않고 종류별 첫 1회만 튜토리얼 문구를 보여 준다.
- 입력은 기존 `openingIn()` / `G` / 터치 버튼 계약을 그대로 쓴다.

## 완료 조건

- PC 1280×720 / 모바일 가로 915×412에서 처형 표식이 보스 근처에 있으면서 화면 밖으로 나가지 않는다.
- 탐색 조사 버튼은 기존 동작을 유지한다.
- 처형 가능 여부, 실행 입력, 카운터 후속 입력의 combat 수치/판정 코드는 변경하지 않는다.
- 후속 기회 가이드는 같은 종류에서 반복해서 화면 중앙을 가리지 않는다.
- L2/L3 동안 처형 표식이 카메라 연출을 가리지 않는다.
