# 아인 — 기본 몸체와 교체 의상 분리 제작

2026-09-20 사용자 전달사항 반영. 관련 작업: #97, docs/design/40-base-body.md, Claude 커밋 7f2ce0c.

## 확인된 문제

기존 ain_anim.glb는 얼굴·몸·코트·장갑·부츠가 합쳐진 메시다. 새 의상을 위에 얹는 방식은 교체 착장이 아니다. Claude의 ain_body.glb는 기존 골격/28개 클립을 사용하는 가봉용 몸체이며, 아인 얼굴이 없는 상태다. 이를 완성 캐릭터로 대체하거나 덮어쓰지 않는다.

## 제작 순서

1. 기존 full-ain.webp/face-ain.webp를 정체성 기준으로, 얼굴·목·손·발이 있는 기본 몸체 후보를 만든다. 작업용 불투명 스포츠 상의와 반바지만 착용한다. 무기·코트·장갑·부츠·목도리·장신구는 넣지 않는다.
2. 기본 몸체 후보를 1.68m, Y-up, 정면 +Z, 발바닥 y=0으로 정리한다. 기준 포즈와 관절 위치는 Claude의 실제 아인 리그에서 추출해 맞춘다. 이미지의 A포즈만 보고 기존 리그에 즉시 호환된다고 하지 않는다.
3. 얼굴/체형/손가락을 실제 GLB의 정면·옆·뒤 렌더에서 검수한 다음 기본 몸체를 확정한다. 확정 전 의복을 대량 생성하지 않는다.
4. 상의/하의/장갑/신발/장신구는 기본 몸체와 별도 메시/GLB로 제작한다. 마네킹·피부·머리·다른 의복이 포함된 생성 결과는 옷 파일로 납품하지 않는다.
5. 의복을 확정 몸체에 맞춰 리토폴로지/피팅하고 같은 스켈레톤으로 스킨 웨이트를 만든다. 얼굴/머리카락 분리는 필요 시 따로 하되, 목 경계를 먼저 확보한다.
6. 의복으로 덮이는 몸 영역의 마스크와 착장 슬롯을 통합한다. 팔꿈치·어깨·골반·무릎·목·손목 관통을 기존 공격/반격/회피 클립으로 검사한다.

## 파일 계약

### 1차 생성 실측 (아직 게임 합격 아님)

Hi3D 원본 다운로드 및 Blender 4방향 렌더 완료. 얼굴/목이 있는 스포츠 기본복 몸체다. 원본은 단일 메시 2,000,000삼각형, 8192 텍스처 2장, 59,859,312바이트다. 경량 정적 후보는 59,000삼각형, 높이 1.68m, 2048 PNG 2장, 6,240,920바이트. 원본과 후보는 아래 로컬 경로에 보존했다.

- `output/ain-modular-body/ain_base_source.glb`
- `output/ain-modular-body/candidate/ain_base_candidate.glb`
- `output/ain-modular-body/candidate/inspection/{front,rear,side,oblique}.png`

Git 공유용 검수 후보: `art/3d/base/ain_base_candidate.glb`, 실제 후보 렌더: `art/review/ain_modular/front.png`, 상태표: `art/review/ain_modular/candidate_report.json`. 런타임에는 연결하지 않았다.

주의: 경량화로 의복 주름과 피부 세부가 감소했다. 노멀 베이크/변형용 리토폴로지/손가락 검수/기존 스켈레톤 바인딩은 아직 안 됐다. 기본 스포츠복과 머리카락은 몸체와 한 메시이며, 교체용 외투/방어구는 별도로 만들어야 한다. 이 파일을 `ain_body.glb`로 바로 대체하지 않는다. 50종 모두 GLB 완성 또는 장비 교체 완료라고 표시하지 않는다.

- 원본/후보: output/ain-modular-body/ 아래. 기존 ain_body.glb와 ain_anim.glb는 보존.
- ain_base_source.glb: Hi3D 생성 원본, 품질/치수/리그 미승인.
- ain_base_candidate.glb: 몸체 정리 및 검수 후보. 기본 속옷은 교체 장비가 아닌 안전한 기본 레이어다.
- 의복: ain_outfit_<set>_upper.glb / lower.glb / hands.glb / shoes.glb. 장갑·신발은 좌우 노드를 구분.
- 생성 단계 GLB는 정적이며 리깅/애니메이션을 넣지 않는다. 통합 단계에서 동일 기준 골격을 사용한다. 기존 클립 이름만 같다고 호환으로 간주하지 않는다.
- 머리·목·손은 자동 생성만으로 원화와 동일하거나 해부학적으로 정상임을 보장하지 않는다. 검사에 실패하면 실패 항목을 기록하고 재시도 비용을 무한히 쓰지 않는다.

## 이번 실행과 예산

### 몸·속옷·머리카락 분리 요구 — 2026-09-21, 미완료

사용자는 기본 속옷까지 교체 가능한 완전 분리를 요구했다. 기존 생성 입력에서 스포츠복을 몸과 합쳐 만든 방식은 이 요구를 충족하지 않는다.

`split_ain_modules.py`로 색·연결 면·위치 기준의 4회 분리 시험을 했으나 **시각 검수 실패**다. 4개 메시와 개별 GLB, 공유 스켈레톤/28클립 보존은 확인했지만 이는 구조 검사일 뿐이다. v1/v3은 속옷 조각이 피부에 남고 v2/v4는 피부가 의상에 섞인다. 원본에 속옷 아래 피부와 머리카락 아래 두피가 없어 단순 추출로 온전한 몸이 되지 않는다.

실험 원본은 로컬 `output/ain-modular-body/separated-v1`~`separated-v4`에만 보존한다. **납품/런타임 자산으로 승격하지 않았다.** 이 스크립트는 실패 재현용이며 생산용으로 사용하면 안 된다. 후속 작업은 완전한 몸/두피 복원(기존 CC0 체형 활용 가능)과 얼굴 정체성 보존, 경계 루프 기반 의복 재단이 선행돼야 한다. 빈 몸이나 피부가 붙은 속옷을 분리 완료라고 표시하지 않는다. 추가 크레딧 사용 0.

동시 작업 `2512d51`을 병합하고 `docs/design/45-hair-handoff.md`도 확인했다. 최종 헤어는 별도 `_hair` 재질(피부 재질 공유 금지), 24관절 스킨, 머리를 숨겨도 남는 살색 두피를 갖춰야 한다. 현재 시험은 이 계약에 불합격이다. Claude가 기존 후보를 게임 `ain_body.glb`로 채택한 변경은 보존했으며, 실패 분리본으로 재교체하지 않았다.

### 확대 정밀 보정 — 2026-09-21

`art/3d/base/ain_modular_precision_candidate.glb`에 개선본을 별도 보관했다. 기존 후보/게임 기본 몸체는 그대로다. `art/review/ain_modular/precision/`에 얼굴·어깨·손·공격 확대 렌더와 수정 전 이미지를 함께 저장했다. 확대 이미지는 내보낸 GLB를 다시 읽어 렌더한 것이다.

가슴이 팔에 끌려 꺾이고 손목이 뾰족해지는 문제를 발견했다. 좌표 구간으로 수동 보정한 v6~v8은 다른 부위에 악영향이 있어 채택하지 않았다. 최종 검수 후보는 Blender bone heat 가중치, 머리/머리카락 Head 고정, 정점당 최대 4개 영향 정규화를 적용했다. 29,440개 연결 정점 중 자동 가중치 없는 22개는 폴백으로 연결했다. 이 작업은 리토폴로지 또는 손가락 리깅의 대체가 아니다.

28클립 × 5시점 = 140샘플 검사. 길이 1mm 초과 원본 에지의 변형 후 길이 비율을 측정했다. 각 샘플의 99백분위 중 최악은 6.618 → 1.512, 전체 최대는 83.896 → 17.595. 여전히 극단값이 있으므로 완전 합격이라고 표시하지 않는다. 충돌/피부 관통 검사가 아니며 개별 손가락, 팔꿈치 볼륨, 머리카락 끝의 구멍·덩어리감, 분리 의상은 남아 있다. Render 런타임 교체 없음, 추가 생성 크레딧 0.

재현: `bind_ain_modular.py -- OUTPUT WELDED_STATIC_CANDIDATE --auto-weights`, `inspect_ain_closeup.py -- EXPORTED_GLB OUTPUT`, `audit_ain_deformation.py -- EXPORTED_GLB REPORT_JSON`. 경량화 전 UV 경계 병합된 candidate-v2를 입력으로 사용해야 한다.
