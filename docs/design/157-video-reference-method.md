## 1. 영상을 «보는» 법 (내려받지 않는다)

유튜브는 파일로 받지 않고 브라우저에서 확인한다(다운로드는 디렉터 승인 대상).

1. 제목·길이·설명란: `document.querySelector('video').duration`, 설명란 펼치기.
2. **자막 전체**: 설명란의 «스크립트 표시» → 세그먼트(`시:분 + 문장`)를 모아 읽는다. 말로 설명하는 영상은 자막이 가장 빠르다.
3. **장면**: `video.currentTime = t` 로 옮기고 멈춘 뒤 영상 영역만 확대 캡처. 말하는 사람만 나오는 구간은 건너뛰고,
   자막에서 «여기 보시면»이 나오는 시각을 골라 찍는다.
4. 영상이 가리키는 원본(페이지·예제)이 있으면 **그 원본을 직접 연다** — 이번에는 영상 화면의 대부분이 «주문 사전» 페이지였다.
5. 로컬 mp4(핸드오프의 참고 영상 등): `cv2.VideoCapture` 로 프레임 수·fps를 재고 고르게 8장 뽑아 한 장으로 붙여 본다.
6. 참고 영상은 **아이디어만** 가져온다. 결과물·문구·그림을 복제하지 않는다(핸드오프 v7 지시와 같음).

## 2. 영상이 가르치는 것 — 요약

- 도구: Claude Code(또는 Codex) + **HyperFrames 스킬**(HTML/CSS/Three.js 애니메이션을 영상으로 렌더) + Node.js + FFmpeg.
  «주문 사전»은 88개 모션그래픽(자막·인트로·전환·지도/장소·3D·데이터·행사 등) 각각의 **주문 문장**을 준다.
- 주문은 «간단히»(한 문장)와 «자세히»가 있다. 영상의 핵심 주장: **자세히 쓸수록 덜 어긋난다**, 그중 가장 중요한 것은 **초 단위 장면 순서**,
  그리고 **하지 말 것(금지 조건)** 을 적어 두어야 두 번 만들지 않는다.
- 여러 장면은 «주문서에 담기»로 묶어 한 번에 렌더한다(5초 + 10초 → 15초 한 편).
- 공통 설정: 도구, 화면 비율(16:9 / 9:16 / 1:1), 브랜드 색, 길이(기본 4–6초, 늘리면 장면이 추가된다).

### «자세히» 주문서의 틀 (우리 것으로 옮겨 쓴다)

```
[무엇]      한 줄 — 무엇을 만드는지, 3D 면 무엇으로(우리는 UE)
[길이·크기] 전체 N초 · 해상도/비율 (우리: 모바일 가로 우선)
[장면 순서] 0~1.5초: … / 1.2~2.1초: … (겹쳐도 된다 - 겹침이 부드러움을 만든다)
[볼거리 한 컷] 이 연출에서 반드시 남아야 할 한 장면
[모양]      색·재질·선 굵기·글꼴
[움직임]    가속/감속, 카메라 각도(예: 바로 위 → 35°), 튀어오름 크기
[하지 말 것] 금지 조건 — 긴 문구, 과한 네온, 원본에 없는 것 …
```

## 3. 우리 게임에 쓸 만한 연출 (주문 사전 항목 중)

| 항목 | 요지 | 황혼의 서울에서 |
|---|---|---|
| 평면도 → 3D 세우기 (S08) | 위에서 본 평면도 선이 그려지고, 바닥색이 깔리고, 벽이 솟고, 카메라가 35°로 내려와 돌며 방 이름표 | **입장 연출의 뼈대** — 작전실 탁자 위 B-1 평면도에서 실제 쉘터로 (문서 158) |
| 층별 안내 3D (M06) | 층판이 벌어져 떠오르고 이름표, 강조 층이 빛남 | B-1 / B-2 층 선택, 던전 층 안내 |
| 명소 핀 투어 (M04) | 핀에서 핀으로 카메라가 옮겨 가며 카드가 튀어오름, 핀 사이 점선 | 쉘터 시설 7곳 핀(인력사무소·평가소…) |
| 지역 확대 + 동그라미 (M02) | 넓은 지도에서 한 곳으로 확대, 손그림 원과 이름표 | 스토리 화 시작: 서울 지도 → 이번 화 장소(강남·여의도·고흥…) |
| 찾아오는 길 경로 그리기 (M03) | 경로 선이 그려지며 이동 | 출격 셔터 → 던전 입구 이동 연출 |
| 3D 무대 오프닝 타이틀 (B19) | 어둠에서 조명이 하나씩 켜지고 제목이 떠오름 | 타이틀 화면 첫 1–2초(작전실 조명이 탁탁 켜진다) |
| 필름 빛 샘 전환 (B14) | 빛 덩어리가 번지며 장면 교체 | 스토리 카드 ↔ 전투 전환(호박색 빛) |

## 4. 우리 쪽 규칙

- **게임 본체의 연출은 UE 안에서** 만든다(카메라·Sequencer·UMG/HUD, v7 결정: HTML/WebGL 은 게임 본체에서 뺀다).
  HyperFrames 식 HTML 렌더는 **홍보 영상·예고편·SNS 클립**처럼 게임 밖 영상에만 쓴다(설치: Node.js + FFmpeg + HyperFrames 스킬 — 필요할 때 디렉터 승인 후).
- 게임 안 연출도 같은 «자세히» 틀로 먼저 쓴다: 문서에 초 단위 장면 순서와 금지 조건을 적고, 그 표를 코드(타임라인 상수)와 1:1 로 맞춘다.
  QA 는 그 시각마다 캡처해 시트로 붙인다(말로 «자연스럽다» 하지 않는다 — CLAUDE.md §1).
- 글자: 원문/디자인 시트에 없는 문구·슬로건을 새로 넣지 않는다(v7 «장문 텍스트 금지»).
