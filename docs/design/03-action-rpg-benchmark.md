# 황혼 — 액션 RPG 완성도 기준표 v0.1 (검은사막 · 붉은사막 · 마비노기 영웅전 · 아이온 1)

> 작성일 2026-09-16 · 목적: "그래픽은 낮아도 완성도는 높게". 참고작에서 완성도를 만드는 요소를 뽑아 우리 던전에 적용할 순서를 정한다.
> 조사 출처: 인벤 마영전 전투 조작 기사, 나무위키 마영전/시스템, Garmoth·BDFoundry 검은사막 전투 가이드, Fextralife 붉은사막 Combat/Bosses, Vindictus 위키 Break Off·Boss Fight Strategies, 아이온 클래식 인벤 던전 가이드, game-feel 자료(hit stop·screen shake·knockback).

## 1. 참고작에서 뽑은 규칙

### 마비노기 영웅전 (가장 가까운 모델)
- 일반 공격은 **4연타**, 빠르지만 약하다. **스매시(D)** 를 몇 타째에 넣느냐로 모션·피해가 달라진다: [S→D] [S→S→D] [S→S→S→D] [S→S→S→S→D].
- 회피는 방향 입력 + 무적 프레임(캐릭터별). 가드는 스태미나를 소모하고, **가드 성공 직후 스매시 = 카운터**.
- 스태미나는 달리기·스매시·회피·가드 모두 소모. "언제나 회피 한 번 분량은 남겨라".
- 잡기(인간 크기 몬스터), 보조무기로 둔화·부위 타격, **보스 부위 파괴**(부위별 숨은 HP, 파괴력 있는 공격이 유효), 스태거 스킬로 보스 패턴 끊기, 보스가 포효하는 순간이 반격 창.
- 카메라: 적을 향해 시점을 맞추는 **자동 대상**, 보스 락온 옵션, 줌 조절.

### 검은사막
- 콤보는 **후딜 캔슬**로 흐른다. 서 있는 시간을 줄이는 것이 곧 화력·생존.
- 방어 3종: **전방 가드 · 슈퍼아머 · 무적(i-frame)** 을 이어 붙여 CC 를 흘린다.
- CC 는 **경직·스턴·다운·띄우기·넉백·바운드** 로 층이 있고, CC 카운트 2 이상이면 5초 면역(무한 CC 방지).

### 붉은사막
- 콤보 문자열·타이밍·간격 중심. 보스 뒤로 **앞-우측 회피 → 2~3타** 가 기본 리듬.
- 가드·카운터를 제때 맞추면 반격이 열린다. 보스는 고유 기믹 + 높은 내구 + **스태거 게이지**(채우면 무너짐).
- 스태미나가 방어에도 든다(패치로 완화). 보스 리플레이·난이도 옵션.

### 아이온 1
- 액션은 아니지만 **연계 스킬(체인)** 이 UI 로 안내되고, 퀘스트가 **연속 퀘스트** 로 이어지며 마지막에 큰 보상.
- 던전은 "제한 시간 안에 구역 몬스터 처치 → 보스", 추가 목표 달성 시 버프/보스 디버프.

### 게임 필(공통)
- 히트스톱은 타격 세기에 비례(약공 2프레임, 마무리 1/4초). 화면 흔들림은 **타격 축 방향**. 파티클은 **타격 벡터 방향**으로 튄다.
- 피격 대상은 반드시 **반응**한다: 섬광 → 경직/넉백/다운. "맞았다"가 즉시 읽혀야 한다.
- 모든 피드백은 **동기화**(히트스톱 + 흔들림 + 파티클 + 소리가 같은 프레임).

## 2. 우리 던전과의 차이 (완성도 갭)

| 항목 | 참고작 | 지금 | 조치 |
|---|---|---|---|
| 콤보 | 4연타 + 스매시 마무리, 타수별 모션·피해 | 3연타 동일 모션 | **4연타 + 스매시(길게 누름), 타수별 배율·자세·히트스톱** |
| 피격 반응 | 경직·넉백·다운 층 | 보스 움찔만 | 잡몹에 **경직/넉백/다운**, 보스는 자세 게이지 → 격추 |
| 방어 | 가드·카운터·무적 회피 분리 | 공격 길게 = 방어(충돌) | **방어 전용 버튼**, 가드 성공 직후 스매시 = 반격 보너스 |
| 적 구성 | 잡몹 → 보스 | 보스만 | **짚 인형 3체**(마당) → 문 → 보스 |
| 보상 | 드랍·경험치·레벨·골드 | 정산 화면만 | **드랍 픽업·XP·레벨업·골드**, 저장 |
| 퀘스트 | NPC 대사 → 목표 추적 | 안내 줄 | **마태오 대화 → 목표 추적 HUD** |
| 죽음 | 사망 → 재도전 | 체력 자동 회복 | **진짜 사망 → 문 앞 재도전** |
| 보스 HUD | 스태거 게이지 | 마름모 5개 | **격추 게이지 바**, N HIT 콤보 카운터 |
| 카메라 | 락온·자동 대상 | 플레이어 추적 | 전투 중 **플레이어·보스 중간점 추적**(둘 다 화면에) |

## 3. 적용 순서
1. 전투 규칙: 4연타 + 스매시, 방어 버튼 분리, 피격 반응 층, 진짜 사망, 플레이어 상태 유지(탐색↔보스)
2. 잡몹 3체 + 드랍·XP·레벨·골드·저장 + HUD(XP·골드·퀘스트 추적·격추 게이지·콤보 카운터)
3. 마태오 대화·퀘스트 추적, 사망/재도전, 전투 카메라
4. 다음 던전(갈대습지)으로 규칙 확장
