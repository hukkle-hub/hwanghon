# 황혼 — 등급 시스템(레벨 대체) 검수 v0.1

> 작성일 2026-09-17 · 디렉터 지시: "레벨이 아니라 등급으로 표기. A 부터 SS 까지. 카운터 등급·부위 파괴 등급 같은 기술 등급이 파티에 영향을 준다." · 근거: 마비노기 영웅전 「전투 등급·오라클 티어」, 몬스터 헌터 「헌터 랭크」, 블소 「무공 숙련」, 검은사막 「생활 등급(채집·제작 숙련: 초보→아마추어→숙련→전문가→장인→명장→도인)」.

## 0. 규칙
| 항목 | 규칙 |
|---|---|
| 요원 등급 | **A → A+ → S → S+ → SS** (5단계). 누적 경험치로 오른다: 0 / 1,500 / 5,000 / 12,000 / 25,000. 레벨 숫자는 화면에서 사라지고 내부 저장만 유지 |
| 기술 등급 5종 | **C → B → A → S → SS**. 카운터(카운터·퍼펙트 횟수·성공률), 부위 파괴(파괴 수·파괴율), 정제(채집·소모품 제작·회복약), 드랍(전리품·희귀 드랍), 제작(강화 성공·제작·수리). 전부 실제 전투·대장간 기록(`save.stats`)에서 계산 |
| 파티 효과 | 파티원(플레이어 + 동행 NPC 시트 등급)의 각 기술 **최고 등급**이 반영. 카운터 → 판정 +0.02~0.09초 · 부위 파괴 → 파괴 부위 피해 ×1.05~1.25 · 정제 → 클리어 재료 +10~50% · 드랍 → 행운 +0.05~0.25 · 제작 → 강화 성공률 +1~6%p, 수리비 −5~25% |
| NPC 표기 | 시트의 레벨(24~32)을 요원 등급으로 환산(≥34 S+, ≥30 S, ≥26 A+, 그 외 A) |

가정: "A 부터 SS" 를 요원 등급 범위로 읽었다. 기술 등급은 시트의 NPC 값(B·A·S)을 살리기 위해 C 부터 시작한다. 새 요원은 요원 A · 기술 C 에서 출발한다.
