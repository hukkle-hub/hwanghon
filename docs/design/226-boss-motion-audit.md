# 226 · 보스 동작 감사 — «사람같이» 되는가

디렉터: «진행해.. 확대해서 이상한건 다 잡고 스킬 모션이 정상적으로 사람같이 구현되는가도 보고».

## 1. 재는 도구 — `tools/3d/motion-audit.mjs`

클립마다 사람 관절로 못 하는 것을 잰다:

| 항목 | 기준 |
|---|---|
| 역관절 | 엉덩이-발목(어깨-손목) 선에서 무릎(팔꿈치)이 나온 쪽이 그 마디의 앞(뒤)과 120° 넘게 어긋남. 값 = 그때 꺾인 각 |
| 경첩 밖 | 같은 각이 50~120° (옆으로 꺾임) |
| 비틀림 | 아래팔 100°·손 80°·종아리 40° 넘게 뼈 축으로 돎 |
| 목·척추 | 가슴 대비 머리 좌우 80°·숙임 70° · 골반 대비 가슴 비틀기 70° |
| 튐 | 한 프레임(1/30 s)에 60° 넘게 도는 뼈 |
| 발 묻힘 | 발 정점(1위 뼈가 발·발끝)이 쉬는 자세 바닥보다 4 cm 넘게 아래 |

`tools/3d/clip-sheet.html?…&bones=1` — 몸을 비치게 하고 뼈를 선으로(왼쪽 빨강·오른쪽 파랑). 무릎 방향은 이걸로 보면 바로 보인다.

### 지표부터 의심했다 (세 번 틀렸다)

1. **경첩 축을 일반 클립에서 배우기** → 그 클립들은 팔꿈치를 **아예 안 굽혔다**(아래팔 0°). 축이 0 이 돼 전부 «경첩 밖 90°». → 해부학으로(꺾으면 손은 앞, 발은 뒤) 정하고, 다시 «마디 꼭짓점의 방향» 이라는 기하 판정으로 바꿨다. 일반 클립이 전부 깨끗한 것으로 검증.
2. **발 묻힘을 뼈 높이로** → 쉬는 자세 기준이 어긋나 걷기도 20 cm. → 발 정점으로.
3. **AnimationMixer 로 표본** → 믹서는 값이 지난번과 같으면 뼈에 다시 쓰지 않는다. 표본마다 쉬는 자세로 되돌리면 클립이 멈춘 구간의 뼈가 쉬는 자세로 남아 «79° 튐» 을 지어냈고, 고치는 도구가 거기에 쉬는 자세를 써 넣을 뻔했다(한 번 써 넣었다가 원본에서 다시 했다).
   → `tools/3d/pose-eval.mjs` — 트랙마다 보간기를 직접 불러 넣는다. 늘어남 감사(문서 225)도 이걸로 바꿨다.

## 3. 고친 방법

### `tools/3d/clip-joint-fix.mjs` — GLB 안 애니메이션 출력만 같은 자리·같은 크기로 덮어씀

1. **역무릎**: 엉덩이·발목 자리는 그대로, 엉덩이-발목 선 뒤로 나간 무릎을 발끝 쪽으로 **거울 대칭**(두 뼈 길이 그대로). 거울은 무릎이 선 위면 항등이라 프레임 사이가 이어진다. 종아리 비틀림(허벅지 기준)은 원래대로 되돌린다 — 안 그러면 최소 회전 두 번이 70° 를 얹어 무릎이 꼬였다. 발 방향도 원래대로.
2. **바닥**: 손·쥔 소품을 뺀 몸 정점이 쉬는 자세 바닥보다 내려가면 그만큼 골반을 올린다(올리기만 — 뜀은 그대로).
3. **시작 결함**: 처음 1~3 키만 튀면 그 다음 키로 채움.
4. **이음새**: 큰 걸음이 한두 키 이어지고 앞뒤는 작은 곳 = 끊김. 끊긴 만큼의 회전을 **이음새 앞 0.12 s 동안** 0 → 1 로 얹어 이음새 키에서 뒤 테이크에 닿게 한다.
   처음엔 이음새 «뒤» 에서 섞었다가 클레이브 안무(`CLAVE_CHOREOGRAPHY`)를 보니 **이음새가 곧 타격 순간**(폭풍 1.6·2.567·3.6 s 가 판정)이라 타격 자세가 0.2 s 늦게 왔다 → 앞에서 섞는다. 순간이동이 빠른 휘두름이 됐다.

`tools/3d/jeong-clips.mjs`(정 장관 전용 동작 생성기):
- 칼날 방향이 키 사이에서 120° 넘게 바뀌면 **아래팔이 도는 회전을 칼날에도 같이 얹고** 남는 차이만 보간 — 칼이 손목과 함께 휘돈다.
- 팔꿈치: 위팔을 자기 축 둘레로만 돌려 경첩을 굽힘 평면에, 아래팔은 다시 겨눔(뼈 방향 그대로, 비틀림만). 얼굴 감사 그대로 통과.
- 등 뒤 베기: 가슴 방향(−175°)은 그대로, 척추 70° · 나머지는 골반째(yaw −80 → −105).
- 굽고 나면 `skin-rebind` → `clip-joint-fix` 를 차례로 부른다.

`js/mmo/boss-motion.js`: 클레이브 골반 내림을 대기 0.35·내려찍기 0.2 배로 줄이던 보정을 걷었다(클립 자체를 바닥에 맞췄다).

### 해 보고 버린 것

| 시도 | 왜 버렸나 |
|---|---|
| 팔꿈치 비틀기 맞춤(괴물 팔) | 위팔 비틀기가 ±180° 근처에서 부호가 뒤집혀 손이 한 키 163° 튐 — 기본 끔(`--elbow`) |
| 손목 비틀림을 아래팔로 옮기기 | 매 프레임 재면 ±180°에서 140° 튐, 트랙째 이어 붙이면 앞에서 한 바퀴 돈 손 때문에 아래팔이 오래 80° 꼬임 — 기본 끔(`--wrist`) |

- 섀도우 팽 연격·개화 팔꿈치가 20~37° 뒤로, 실험체 09호 왼팔꿈치가 옆으로 — 휘두르는 괴물 팔. 뼈를 그려 보면 «괴물의 팔» 로 읽히고, 고치려던 비틀기는 튐을 만들었다.
