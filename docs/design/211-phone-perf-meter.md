# 211 · 휴대폰 무게 표시 (`?debug=1`, 2D·3D 필드)

디렉터 폰(안드로이드)으로 실제 프레임을 재려고 화면 안 표시를 만들었다. `js/mmo/perf-meter.js` 하나를 2D(`mmo.html`)·3D(`world3d.html`)가 같이 쓴다.

| 줄 | 뜻 |
|---|---|
| `fps 58 · 느린 1% 24ms` | 지난 1초 프레임 수 · 최근 300프레임 중 가장 느린 1% 의 프레임 시간 (끊김) |
| `콜 360 · 삼각형 509k` | **한 프레임 전체 합** — 그림자 패스·장면·화면 합성까지 |
| `픽셀비 · LOD · 몬스터 · 사람` | 해상도 배율 · 가벼운 모델 여부 · 그려지는 몬스터·사람 수 |
| `30초 평균 · 가장 낮은 1초` | 30초마다 갱신 — 이 줄을 찍어 보내면 된다 |

- **옛 2D 표시는 틀렸다:** `renderer.info` 는 그릴 때마다 비워지는데, 화면 합성(bloom) 뒤에 읽어 마지막 패스(호출 1 · 삼각형 0k)만 보였다. 이제 틱 처음에 비우고(`autoReset` 끔) 끝에 읽는다. 대전 2D 호출 94 · 삼각형 44.7만, 3D 360 · 50.9만 (`__MMO.info()`/`__W3D.info()` 와 ±4 — 합성 패스 몫).
- 자리: 2D 는 미니맵 아래, 3D 는 왼쪽 위 상태 글자 아래 (Pixel 7 가로 — 미니맵·조이스틱·안내 띠와 안 겹침, 터치 통과). 그림 `.node-shots/w3d/dbg-sheet.png`.
- 시험 `tests/perf-meter.test.mjs` — 한 프레임 세 번 그려도 합 · 30초 요약 (자동 비우기를 켜 두면 실패하는 것을 봤다).

## 폰에서 재는 법

1. 3D: `https://hukkle-hub.github.io/hwanghon/world3d.html?zone=daejeon&debug=1`
2. 2D: `https://hukkle-hub.github.io/hwanghon/mmo.html?zone=daejeon&debug=1`
3. 사냥터(중앙로 폐허 거리 등)로 걸어가 몬스터 근처에서 30초 넘게 — 왼쪽 위 «30초 평균» 줄이 나오면 화면을 찍는다. 가로·세로 둘 다면 더 좋다.
