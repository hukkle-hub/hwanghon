# 운영 도구 — 신고 처리 · 제재 · 서버 공지

「운영 도구 화면 만들어.」

문서 28 §5 에 「쉘터에는 없다」고 적어 둔 마지막 항목이다. 서버에는
`adminState` · `moderate` · `announcement` 가 **처음부터 있었고**,
`party.html` 의 개발용 대화상자에 `<pre>` 로 JSON 을 뿜는 화면이 하나 있었다.
그걸 제대로 된 화면으로 세웠다.

## 1. `admin.html` — 3열

```
┌ 운영 도구 ───────────────────── 접속 2/100 · 새로 고침 ┐
├ 신고 ────────┬ 처리 ───────────────┬ 서버 공지 ────────┤
│ 미처리|처리됨│ 문제요원   (플레이어 id)│ [240자] 게시·비우기│
│ |전체        │ 캐릭터로 찾기 [    ][찾기]├ 기록 ────────────┤
│ #1 문제요원  │ 현재 제재 채팅 1시간 남음│ 운영 | 거래       │
│    욕설 반복 │ 신고 내용 · 증거(대화)  │ 06:53 운영자      │
│    미처리    │ 기간 [1시간] 사유 [   ]│  moderate:mute →  │
│              │ [채팅 제한][접속 제한] │  문제요원         │
│              │ [제재 해제][검토 완료] │                   │
└ 로비 · 인력 사무소 · 쉘터 · 파티 모집 · 운영 도구 · 창고 ──┘
```

- **신고**: 미처리 / 처리됨 / 전체. 줄에 대상 이름·사유·시각·상태.
- **처리**: 고른 신고의 내용과 **증거로 붙은 최근 대화**, 대상의 **현재 제재**,
  그리고 기간(10분~30일)·사유를 정해 거는 네 단추.
- **캐릭터로 찾기**: 신고가 없는 사람도 이름으로 불러 제재·해제할 수 있다.
- **서버 공지**: 접속한 모두에게 한 번. 현재 공지를 다시 띄워 고칠 수 있다.
- **기록**: 운영 조작 50건 · 거래 50건.

권한이 없으면 **「권한 없음」 한 장**만 보여 준다 — 서버가 어차피 거절하지만
못 누르는 단추를 늘어놓지 않는다. 안내에 **자기 플레이어 id** 를 같이 찍어
준다 (그걸 `ADMIN_IDS` 에 넣어야 하므로).

쉘터 상단의 「운영 도구」 단추도 **권한이 있을 때만** 나타난다.

## 2. 서버 — 세 가지를 고쳤다

화면을 붙이면서 서버 쪽 결함이 세 개 드러났다.

### 2.1 운영 화면인데 UUID 만 보였다

`adminState` 가 테이블 행을 그대로 보냈다. `7bc75877-8d05-…` 를 보고
누구를 제재할지 정할 수는 없다. 이름과 **대상의 현재 제재**를 함께 싣는다.

```js
const named=pid=>{try{return store.get(pid).name;}catch{return '알 수 없음';}};
reports: … .map(r=>({...r,reporterName:named(r.reporter),targetName:named(r.target),
                     sanction:sanctionOf(r.target)})),
audit:   … .map(r=>({...r,actorName:named(r.actor),
                     targetName:/^[0-9a-f-]{36}$/.test(r.target||'')?named(r.target):null})),
announcement: <현재 공지>
```

### 2.2 제재 기간 상한이 **999분** 이었다

`moderate` 가 물품 수량 검사기(`quantity`, 1~999)를 그대로 쓰고 있었다.
**하루짜리 정지도 걸 수 없었다.** 같은 이유로 **신고 번호 1000번부터는
«검토 완료» 가 안 됐다.** 둘 다 제 축에 맞는 검사로 바꿨다 — 기간은
1분~1년, 신고 번호는 안전 정수.

### 2.3 이름으로 사람을 찾을 길이 없었다

`adminFind {name}` 를 새로 뚫었다. 신고에 안 걸린 사람을 제재하거나,
제재를 해제할 때 필요하다. 운영자만 쓸 수 있다.

## 3. 검수

`node tools/admin-scenario.mjs` — 서버를 이 프로세스에서 띄우고 운영자 ·
신고자 · 대상 **세 사람을 실제로 붙여** 끝까지 밟는다. `MOBILE=port|land`
도 된다.

```
신고 접수 1건                       ← 쉘터의 «신고» 단추로 진짜 넣었다
비운영자 안내  권한이 필요합니다… 내 id 74f…
비운영자 공지 잠김?  true
신고 목록      미처리 1 / 1 | #1 문제요원 욕설 반복 · 09.20 06:55 미처리
채팅 제한 걸림?  true | 사유 욕설 반복 | 남은 분 60      ← store.sanction 으로 확인
화면 표시      현재 제재 채팅 제한 1시간 남음 욕설 반복
```

**화면 글자가 아니라 서버 상태로** 확인한다 — 제재는 `store.sanction`,
신고 처리는 `reports.status`, 공지는 `meta` 테이블.

`tests/admin-tools.test.cjs` 6개 추가 (**165/165**):
권한 없는 계정은 네 명령 전부 거절 · 목록이 이름과 제재를 준다 ·
제재가 실제로 걸리고 **제한된 계정이 정말로 말을 못 한다** · 1440분이 통하고
600000분은 거절된다 · 1200번 신고도 처리된다 · 이름 조회 · 공지 전파.

전 21화면 952px, 휴대폰 가로·세로 확인.

## 4. 쓰려면

**지금 이 화면은 아무에게도 안 보인다.** `render.yaml` 에 `ADMIN_IDS` 가
없기 때문이다. 운영자로 쓸 계정으로 접속해 `admin.html` 을 열면 안내에
자기 id 가 찍힌다. 그 값을 Render 환경변수에 넣는다.

```
ADMIN_IDS = <플레이어 id>          # 쉼표로 여러 명
```

`server/` 가 또 바뀌었으므로 **재배포 대기 목록에 한 줄 더 선다**
(`docs/DEPLOY-PENDING.md`).
