# 106 — 전투 피드백 HUD 정리 v05 (2026-09-26)

기준: GPT HUD v04 적용본.

## 목적

전투 화면에서 가장 큰 프로토타입 느낌인 **큰 피해 숫자·중앙 배너·상태 카드의 경쟁**을 줄인다. 게임 판정/피해/입력은 바꾸지 않고 DOM 표현만 정리한다.

## 규칙

- 일반 피해 숫자 16px / 0.62초, 모바일 13px.
- 치명타·카운터·피격·흘림만 우선순위가 높다.
- 동시에 보이는 피해 숫자는 PC 9개, 모바일 6개로 제한. 중요한 숫자는 먼저 보존한다.
- 카운터 배너는 58px 대형 숫자 대신 32px 짧은 타이포그래피. 중앙 시야를 덜 가린다.
- 콤보는 우측 중앙에 숫자 중심으로 축소.
- 상태 이상은 박스 대신 얇은 정보선.
- L1 중 일반 숫자/콤보는 45%로 뒤로 물리고, L2/L3에서는 피해 숫자를 숨긴다.
- 보스명/PHASE가 수치보다 먼저 읽히도록 자간과 위계를 조정한다.

## 금지

`js/game3d.js`, `combat.js`, 피해량, 판정 시간, 이동 거리, 회피 무적시간은 변경하지 않는다.
