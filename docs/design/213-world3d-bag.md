# 213 · 3D 필드 가방 · 상점 · 창고

2D 필드 가방(문서 198)을 `js/mmo/field-bag-ui.js` 모듈로 옮겨 3D(`world3d.html`)에 붙였다. 서버(`server/field-bag.cjs`)는 그대로 — 가방은 서버 프로필(items · equipment · vault · gold)을 보여 주고, 바꾸는 건 `fieldBag {op, item, quantity}`.

- 단추: 오른쪽 위 미니맵 왼쪽 «가방» 64 px (PC: I · B, Esc 닫기). 안전 지대에 들어서면 «가방 / 상점» 으로 바뀌고 한 번 알린다.
- 탭: 장비(착용 칸 7 + 가방) · 소모품 · 재료 · 상점 · 창고. 장착·해제·회복약은 어디서나, 사기·팔기·창고는 **안전 지대(마을·쉼터)에서만** — 서버와 같은 `js/mmo/safe-zones.js`. 거점 마을은 길드가 빼앗기 전엔 닫혀 있다(대전역 마을 = 보스 점령 → 상점 닫힘, 수원 «길잡이 쉼터» = 열림).
- 3D 는 거점 주인(`fieldJoined.hub` · `hubState`)을 따로 기억한다. 서버가 아직 안 보내면 보스 차지로 본다.
- 접속 답보다 **먼저** 가방을 만든다 — 입장 때 오는 profile·답을 받게 (3D 몬스터에서 한 번 밟은 순서 문제).
- 혼자 연습에는 가방이 없다(«온라인에 들어가면 서버 가방이 열린다»).
- 장착은 서버 능력치에만 반영된다 — **3D 영웅 겉모습은 아직 프로필 장비를 안 따른다**(다음 일).
- 세로 화면: 지역 이름 띠를 40% 높이로 올렸다(아래쪽 스킬 단추와 겹쳤다).

확인 (서버를 한 프로세스에서 띄움, Pixel 7 가로·세로, 수원 길잡이 쉼터): 안전 지대 인식 · 상점 목록 · 회복약 사기 5,000 → 4,880 G · 소모품 탭에 회복약 1 · 회복약 단추 «1» · 판 크기 782×398 / 394×782 (화면 안).
그림 `.node-shots/w3d/bag-shop-land.png` · `bag-use-port.png`. 시험 `tests/world3d-bag.test.mjs` — 가방이 보내는 명령이 서버에 다 있는지(이름을 틀어 실패 확인) · 접속 전 생성 · 안전 지대 규칙.
