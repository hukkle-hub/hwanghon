# 황혼 — 4단계(퀘스트·스토리) 검수: 실제 게임과 비교 v0.1

> 작성일 2026-09-17 · 근거: 마비노기 영웅전 스토리 진행(오라클 대사창·전투 후 귀환 대사·보상 수령), 블레이드앤소울 에픽 퀘스트(컷신 → 전투 → 후일담, 대사 건너뛰기), 검은사막 흑정령 안내(다음 목표 표시), 아이온 캠페인(장 구성·재생 로그). 디렉터 지시: 잡몹 없음, 보스만 잡는다.

## 0. 이번 단계에서 만든 것
| 항목 | 내용 |
|---|---|
| 진행 데이터 | `js/story.js` — 장 4개(프롤로그·1장 훈련장·2장 갈대습지·3장 예고), 의뢰 상태 4단계(잠김/수행 가능/완료·보수 미수령/보수 수령 완료), 상태는 `save.js` flags |
| 대사 오버레이 | 초상화(마태오는 사무실 원화에서 잘라 냄)·이름·직함·본문, 탭/스페이스로 진행, 건너뛰기. 지문(narr)·문서(record) 스타일 분리 |
| 흐름 | 로비 첫 방문 프롤로그 → 의뢰 「출격」·사무실 던전 카드 첫 출격 시 마태오 브리핑 → 던전 입장 플라이오버 컷신(보스 자리에서 플레이어 뒤로) + 초상화 대사 → 격파 컷신(무너지는 보스 앞으로 카메라) → 정산 → 사무실 후일담(정찰대의 기록 유무 분기) → 의뢰 보수 수령(골드·경험치·재료 실제 지급) → 3장 예고 |
| 이야기 화면 | `story.html` — 장 카드(상태)와 대사 로그, 다시 보기 |
| 잡몹 제거 | 두 던전 모두 잡몹·문 잠금 삭제. 문은 처음부터 열려 있고 보스 경험치 상향(600/1,500) |
| 낫 파지 | 대기·걷기: 낫을 오른쪽 옆에 곧게 세우고 자루 끝을 땅에, 오른손이 허벅지 높이에서 자루를 감쌈, 왼팔은 내림(디렉터 시트 2/7 기준). 자유로운 팔이 수평으로 뜨던 리타겟 오류 수정(`relax_left`) |

## 1. 참고작의 규칙
| 항목 | 마영전 | 블소 | 검은사막 | 아이온 |
|---|---|---|---|---|
| 대사 형식 | 초상화 + 이름 + 본문, 클릭 진행 | 컷신·대사창, ESC 건너뛰기 | 흑정령 안내창 | 대사창 + 캠페인 로그 |
| 전투 앞뒤 | 전투 전 브리핑 → 전투 후 귀환 대사 | 에픽: 컷신 → 전투 → 후일담 | 목표 자동 안내 | 장 단위 |
| 보상 | 전투 보상 + 스토리 보상 별도 수령 | 퀘스트 완료 시 수령 | 완료 즉시 | NPC 에게 보고 후 수령 |
| 다시 보기 | 스토리 다시 보기 | 회상 | — | 캠페인 로그 |

## 2. 우리 구현과 비교해 찾은 문제 → 조치
| # | 문제 | 참고작 | 조치 |
|---|---|---|---|
| 1 | 던전에 들어가면 바로 조작 — 어디인지, 왜 왔는지 모른다 | 블소 컷신, 마영전 인트로 | 입장 플라이오버(보스 자리 → 플레이어) + 장소 자막 + 마태오/아인 대사(초상화). 탭으로 건너뛰기 |
| 2 | 의뢰 보수 18,000 골드가 표시만 되고 받을 수 없었다 | 마영전·아이온 NPC 보고 후 수령 | 사무실 의뢰 정보에 「보수 수령」, 골드·경험치·재료 실제 지급, 중복 수령 불가, 상태 칩 |
| 3 | 클리어 후 아무 반응이 없다 | 마영전 귀환 대사 | 사무실 후일담. 정찰대의 기록을 가져왔으면 기록 본문 공개 + 다음 의뢰 예고, 못 가져왔으면 다시 가라는 분기 |
| 4 | 대사가 텍스트만 | 초상화 대사창 | 초상화·직함·문서 스타일. 던전 내 대사창에도 초상화 |
| 5 | 이야기를 다시 볼 곳이 없다 | 아이온 캠페인 로그 | `story.html` 장 카드 + 대사 로그 + 다시 보기 |
| 6 | 잡몹 구간이 보스 사냥의 흐름을 끊음 | 몬헌·마영전 보스전 중심 | 잡몹 삭제, 문 개방, 채집·기록만 남김 |
