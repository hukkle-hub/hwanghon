# 108 — 시네마틱 락온·부위 조준 UX v07 (2026-09-26)

## 목적

전투 화면 우측의 `T · 락온 켜짐`, `조준 · 머리 / 내구도 ...` 같은 개발용 텍스트 알약을 제거한다. 3D `lockRing`이 실제 목표 부위를 직접 가리키고, DOM HUD는 현재 선택 부위와 락온 상태만 최소 정보로 보조한다.

## 규칙

- 락온 위치 자체는 기존 Three.js `lockRing`을 유지한다. 게임 판정이나 타겟 선택 규칙은 바꾸지 않는다.
- `target-cycle`은 보스바 아래의 얇은 한 줄로 이동. `부위명 + 내구도%`만 표시한다.
- `lockon`은 우상단의 작은 원형 상태 아이콘으로 축소. PC 키 `T`는 작은 힌트만 남긴다. 모바일에는 키 문자를 숨긴다.
- 락온 OFF에서는 조준 정보의 채도/불투명도만 낮춘다. 선택 부위는 여전히 탭/키로 바꿀 수 있다.
- L1/L2/L3 시네마틱 순간에는 조준/락온 DOM을 숨긴다. 실제 `lockRing`도 기존 `cine` 조건으로 숨는다.
- 모바일은 기존 `html.mobile` 규칙보다 높은 specificity를 사용한다. `.cinema-hud-v1 html.mobile ...` 형태는 금지한다.

## 모바일 핫픽스 병합

동시에 v05 검수에서 발견한 두 가지를 수정한다.

1. 안내 줄: `html.mobile .cinema-hud-v1 .guide`로 specificity를 높여 화면 하단 5px 부근에 고정.
2. 카운터 배너: 모바일 `top:24%` → `12%`, 숫자 24px → 22px. 보스 핵과 겹치지 않게 한다.
