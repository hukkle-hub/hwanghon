# 224 · 바닥 예고를 없애고 준비 동작으로

디렉터: «게임내 예고를 알리는 표시같은 건 다 지워. 의미 없어. 다만 그 스킬을 쓸때 준비 동작을 넣어줘».

## 0. 무엇을 지웠나 (3D 필드 `world3d.html`)

| 대상 | 지운 표시 | 어디서 |
|---|---|---|
| 클레이브 | 바닥 부채꼴·원·직선 + 테두리, 반격창의 청록 바닥·청록 손빛·청록 궤적 | `setupBossMotion(..., { telegraph: false })` |
| 섀도우 팽 · 실험체 09호 · 정 장관 (기술표형) | 바닥 도형 전부, 정 장관 세 줄, 실험체 09호의 «대상 자리 원»(낙뢰 1.2 초 전) | `kit-motion.js` 에서 도형 자체를 만들지 않는다 |
| 2급 지배형 | 바닥 붉은 원·부채꼴 | `setupDominator(..., { telegraph: false })` |
| 필드 몬스터 | 발밑 붉은 고리(공격 600 ms 전), 철갑형 반격 노랑·청록 고리 | `createMobView({ ..., telegraph: false })` |
| 보스 발밑 기운 | «예고가 뜨면 물러나던» 동작 — 늘 같은 세기 | `boss-stage.js` |

남긴 것은 **공격 그 자체**다: 판정 순간의 번개(낙뢰), 충격파 고리, 불꽃·먼지, 반격 성공 섬광, 하늘이 어두워지는 방전 폭우.
기술표형 보스의 가슴 균열 빛은 몸의 일부라 준비 동작과 함께 밝아지게 남겼다(바닥·허공에 그리는 표시가 아니다).
판정·박자·반격창은 서버 그대로이고, 박자는 화면 밖에서 계속 센다(`telling` · `warnSeq` · `warnBeat`) — 준비 동작이 시작될 때 나는 기합음이 이것을 쓴다.

2D 필드(`mmo.html`)는 손대지 않는다(§1.5): 공용 모듈은 기본값이 예전 그대로(`telegraph` 생략 = 표시 있음)이고 시험이 본다.

## 1. 준비 동작 — `js/mmo/windup.js`

보스 뿌리(root)와 몸(model) 사이에 틀(`WindRig`) 하나를 끼워 **그 틀만** 움직인다. 클립·돌진·떠오름·움찔(flinch)·사망은 각자 몸이나 뿌리를 움직이므로 서로 안 부딪힌다.

창 하나 = `{ from, at, style }` (기술 시작부터 ms, 서버 시계):

- **준비** (`from → at`): 창의 85 % 까지 부드럽게 다 감고, 끝 15 % 는 감은 채 떤다(움직임 줄이기 설정이면 안 떤다).
- **터짐** (`at → at + 180 ms`): 늘어나며 앞으로 쏟아졌다 제자리.

**웅크림은 «내리기» 가 아니라 «눌림»** 이다. 처음엔 틀을 아래로 내렸는데, 몸 전체가 내려가니 발이 바닥에 묻혔다 —
클레이브 셔터 돌진 준비에서 −0.417 m(42 cm)를 재 봤다. 틀의 원점이 발밑이라 키(y)를 줄이고 옆(x·z)을 반만큼 넓히면 발은 바닥에 남는다.
시험이 «틀을 내리지 않는다» 를 본다(내리게 되돌리면 2개 실패).

| 모양 | 몸 | 쓰는 곳 |
|---|---|---|
| `coil` 감기 | 살짝 눌리고 젖히며 24° 비틂 → 반대로 풀며 앞으로 | 가로 베기: 클레이브 폭풍 1·2타, 섀도우 팽 연격 2·3타, 실험체 09호 폭주 1·2타, 정 장관 원·3합·등 뒤, 지배형 베기 |
| `crouch` 웅크림 | 키를 10 % 눌러 11° 숙임 → 앞으로 튀어 나감 | 돌진·찌르기: 클레이브 셔터 돌진, 섀도우 팽 찌르기·연격 1타 |
| `rear` 젖힘 | 14° 뒤로 젖힘 → 크게 내려찍음 | 내려찍기·광역: 클레이브 내려찍기·폭풍 3타, 실험체 09호 폭주 3타·방전 폭우, 섀도우 팽 개화, 정 장관 지휘, 지배 파동, 몬스터 내려찍기 |
| `brace` 버팀 | 눌리고 살짝 젖혀 버팀 | 그 밖(몬스터 기본 공격 등) |

창은 어디서 오나:

- 클레이브: `CLAVE_WINDS` (`boss-motion.js`) — 판정마다 창 하나, 창 끝 = 판정 시각. 클립이 «멈춘» 구간(`CLAVE_CHOREOGRAPHY`)과 겹치게 잡았다.
- 기술표형: 서버 기술표의 `tells`(예전 바닥 예고였던 박자, `style` 로 모양) · 따로 줄 때 `winds` · 기본 모양 `wind`. **리듬 깨기**(실험체 09호 `shift`)는 준비 동작도 같이 민다.
- 지배형: 시작 → `tell`, 모양은 `DOM_WIND`.
- 몬스터: 시작 → `windupMs`, 연타는 타점(`strikes`)마다.

`server/field-boss-kit.cjs` 에는 화면만 읽는 `style` · `wind` · `winds` 를 더했다. 서버 판정은 바뀌지 않아 **Render 재배포가 필요 없다**(다음 재배포 때 같이 실려도 무해).

## 2. 시험

`tests/windup.test.mjs` (9) · `tests/kit-motion.test.mjs` (5, 다시 씀)

- 기술표형 보스 **전 기술 × 50 ms 마다**: 장면에 보이는 바닥 메시 0, 첫 판정 전 틀이 움직인다.
