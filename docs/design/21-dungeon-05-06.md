# 던전 05·06 — 버려진 식물원 / 끊어진 수송로

`js/world.js` 에 의뢰는 있는데 들어갈 던전이 없던 두 건(`q_plant`, `q_road`)에
실제 던전을 붙였다. 4장까지의 사슬을 두 장 더 잇는다.

## 1. 왜 이 둘인가

의뢰 목록에는 `q_plant`(식인초, 위험 B)·`q_road`(수송로, 위험 A)·`q_med`(폐병원, B)가
«화면에만» 있었다. 앞의 둘은 목표 구조가 이미 정해져 있어(군락 5곳 소각 / 수송로 3구간 확보)
그대로 레벨 설계로 옮길 수 있었다. `q_med` 는 남겨 둔다.

## 2. 구조를 겹치지 않게

기존 세 던전은 «목표를 어떤 순서로 처리하는가» 로 갈라져 있다. 새 둘도 같은 축에서 비켜 세웠다.

| 던전 | 구조 | 읽는 법 |
|---|---|---|
| d03 정화장 | **병렬** — 밸브 3개, 순서 없음 | 세 방을 한 번씩 |
| d04 변전소 | **순차** — 북 축전기 → 남 → 차단기 | 순서를 외운다 |
| **d05 식물원** | **확산** — 군락 5개가 온실 전체에 흩어짐, 순서 없음 | 길을 «고르는» 문제. 안 태운 군락은 계속 포자를 뿜어 경로가 좁아진다 |
| **d06 수송로** | **왕복** — 기중기가 한 대뿐 | 조작대 → 구간 → 조작대 를 세 번. 오가며 같은 붕괴 구역을 몇 번이고 다시 읽는다 |

d06 은 처음에 `env:'swamp'` 로 두었다가 **갈대밭이 d02 와 똑같아 보여서** 실내(`bunker`)로 돌렸다.
«붕괴한 고가 *하부*» 로 자리를 잡으니 이야기도 맞고 화면도 갈라진다.

## 3. 보스

둘 다 절차적 강체 리그다 (`relay-boss.js` 와 같은 방식, 나중에 GLB 로 교체 가능).

| | 모근체 (d05) | 파쇄 기갑 (d06) |
|---|---|---|
| 파일 | `js/root-boss.js` | `js/hauler-boss.js` |
| 크기 | 3.76 m × 5.74 m | 3.66 m × 4.98 m |
| 파괴 부위 | 왼·오른 덩굴 (`VineL/R`) | 파쇄 턱 (`JawR`) · 평형추 (`ArmL`) |
| 약점 | 가슴 포자낭 | 등판 아래 동력로 |
| 클립 | 12 (`atk_lash` · `atk_lash_b` · `atk_slam` · `atk_spore` · `atk_sweep` …) | 12 (`atk_bite` · `atk_bite_b` · `atk_ram` · `atk_quake` · `atk_burst` …) |
| 광란 구역 | 포자 구름 3자리 | 낙석 4자리 |

연계는 기존 규칙(`18-boss-fight-design.md` §2)을 그대로 쓴다 — **부위를 부수면 그 부위가 맡던
연계 타격이 통째로 빠진다.** 모근체는 덩굴을 끊으면 후려치기 연계가 짧아지고, 파쇄 기갑은
턱을 부수면 돌진의 마무리 물기가, 평형추를 부수면 강타의 «버티는» 구간이 사라진다.

## 6. d04 광란 체력 260,000 → 220,000 (디렉터 지시) 과 그 뒤에 남은 것

봇 클리어 테스트를 d01~d03 에서 **전 던전** 으로 넓히다가, 새로 만든 둘이 아니라
**기존 d04** 가 깨지지 않는 것이 드러났다. 지시대로 광란 체력을 220,000 으로 내렸다.

**다만 체력만으로는 해결되지 않는다.** 260,000 이든 220,000 이든 봇은 **같은 틱(12,033)에**
죽는다 — 죽는 시점이 체력과 무관하다는 건, 병목이 «보스를 못 깎아서» 가 아니라
«맞아서» 라는 뜻이다. 체력을 내리면 보스가 더 깎일 뿐(183,946 → 117,946) 결과는 같다.

### 왜 d04 만 다른가 — 받는 피해 출처

| 던전 | 봇 2인이 받는 피해 (합계 체력 48,900) | 결과 |
|---|---|---|
| d03 | 압력 망치 1/2 = 12,400 · 나머지 1,960 → **14,360** | 클리어 |
| d06 | 과부하 배출 = 18,580 · 나머지 1,960 → **20,540** | 클리어 |
| d05 | — (전부 피함) | 클리어 |
| **d04** | 과부하 방전 17,380 + 접점 쓸기 14,000 + 접점 내려찍기 13,600 + 3,920 → **48,900** | 전멸 |

다른 던전은 **한 패턴만** 꽂히는데 d04 는 **셋이 다 꽂힌다.** 광란 `patternGap` 이 .95 로
전 던전 중 가장 짧아(다른 광란은 전부 1.0) 회피 재사용 대기(0.45초)가 안 돌아오는 것이 유력하다.

### 손잡이를 다 재봤지만 «봇에 맞춘 수치» 밖에 안 나온다

| 조합 | 결과 |
|---|---|
| 220k 단독 | 전멸 (보스 117,946 남음) |
| 220k + 간격 1.0 (형제와 통일) | 전멸 (83,975 남음) |
| 220k + 간격 1.25 | 전멸 (**6,861** 남음 — 코앞) |
| 220k + 간격 1.3 | 전멸 (164,619 남음 — 1.25 보다 **나쁘다**) |
| 220k + 타격 −30% / −35% | 둘 다 **똑같이** 전멸 (13,527틱, 13,700 남음) |
| 210k + 간격 1.25 | 클리어 — 남은 체력 **1** |
| 200k + 간격 1.25 | 클리어 — 남은 체력 175 |

간격 1.3 이 1.25 보다 나쁘고, 타격을 30% 든 35% 든 내려도 결과가 한 글자도 안 바뀐다.
**수치에 대해 매끄럽지 않다** — 봇의 회피 타이밍이 특정 박자와 맞물리느냐 마느냐의 문제다.
여기서 «1 HP 남기고 통과» 하는 조합을 골라 넣으면 그건 밸런스가 아니라 봇 맞춤이고,
다음에 뭘 조금만 건드려도 다시 깨진다.

### 그래서 지금 상태

- 광란 체력 220,000 적용 (지시대로). 보스가 4만큼 덜 버티니 사람에게도 분명히 짧아진다.
- 봇 클리어 게이트에는 d04 를 계속 빼 두고, 이유를 테스트 주석에 남겼다.
- 이 봇은 **가드·물약·스킬·궁극기를 하나도 쓰지 않는다.** 사람이 못 깬다는 근거가 아니다.
  실제로 손이 막히는지는 디렉터가 한 판 돌아보는 게 가장 빠르다.
- 손대야 한다면 다음 후보는 **광란 `patternGap` .95 → 1.25** 다 (타격 수치가 아니라 박자).
  다만 위 표대로 이건 검증된 값이 아니라 «봇이 거의 통과하는» 값이라는 점을 감안해야 한다.
