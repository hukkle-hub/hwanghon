AI 영상(문서 163)은 멈춘다. **게임 화면 자체**를 올린다. 엘든 링의 연출은 전부 엔진 안에서 나온다.
범위는 EP01 허수아비전 하나다.

## 1. 기준 영상 — 32 초, 1 초 간격으로 본 것

영상은 엘든 링 DLC 보스전(쌍월의 기사 렐라나)의 실제 플레이 화면이다. 플레이어는 짚 망토에 낫을 들었다.

| 초 | 화면 | 우리가 가져올 것 |
|---|---|---|
| 0–7 | 고딕 안뜰, 보스가 붉은 검으로 뛰어든다 | 등장이 곧 **첫 공격**이다. 카메라는 플레이어 뒤에 있고 보스가 화면을 채운다 |
| 9–21 | 물 고인 푸른 성당, 달빛 검기가 화면을 대각선으로 가른다 | **색으로 기술을 구분**한다. 무기 궤적 이펙트, 물보라, 반사광 |
| 22–26 | 달이 뜨고 화면이 하얗게 번진다 | 광역기 **예고를 화면 전체의 색**으로 준다 |
| 27–29 | 붉은 불과 번개가 화면을 채운다 | 예고색 → 타격색 **반전**, 파편, 불꽃 입자 |
| 30–32 | 연기 속에 두 사람이 서 있다 | 폭발 뒤 **정적** |

## 2. 지금과의 차이

| 요소 | 지금 | 목표 |
|---|---|---|
| 배경 | 회색 상자 그레이박스(문서 136) | 원문의 낮은 천장 지하 훈련장: 낡은 매트, 깨진 형광등, 콘크리트, 사슬. 조명과 반사 |
| 허수아비 | 대역 몸 + 남의 모션 | 턴어라운드 디자인. **변신을 엔진 안에서**: 붉은 문양 → 섬광 → 연기 → 안광 → 3 m |
| 기술 이펙트 | 거의 없음 | 회전(숨 예고)·팔꿈치마다 예고색(붉은 문양) → 타격 궤적 → 파편 |
| 타격감 | 기본 | 히트스톱, 화면 흔들림, 효과음 |
| 소리 | 없음 | 형광등 웅웅, 강선 «그드득», 사슬, 타격음 |
| 인물 | 아인은 Countess 대역 | 이번 범위에서는 대역 그대로. 인물은 MetaHuman 트랙(별도) |

## 3. 순서 (단계마다 30 초 캡처를 기준 영상과 나란히)

1. 지금 모습 캡처(기준선).
2. 배경: 훈련장 세트. Fab/Megascans 콘크리트·매트·형광등·사슬, PolyHaven 재질. 조명(차가운 형광등 + 엠버).
3. 변신 연출(시퀀서): 문양 선 → 짚 폭발 → 연기 → 안광 → 로우앵글 공개. 컷신이 아니라 **게임 카메라에서 이어지는** 연출.
4. 보스 기술 2개(회전·팔꿈치): 예고색 → 궤적 → 파편 + 히트스톱·흔들림·소리.
5. 30 초 플레이 캡처를 기준 영상과 나란히 놓고 판정한다.
