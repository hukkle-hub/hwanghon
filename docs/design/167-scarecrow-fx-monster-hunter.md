## 1. 몬스터헌터에서 가져온 것

기준 영상은 «Monster Hunter Wilds: Arkveld | SnS | No HUD» (HxWl0LMEbek)다.
- 20 장면을 29 s 간격으로 봤다.
- 공격 두 개(2:06–2:10, 4:59–5:06)는 0.5 s 간격으로 봤다.

| MH에서 본 것 | 허수아비에 옮긴 것 |
|---|---|
| 예고와 타격의 **색이 다르다**. 푸른 충전 오라가 돌고, 붉은 폭발이 터진다 | 예고: 몸 윤곽이 붉게 달아오른다(오버레이 재질). 타격: 불꽃·불티 |

| 몸을 가리지 않는다. 폭발은 짧고 낮다 | 바닥 고리 0.7배, 손 불꽃 0.5배. 동작이 가려지지 않게 한다(«동작이 항상 잘 보이게») |

## 2. 재료: Paragon 그룩스·세바로그의 파티클

- Fab VFX 팩은 아직 프로젝트에 설치되지 않았다(런처 작업).
- 이미 받아 둔 Paragon Grux·Sevarog를 VaultCache에서 복사했다. `FX`와 `Characters/Global` 폴더로 약 2 GB다.
- `Scripts/ue_fx_inventory.py`로 검사했다. 파티클 127개가 전부 열리고, 빠진 의존성은 0이다.
- **이름이 아니라 그림으로 골랐다.** `-HWQA=fxgallery`가 EP01 방 바닥에서 후보 35개를 하나씩 터뜨리고 0.04 / 0.12 / 0.3 / 0.7 / 1.4 s에 찍는다. 목록은 `Scripts/fx_candidates_scarecrow.txt`다.
  - 흰 방에서는 발광 이펙트가 보이지 않았다. 그래서 검은 바닥과 뒷벽을 세우고 노출을 고정했다.
  - 이름에 Trail이 있는 것은 원을 그리며 움직여야 보인다. 초당 1.5바퀴로 돌린다.
  - 스토리 시퀀스가 카메라를 뺏어 가서 시퀀스를 멈추게 했다.
- 세바로그 이펙트는 전부 초록(영혼)이라 쓰지 않는다.

## 3. 구현

- `UHWBossFxComponent`: 스토리 연출이 허수아비 규칙(`UHWHeosuabiRules`)과 함께 붙인다.
  - 받는 것: 보스 상태 변화, 패턴의 예고·타격 시각, 소설 비트(deflect / rebound / sever)
  - 시간은 패턴 값을 그대로 쓴다: 예고 1.3 s, 타격 0.12 / 0.29 / 0.46 s, 마지막 0.25 s는 «숨»
- 몸의 문양 = `M_HW_GlyphOverlay`
  - 가산 방식, 조명을 받지 않는 재질이다. 몸 윤곽(프레넬)에 빛이 돈다. `Scripts/ue_fx_glyph_material.py`로 만든다.
  - 스켈레탈 메시 사용 플래그가 없으면 게임에서 기본 재질로 그려진다. 한 번 당했다.
  - 첫 값(Glow/30, 바탕 0.18)은 몸 전체를 주황 덩어리로 만들어 짚·강선이 사라졌다. 윤곽만 남기도록 낮췄다(Glow/75, 바탕 0.03, 지수 3).
  - 가슴 점광원과 팔꿈치 점광원(붕괴 중 주황 맥동)을 함께 쓴다.
- QA
  - `-HWQAFxShots`: 스토리 QA 전투에서 보스 상태가 처음 나올 때마다 0.05–1.2 s 사이에 찍고, 로그에 발광 값을 남긴다.
  - `-HWQAFreeSpin`: 첫 회전 한 번은 카인이 막지 않는다. 회전 이펙트를 끝까지 보려는 QA 전용 옵션이다.
  - EP01 스토리 QA `ok=1`

## 4. 남은 것

- 모션: 회전 클립이 실제로 도는 동작이 아니다(대역 클립). Mixamo 교체는 디렉터 로그인 대기다.
- 부위파괴 이펙트·동작 변화(문서 166 탭 5–7)는 이 컴포넌트에 이어서 붙인다.
- 이 방은 흰 그레이박스다. 어두운 훈련장 세트(문서 164)에서는 불꽃이 더 강하게 보인다. 세트가 들어오면 크기를 다시 맞춘다.
- 복사한 Paragon 폴더와 생성된 재질은 `.gitignore` 대상이다. 다른 PC에서는 VaultCache 복사와 스크립트 실행으로 다시 만든다.
