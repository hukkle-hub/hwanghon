# 186 · 리니지 서버 구조에서 배운 것 (L1J 읽기 노트, 2026-10-06)

디렉터: «인터넷에 보면 리니지 개발자가 소스 풀어놓은거 있으니깐 한번 보고.»

## 0. 무엇을 읽었고, 무엇을 안 가져오나

- 공식적으로 NCSoft 가 공개한 리니지 소스는 **없다**. (디렉터가 말한 «리니지 개발자가 풀어놓은 소스» 는 송재경의 OpenMMO 였다 → 문서 187) 돌아다니는 것은 둘이다.
  1. **유출 소스** (리니지2·3 등, 퇴사자 유출 사건) — 불법 유출물. **보지 않는다.**
  2. **L1J** — 팬들이 만든 리니지1 서버 에뮬레이터 ([l1j-en/classic](https://github.com/l1j-en/classic), GPL v2). 흔히 «리니지 소스» 라 부르는 것이 이것.
- L1J 는 **설계(구조)만** 읽었다. 코드는 한 줄도 가져오지 않는다 — GPL 이 우리 저장소 전체에 걸리고,
  거기 든 맵 파일(`maps/*.txt`)·몬스터·드롭 표는 NCSoft 원본에서 뽑은 것이라 쓰면 안 된다.
- 읽은 곳(참고 경로): `src/l1j/server/server/model/map/L1V1Map.java`, `model/Dungeon.java`, `model/L1BossCycle.java`,
  `model/L1BossSpawn.java`, `model/L1Spawn.java`, `db/l1jdb_m10.sql` (`mapids`, `dungeon`, `spawnlist`, `spawnlist_boss`, `getback`).

## 1. 맵 — 리니지는 «칸마다 비트», 우리는 «다각형»

| 리니지 (L1J) | 뜻 | 황혼 2D 맵 (map.json) |
|---|---|---|
| 칸마다 1바이트: 0x01·0x02 걷기, 0x04·0x08 화살 통과 | 벽·통로 | `walk` 띠 + `blockers` (실측 건물 다각형·상자). 화살 통과는 전투 단계에서 `blockers[].shoot` |
| 0x30 두 비트: 안전(0x10) · 전투(0x20) · 일반(0x00) | 구역 | **`areas[]`** `{kind:'safe'|'combat', poly}` — 쉘터·문 둘레는 안전, 보스 구역은 전투 |
| 0x80 «서 있음» (실행 중) | 칸 점유 | 쓰지 않는다 (연속 좌표 + 원 충돌) |
| 문(door)은 맵이 아니라 객체 | 열고 닫는 문 | 다음 단계 — 셔터·차수문(한강 레비아탄 «가두기») |

**맵 속성 표 `mapids`** → 우리 `map.json rules`:

| L1J 열 | 뜻 | 황혼 |
|---|---|---|
| `markable` | 기억(북마크) 가능 | `rules.mark` |
| `teleportable` | 순간이동 | `rules.teleport` |
| `escapable` | 귀환 주문서 | `rules.escape` — 던전 안 보스 구역은 false |
| `resurrection` | 부활 | `rules.revive` |
| `penalty` | PK·사망 벌칙 | `rules.penalty` (PvP 는 나중) |
| `monster_amount` · `drop_rate` | 몹 수·드롭 배율 | `rules.mobs` · `rules.drops` |
| `getback` | 죽거나 «마을로» 시 돌아갈 곳 | `restart: { zone, gate }` — 강남 필드는 강남 벙커 |

## 2. 문 — 리니지는 «밟으면», 우리는 «단추로»

- L1J `dungeon` 표: `src_x, src_y, src_mapid → new_x, new_y, new_mapid, new_heading`. **한 칸**이 문이고, 넓은 입구는 칸 여러 줄.
  그 칸으로 **걸어 들어가는 순간** 이동한다. 도착하면 2초 무적(`ABSOLUTE_BARRIER`).
- 도착 칸 = 돌아가는 문 칸인 경우가 많다(«밟는 순간» 이라 도착만으로는 다시 안 넘어간다). 글루디오 던전은 도착을 한 칸 옆으로 비켰다.
- **황혼**: 휴대폰에서 스틱이 미끄러져 원치 않게 넘어가는 것을 막으려 **원 안에서 단추**(이미 구현). 받아들이는 것:
  - 도착 후 **2초 무적** (전투 단계에서)
  - 같은 지역 안 지름길 문(L1J 의 같은 층 → 같은 층) — 긴 남산 길에 쓸 수 있다
  - `dungeon_random` (도착지 다섯 중 무작위) — 판교 «봉인 건물» 미로에 쓸 수 있다
  - 시간 제한 던전(하루 N시간, 자정 초기화 — 기란 감옥) — 나중

## 3. 보스 — 주기 창(window) 안 무작위

- L1J `BossCycle.xml`: `Period`(주기) · `Start`~`End`(주기 안에서 나올 수 있는 창). 창 안 **무작위 초**에 나온다.
  예: 바포메트 `Period=5h Start=2h30m`.
- `percentage`: 그 주기에 아예 안 나올 확률. 죽으면 **다음 주기 창**에만 다시(같은 창에 두 번은 없다). 여럿이면 다 죽어야.
- 처치 기록(`boss_kills`: 누가, 어느 혈맹, 언제) → 순위.
- **황혼** (보스 단계에서): 디렉터 2026-10-06 «보스까지도 필드 몬스터, 던전은 모든 플레이어가 공유» — **모든 보스가 리니지식 공유 필드 보스**다.
  이 «주기 창 + 확률 + 다음 창» 규칙을 모든 보스에 쓴다. `map.json bosses[].cycle = { period, start, end, chance }`.

## 4. 일반 몹 출현

- `spawnlist`: 개수, 사각 영역(`locx1..locx2`) 또는 점 ± 흩뿌림, 재출현 `min~max` 초, **보는 화면 안에는 안 나온다**(`respawn_screen=0`),
  첫 자리 근처로 돌아온다(`spawn_home`), 무리(`mobgroup`: 우두머리 + 졸개 7종, 우두머리 죽으면 해산).
- **황혼** (보스 단계 다음, 필드 적): `map.json spawns[] = { mob, area:poly|circle, count, respawn:[min,max], group }`.
  화면 밖 출현은 휴대폰 화면이 작아서 더 중요하다.

## 6. 세계 구성

- 리니지: 큰 필드 맵 몇 장(말하는 섬, 아덴 본토 ≈ 1856 × 1472 칸) + **던전 층마다 작은 맵**(≈ 128 × 128).
  글루디오 던전 = 7개 층이 문으로 이어진다(1F ↔ 2F …, 같은 층 지름길, 다른 던전과 옆으로 연결).
- **황혼**도 같은 모양으로 간다: 존(필드) = 실측 OSM 맵, 던전 = 층마다 별도 지역(`gangnam_b1`, `gangnam_b2` …), 문으로 잇는다.
