# 55 · 오래 빨갰던 테스트 둘 — 하나는 진짜 버그였다

두 시험이 오래 빨간 채로 있었다. 「이전부터 빨갛다」고만 적어 두고 진단하지 않았는데,
열어 보니 **하나는 내가 만든 진짜 전투 버그**였다.

| | 내용 | 정체 |
|---|---|---|
| #9 `authored attack contact …` | 스킬1이 높은 부위에 안 닿는다 | **진짜 버그** — 내가 `punch.py` 로 만든 회귀 |
| #27 `repaired Ain: … continuous swings` | 관절이 한 프레임에 24° 튄다 | **진짜 결함** — 도는 기술의 조준 보정 |

## 1. #9 — 스킬1이 높은 부위를 못 때린다

`punch.py` 로 skill1 의 타이밍을 고치면서(최고속 9.1 → 29.5 m/s) 접점 시점의 **자세**가
바뀌었다. 그런데 높은 부위를 겨눌 때 쓰는 보정 자세는 **옛 클립에 맞춰 손으로 맞춘
상수**였다. 클립이 바뀌자 그 상수가 어긋났다.

높이 3.15 m 의 부위(반경 0.488 m)까지의 날 거리:

| | 보정 없이 | 보정 후 |
|---|---|---|
| punch.py 이전 | 0.728 | **0.422** ✅ |
| punch.py 이후 (버그) | 0.492 | **0.568** ❌ *보정이 오히려 멀어지게 했다* |
| 지금 | 0.492 | **0.358** ✅ |

**손으로 다시 맞추지 않았다.** 그 상수를 `AIN_HIGH_CONTACT` 로 빼고 좌표 하강으로
**재서** 찾았다 (`scratchpad/highkey.mjs`, 네 번 훑어 0.568 → 0.358).
손잡이 오차(`gripError < 0.001`)를 제약으로 걸어 양손이 자루에서 떨어지지 않게 했다.

```
[.44, .58, .37, -.025, 1, -.66]  →  [.253, .767, .557, -.212, 1.1, -.51]
```

### 1.1 음성 대조도 자리를 옮겼다

`#9` 가 실제로 빨갰던 줄은 「보정 없이는 빗나가야 한다」는 **음성 대조**였다.
낮은 부위(2.58 m)는 punch.py 이후 **보정 없이도 닿는다** (0.079 < 0.39) — 좋아진 것이라
거기서는 대조가 성립하지 않는다. 팔이 못 미치는 높은 부위로 옮겼다.

## 2. #27 — 도는 기술에 «고정된 세계 좌표» 를 겨누면 팔꿈치가 뒤집힌다

조준 보정은 표적을 향해 양손 중심을 옮긴다. 그런데 몸이 도는 기술에서는 어깨도 같이
돈다. 도는 내내 고정된 세계 좌표를 향해 팔을 끌면 팔꿈치 분기가 뒤집혀 **한 프레임에
13.3° 튄다** (240 표본 기준, `skill3Target`).

고친 방법은 값이 아니라 **켜는 시점**이다. 도는 기술은 «한 바퀴가 끝나 갈 무렵» 부터
조준한다:

| 기술 | 조준 보정 창 [시작, 최대, 감소, 끝] |
|---|---|
| 피의 회전 `skill3` | **[.44, .58, .74, 1]** |
| 궁극기 `ult` | **[.34, .50, .74, 1]** |
| 나머지 | [0, .32, .55, 1] (그대로) |

카운터는 조준 경사로가 좁아서(.28~.42) 그 짧은 구간에 보정이 급히 들어와 8.27° 튀었다.
`.20~.50` 으로 넓히니 5.33° 로 내려갔다.

| | 이전 | 지금 |
|---|---|---|
| `skill3Target` 최대 관절 걸음 | 13.30° | **4.37°** |
| `counterTarget` | 8.27° | **5.33°** |
| `ultTarget` | 4.21° | **1.93°** |
| **전체 최대** | 24.13° → 13.30° | **7.84°** (기준 8°) |

**여유가 0.16° 뿐이다.** 남은 7.84° 는 `ult` 의 «자기 클립» 이 접점(0.525)에서 내는 것이라
— 워프한 smash 소스의 내려치기 — 튀는 게 아니라 실제로 빠른 것이다. 그래도 아슬아슬하니
다음에 ult 소스를 손대면 다시 볼 자리다.

## 3. 배운 것

**「이전부터 빨갛다」는 진단이 아니다.** 두 시험 다 실제 결함을 가리키고 있었고,
그중 하나는 내가 며칠 전에 만든 것이었다. 빨간 시험은 열어 봐야 한다.
