# 212 · 3D 필드 스킬 1~4 (디렉터 «2D 는 이제 안 하고 3D 만», 2026-10-09)

2D 에만 있던 스킬 1~4 를 3D 로. 표는 서버·2D 와 같은 `js/dungeons.js SKILLS` (아인: 낫 베기 · 그림자 걸음 · 피의 회전 · 결의).

| | 3D |
|---|---|
| 쓰는 법 | 단추를 누르면 **바로** 나간다 (2D 는 «고르고 → 공격»). 3D 는 카메라 쪽으로 싸우니 고를 것이 없다. PC 는 숫자키 1~4 |
| 온라인 | `fieldSkill {skill, boss}` · `{skill, mob, generation}` · 대상이 없으면 `{skill}` — 재사용 대기·판정·회피 무적·치명 예약·피해 감소는 서버(`server/field.cjs skill()`). 대기 중이면 `skillUsed ok:false` → «아직 다시 쓸 수 없다» |
| 혼자 연습 | 서버와 같은 규칙: 배율(`mult`) · 여러 접점은 숫자도 나눠서(피의 회전 0.55/0.45) · 그림자 걸음 = 회피 무적 + 다음 공격 치명 · 결의 = 2초 받는 피해 50% 감소(`bossStrike`) |
| 단추 | 64 px 넷, 공격 위·왼쪽 호. 재사용 대기는 가운데 숫자 + 어둡게. 세로 화면은 4번을 위로 쌓아 왼쪽 이동 자리를 비운다 |

- 기본 공격과 스킬이 같은 `strike()`(가장 가까운 보스 → 없으면 몬스터)를 탄다.
- 세로 화면에서 조작 안내 띠가 공격·회피 단추를 덮었다(원래 있던 것) → 첫 터치나 12초 뒤에 걷는다.
- 확인 (Pixel 7 가로·세로, 대전 둥지 옆): 단추끼리 안 겹침 · 64 px 이상 · 화면 밖·이동 자리 0. 낫 베기 9,577 → 추적자 처치, 피의 회전 두 접점, 재사용 대기 중 다시 누르면 막힘.
  그림 `.node-shots/w3d/skill-land-3.png` · `skill-port-3.png`.
- 시험 `tests/world3d-skills.test.mjs` — 표 출처 · 단추 넷 · 온라인 보스/몬스터 전송 · 혼자 연습 규칙이 서버와 같은지 (몬스터 스킬을 기본 타격으로 바꾸면 실패하는 것을 봤다).
- 3D 에 아직 없는 것 (2D 엔 있던 것): 가방·상점, 장비 바꾸기, 전국 지도, 바닥 장비 줍기.
