# 188 · 사냥의 맛 — 멋진 몬스터, 그 몬스터의 장비, 자랑 (2026-10-06)

디렉터: «몬스터가 우리가 기존에 만들었던 이미지와 달리 멋있어야돼. 그래서 사람들이 그걸 잡는 맛이 있어야돼.
예를 들면 리니지의 데스나이트 같은 몬스터… 그리고 확률적으로 그 몬스터의 장비를 획득하고 또 그 장비를 착용해야
남들한테 자랑이 되고 그게 로망이 되서 거기에 목숨 거는 게임이 되는거지»

## 1. 고리 — 리니지가 사람을 붙잡는 방식

```
멋진 몬스터 ─▶ 잡기 어렵다(같이 잡는다) ─▶ 드물게 «그 몬스터의 장비» ─▶ 입으면 보인다
     ▲                                                               │
     └──────── 로망: «나도 저거» ◀── 남들이 알아본다(알림·칭호·빛) ◀──┘
```

- 리니지의 예: **데스나이트 → 불검**(불타는 검이 화면에 보인다), 바포메트 → 지팡이, 커츠 → 커츠의 검.
  사람들은 «불검 든 사람» 을 보고 데스나이트를 잡으러 간다. 몬스터의 멋 = 장비의 멋이다.
- 황혼에서는 원작 보스가 바로 그 자리다. **클레이브**(2.5 m 티타늄 기사 · 붉게 달아오른 장검 · 폭 3 m 셔터 방패, L1774~L1796)가
  그대로 우리의 데스나이트다.
- 보스는 전부 **공유 필드 보스**(문서 185 §3, 186 §3) — 주기마다 한 마리, 모두가 노린다. 희소성이 저절로 생긴다.

## 2. 원칙

1. **보스 장비 = 보스 외형의 조각.** 입으면 «그 보스» 가 보여야 한다 — 실루엣·재질·빛이 보스와 같다.
   클레이브의 장검을 든 카인은 누가 봐도 클레이브를 잡은 사람이다. (장비가 캐릭터에 그대로 보이는 구조는 이미 있다 — 185 §4.1, `js/looks.js`)
2. **드물다.** 전설 무기는 보스 한 마리에 1~2%. 신화는 0.2%. 그래서 한 자루가 서버의 이야기가 된다.
3. **자랑할 길이 여럿이다** — 아래 §5.
4. **원작에서 온다.** 장비 이름·모양은 원작 묘사(줄 번호)에서 꺼낸다. 아무 판타지 이름을 붙이지 않는다.

## 4. 보스마다 «주인의 장비» (원작에서) — 가안

네 영웅의 무기: 아인 = 낫 · 카인 = 대검 · 류 = 쌍단검 · 세라 = 시약/촉매. 방어구(머리·상의·하의·장갑·신발)는 같이 쓴다.

| 보스 | 원작 모습 | 전설 무기 | 세트 방어구 (영웅~전설) | 신화 |
|---|---|---|---|---|
| **클레이브** | 티타늄 기사, 붉게 달아오른 장검, 셔터 방패 (L1774) | 카인 «달아오른 장검» — 칼날이 붉게 빛나고 휘두르면 불티 | «티타늄 기사» 투구·흉갑·건틀릿·각반 | «셔터 방패» (보조 — 등에 메면 보인다) |

## 6. 확률 (가안 — 처치 1회, 보스 한 마리 기준)

| 무엇 | 확률 | 받는 사람 |
|---|---|---|
| 재료(보스 심장 결정 등) | 100% | 기여도 상위 전원 |
| 보스 세트 방어구 한 조각 (영웅) | 12% | 바닥에 떨어진다 — 기여도 1위가 10초 먼저 주울 수 있다 |
| 보스 세트 방어구 (전설) | 3% | 〃 |
| 보스 전설 무기 | 1.5% | 〃 |
| 신화 | 0.2% | 〃 |

- 기여도 = 피해 + 회복 + **카운터 성공**(원작 전투 문법 — 문서 150, «누군가 순간을 열고 다른 누군가 결정타»).
- 확률·주기는 서버 표 하나에서(L1J `BossCycle.xml` 처럼) — 운영 중에 바꿀 수 있게.

## 7. 외형 — «기존 이미지와 달리 멋있게»

- **한눈에 읽히는 실루엣**: 휴대폰 화면 10 m 안에서 0.5초 안에 «저건 클레이브» 가 되어야 한다. 크기는 사람의 1.5~4배.
- **빛나는 약점·무기**: 붉은 장검, 결정 띠, 코어 — 어두운 황혼 화면에서 빛이 곧 존재감이다(블룸이 이미 있다).
- **등장 연출**: 보스가 나오면 그 지역 하늘빛이 바뀌고, 이름이 크게, 화면이 한 번 흔들린다. 주기 알림으로 사람이 모인다.
- **죽음 연출**: 부서짐 + 등급 색 빛기둥 + 서버 알림.
- 데스나이트 결: 검은 판금 + 불타는 무기 + 찢긴 망토 — 클레이브는 «티타늄 판금 + 달아오른 장검 + 셔터 방패».

## 8. 만드는 길과 막힌 것

길(이미 있다): 컨셉 그림(Higgsfield 이미지) → 3D(Tripo · Hi3D) → 리깅(`tools/3d/rig_boss_template.py`, Blender)
→ **보스 모델에서 무기·투구를 섬으로 떼어 장비 GLB 로**(문서 151 의 셔터 떼기와 같은 방법) → `gear_post.py` → `js/items.js`.

막힌 것 (2026-10-06):
- Higgsfield 크레딧 **0** (문서 82 에서 다 썼다).
- Hi3D 자격증명(`HI3D_CLIENT_ID` · `HI3D_CLIENT_SECRET`)이 이 컨테이너에 없다. Hi3D 는 매달 29일 초기화(문서 82).
- 이 컨테이너에 Blender 가 없다 — `pip install bpy`(Blender 파이썬 모듈)로 들일 수 있는지 확인 필요.

크레딧 없이 지금 할 수 있는 것: 보스 출현 주기·드롭 판정(서버) · 기여도 · 서버 알림 · 바닥 빛기둥 · 보스 장비 데이터(`items.js`) ·
기존 보스 모델의 빛·연출 보강 · 기존 모델에서 무기 떼어 임시 장비.
