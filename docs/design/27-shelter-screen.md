# 쉘터 화면 — 설계만 있고 화면이 없었다

「전에 쉘터 구성한 것도 만들어.」

## 1. 무엇이 있었고 무엇이 없었나

`docs/design/15-shelter-social-server.md` 가 쉘터를 정해 놓았다 —
**길드 소속·접속 상태·초대 코드·길드 채팅을 쓰는 텍스트형 쉼터.**
서버는 그대로 다 있다. `server/index.cjs` 에 `guildCreate` / `guildJoin` /
`guildLeave` / `chat`(월드·길드·파티) / `board`(접속 인원)가 구현돼 있고
테스트도 붙어 있다.

**없던 것은 화면이다.** 쉘터 UI 는 `party.html` 안 `#social-area` 에
라벨·입력칸·버튼이 세로로 늘어선 맨 폼으로 들어가 있었다. 게임의 다른
화면과 아무 관계가 없는 모양이고, 로그인하기 전에는 `hidden` 이라
**로비의 「길드」 버튼을 눌러도 로그인 폼만 보였다.**

## 2. `shelter.html` — 게임 화면으로 만들었다

다른 화면과 같은 규약을 따른다: 1672×952 스테이지, 상단바, 하단 네비,
`panel--framed`, `data-mpane` (휴대폰 탭 전환).

```
┌ 쉘터 ─────────────────────────────────────────────────────┐
│ 접속 현황 1/100 ●│  아트 + 인용                │  채 팅    │
│ 내 길드          │  ───────────────────────── │  월드     │
│  문장 · 이름     │  길드 명단                  │  길드     │
│  초대 코드 [복사]│   ● 아인_디렉터    [길드장] │  파티     │
│  길드 공지       │                             │           │
│  [길드 탈퇴]     │  ───────────────────────── │  ────────│
│ 쉘터란           │  → 협동 출격                │ [입력][전송]│
└ 로비 · 인력사무소 · 쉘터 · 협동 출격 · 상점 · 창고 ───────┘
```

접속 상태에 따라 왼쪽 패널이 네 얼굴로 바뀐다:
**접속 전**(계정/체험) → **이름 미정** → **길드 없음**(만들기/코드 합류) → **소속**.

채팅은 월드·길드·파티 세 채널을 탭으로 나눠 보여 준다. 채널마다 색이 다르고,
받은 글은 전부 이스케이프해서 텍스트로만 넣는다.

## 3. 서버는 한 줄도 안 건드렸다

`js/shelter.js` 는 `party.html` 과 **같은 WebSocket 프로토콜**을 쓴다.
서버 주소 규칙(`?server=` → `localStorage`)과 접속 키(`tw:party-token:<host>`)도
같다 — 한쪽에서 로그인해 두면 다른 쪽에서 바로 붙는다.

정적 호스팅(GitHub Pages)에는 파티 서버가 없다. 그때는 **빈 화면을 주지 않고**
설계된 화면을 그대로 띄운 뒤 「서버를 실행한 주소로 열거나 `?server=주소` 를
붙이세요」라고만 알린다.

> **온라인 반영 시점**: `server/` 를 바꾸지 않았으므로 Render 재배포는 필요 없다.
> 정적 파일만 올라가면 바로 열린다.

## 4. 검수 — 실제로 돌려 봤다

로컬 파티 서버(`node server/index.cjs`)를 띄우고 헤드리스로 끝까지 밟았다.

1. 계정 만들기 → `welcome`
2. 캐릭터 이름 「아인_디렉터」 → `profile`, 왼쪽 패널이 «길드 없음» 으로
3. 「황혼의 인력사무소」 길드 생성 → `guild`, 초대 코드 `B7827C8B54`
4. 명단에 초록 점 + 「길드장」 배지
5. 월드 채팅 전송 → 되돌아온 `chat` 이 월드 탭에만 보임
6. 길드 탭으로 바꿔 전송 → 길드 탭에만 보임 (채널 분리 확인)

콘솔 오류 0, 스테이지 952px.

한 가지 밟은 것: 캐릭터 이름은 **전 서버 중복 불가**라 앞 세션이 쓴 이름으로는
다음 단계가 안 넘어간다. 서버가 의도한 동작이고(문서 15), 화면은 그 오류를
왼쪽 아래 상태 줄에 빨갛게 보여 준다.

## 5. 연결

- 로비(`index.html`)의 **길드 / GUILD** → `party.html` 이던 것을 `shelter.html` 로.
- 하단 네비에 「쉘터」 추가, 「협동 출격」(`party.html`)과 나란히.
- `sw.js` 프리캐시에 `shelter.html` · `js/shelter.js`.

## 6. 안 한 것

- **길드 공지 편집·길드장 위임·추방** — 서버에 명령이 없다. 넣으려면 `server/`
  를 고쳐야 하고 그러면 Render 재배포가 필요하다. 지시를 받고 한다.
- **귓속말·차단** — `rpg-server.cjs` 에 있지만 party.html 쪽 UI 에 묶여 있다.
- 쉘터 화면에는 **단위 테스트가 없다.** DOM 에 붙은 UI 라 노드 테스트로
  의미 있게 고정하기 어려워서, 위 6단계 헤드리스 시나리오로 대신했다.
