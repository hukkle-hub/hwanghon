# 황혼 — 상용 액션 RPG 품질 목표와 현재 구현

2026-09-18. 사용자가 지정한 아이온·블레이드앤소울·붉은사막·마비노기 영웅전을 비교 대상으로 삼는다. 황혼의 기존 기획인 아인, 낫, 어려운 허수아비, 정밀 회피·반격·부위 파괴를 중심으로 판단한다. 아래 적용 항목은 참고 자료에서 도출한 황혼의 설계 선택이며, 각 게임의 엔진 내부 구현을 재현했다는 뜻은 아니다.

## 확인한 근거와 적용

| 참고작·확인 범위 | 공식 자료에서 확인한 요소 | 황혼에 적용한 선택 |
|---|---|---|
| 아이온 클래식 | 임무로 시스템·콘텐츠를 익히고, 완료·누적 점수 보상으로 성장하도록 구성 | 훈련 → 늪지 → 정화장 의뢰 연결, 첫 완료 보상, 탐색 목표와 정산 |
| 블레이드앤소울 NEO의 현행 공식 소개 | 강화 상태에서 이어지는 무공, 단계별 1인 수련 보상, 무공 계열 선택, 장비 승계·성장 | 행동별 준비·타격·회복 구분, 반격 창 안내, 조준 부위 전환, 기존 제작·장비 성장 유지 |
| 붉은사막 | 무기·연계 기술, 기술 해금, 장비 강화와 위협 공략을 함께 소개 | 공격의 실제 전진·방향 고정, 예고와 판정 동기화, 회피 후 반격 기회 |
| 마비노기 영웅전 | 전투 목표·지도·자원 표시, 완료 정산, 부분파괴 추가 보상, 정교한 조작을 요구하는 1인 보스전 | 부위 파괴로 보스 패턴 봉쇄, 기술 등급, 지도·위험 구역·빠른 재도전 |

아이온은 아이온 2 자료로 대체하지 않았다. 블레이드앤소울은 이번에 확인 가능한 **NEO 공식 페이지** 범위를 표시했다. 원작의 직업별 프레임·합격기 수치나 영상 전체를 확인했다고 주장하지 않는다. 사용자가 앞서 준 유튜브 영상의 구체적인 모션 프레임 분석은 이번 조사에 포함하지 않았다.

아이온의 임무와 성장 연결은 [데바의 여정 공식 가이드](https://aion.plaync.com/guidebook/classic/view?title=%EB%8D%B0%EB%B0%94%EC%9D%98%20%EC%97%AC%EC%A0%95)에서 확인했다. 웹 본문 추출에 부족한 내용은 브라우저에 표시된 문서를 읽었다.

블레이드앤소울의 강화 상태 무공·흑풍 수련장·무공서 및 장비 개편은 [NEO 공식 업데이트 소개](https://bns.plaync.com/promo/260805_update)의 브라우저 표시 내용에서 확인했다. 특정 시점의 이벤트 보상이나 성장 속도를 황혼에 옮기지는 않는다.

붉은사막의 무기·연계·성장 구성은 [공식 Combat and Progression 소개](https://crimsondesert.pearlabyss.com/en-US/News/Notice/Detail?_boardNo=58)의 설명 본문을 읽었다. 영상의 모든 장면을 분석한 것은 아니다.

마영전의 목표·정산·부분파괴 보상 및 아인라허는 [공식 전투 개요](https://heroes.nexon.com/guide/view?postno=89)를 확인했다. 환경 물체와 전투의 연결도 [공식 오브젝트 가이드](https://heroes.nexon.com/guide/view?postno=98)를 참고 대상으로 확인했다.

## 다음 제작 묶음

1. **전투 한 장면의 상용 수준 검수:** 아인·각수-0의 전용 이동/공격 클립, 실제 무기 궤적, 무기별 그립, 카메라 가림 방지. 첫 수료 시간 목표는 원기획의 초회 4~7분·숙련 2분30초를 인간 플레이로 확인한다.
2. **보스 공략의 깊이:** 같은 예고에서 다른 도달 시간, 연속 공격·잡기·지연타, 사망 원인 안내, 적응형 패턴. 어려움을 공격력·체력 증가만으로 만들지 않는다.
3. **성장과 재도전:** 장비 재료 출처와 부족분 안내, 플레이 스타일을 바꾸는 장비 효과, 의뢰별 선택 목표·추가 보상 검수.
4. **제품 품질:** 실제 Android 빌드에서 저장·백그라운드 복귀·멀티터치·성능 검수. 이후 최종 캐릭터 외형과 던전 아트 패스.

현재 결과물은 실제 규칙과 저장·진행을 갖춘 개발 빌드다. 상용 작품 수준의 최종 에셋·풍부한 콘텐츠·실기기 최적화·온라인 서비스까지 완성한 결과물로 취급하지 않는다. 기존 `03-action-rpg-benchmark.md`의 포괄적인 참고 메모에 대해, 이번 문서는 확인 가능한 공식 근거와 현재 구현/미구현 경계를 보완한다.
