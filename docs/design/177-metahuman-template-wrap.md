# 177 — 유튜브 재학습: 메타휴먼 얼굴을 디자인 머리로 «감싸서» 넣기 (2026-10-01 밤)

디렉터: «유투브로 다시 학습하고 하자. 이대로는 안될 거 같은데?»

## 1. 다시 본 것 (프레임 시트로 전 구간)

| 영상 | 순서 |
|---|---|
| Lost Realm «단일 이미지로 커스텀 MH (5.7+)», 84 s | AI 얼굴 이미지 → 3D 대머리 → Blender 정리 → **Identity**(메시에서 구성요소 → 마커 추적 → 솔브) → Character에서 **Conform: Identity에서** → 헤어·피부 |
| Na0n «블렌더로 메타휴먼 쉽게», 353 s | MH 얼굴을 **FBX(LOD0)로 내보내** → Blender에서 Shape Key로 **직접 스컬프트** → 다시 넣는다. Character에서 **Conform: 템플릿에서**, 정렬 None. 메타휴먼 위상이 그대로라 추적·솔브의 오차가 없다 |

- 우리가 전에 한 것은 둘 다 아니다. `conform_to_target_meshes`에 남의 위상 메시(Hi3D)를 바로 넣었다.
  - 위상이 다르니 솔버가 «대충 비슷한 사람»으로 근사했다.
  - 그래서 닮음이 약했다(문서 176 §6).
- Na0n 방식이 우리에게 맞다. 사람 손 스컬프트 대신 **Hi3D 대머리 머리에 자동으로 감싼다**.

## 2. 파이프라인 (전부 스크립트)

1. `tools/metahuman/export_template.py`(UE, 렌더 켠 에디터): 플러그인 원본 `SKM_Face`를 FBX로 내보낸다.
   - 34,657 정점, 그중 피부 24,414
   - `-nullrhi`에서는 스킨드 메시 내보내기가 `MeshObject` 어서트로 죽는다.
2. `tools/metahuman/wrap_template.py`(Blender):
   1. Hi3D 머리를 정수리·이마 폭·코 깊이로 맞춰 놓는다.
   2. 두 얼굴을 정면 렌더해 **mediapipe FaceMesh 468점**을 양쪽에서 찾는다. 가상환경은 `C:/w/tools/face-venv`(py3.10)다.
   3. 찾은 점을 광선으로 메시에 꽂아 3D 쌍을 만든다. 윤곽처럼 비스듬히 맞은 점과 입 안쪽 입술점은 버린다. 깊이 이상치 19개도 버린다.
   4. **RBF**(φ=r + 아핀)로 템플릿을 옮겨 쌍을 맞춘다. 잔차는 0.3 mm다.
   5. 피부를 법선 방향 6 mm 안에서 Hi3D 표면에 붙이고, 못 붙은 곳은 이웃 평균으로 메운다.
      - 눈가, 입 안쪽, 귀는 RBF 결과를 그대로 둔다.
      - UV 이음새의 쌍둥이 정점 365개는 같이 움직이게 묶는다.
   6. 눈알·치아·속눈썹은 가장 가까운 피부를 따라간다.
3. `tools/metahuman/split_template.py`: 피부만 남긴다.
4. `tools/metahuman/import_template.py`(UE):
   - 프리셋을 복제하고 `import_from_template(char, 정적메시, None, None, None, params)`를 부른다.
   - params는 UV로 정점 매칭, 정렬 SRT다.
   - 결과는 `SUCCESS`다.
5. `lab_build.py`를 `MH_EXISTING=1 MH_ONLY=<이름>`으로 돌린다. 감싼 얼굴을 유지한 채 피부·속옷·헤어를 입혀 빌드한다.

### 함정

1. `EAlignmentOptions`는 Python에서 `unreal.MetaHumanAlignmentOptions`다.
2. φ=r RBF의 정규화는 **빼야** 한다. +λI로 넣었더니 잔차가 15.7 mm로 «아무것도 안 맞춤»이 되었다.
3. 처음 시도한 최근접점 감싸기(ICP + 매끈한 끌어당김)는 다음을 만들었다. 랜드마크 없이 하면 안 된다.
   - 정수리가 갈라졌다.
   - 입이 구겨졌다.
   - 눈에 구멍이 났다.

| 단계 | 결과 |
|---|---|
| 감싼 템플릿 | Hi3D와 거의 같다 |
| → `import_from_template`(고주파 끔이 하드코딩) → 얼굴 상태 | 무거운 눈꺼풀과 눈썹뼈가 조금 무뎌진다. 머리가 약간 커진다(SRT) |

  - Python이 템플릿 UV와 대응시켜 DNA 순서 정점을 만들고, `fit_state_to_target_vertices`에 넣는다.
- 휴대폰 예산: 얼굴 19k 정점은 MEDIUM의 4.7배다. 태블릿에서 재야 한다(4인 파티 + LOD 전환).

### 7.2 조사한 것과 결과

1. **머리색**: 공식 예제 방식을 썼다. 순서는 미리보기 컬렉션 → 선택 → `on_edit_preview_collection` → `assemble_for_preview` → 그룸 인스턴스 파라미터(Melanin, Redness, **Whiteness**, Lightness…)다.
   - 세라 은발(Melanin 0, Whiteness 1)이 된다. 전에는 내부 컬렉션을 직접 고쳐서 파라미터가 비어 있었다.
2. **헤어 선택지**: 미리보기 배우에는 그룸이 끝내 안 나온다. 그래서 빌드로 비교했다(`hair_builds.ps1`, 이미지 `ain_hair_presets.png`).
   - BobMessy / S_Messy / M_Layered / M_SideSweptFringe 중 **M_SideSweptFringe가 가장 가깝다.**
   - 디자인의 숱과 눈을 덮는 앞머리는 프리셋에 없다. 직접 만든 그룸이 필요하다(다음 과제).
3. **붉은 눈**: 홍채 global_tint (1, .15, .1), 채도 3, primary_color (u .9, v .9), 동공 0.6 → 선명한 빨강(`ain_iris_survey.png`)
4. **반쯤 감긴 눈**:
   - 랜드마크 이동: 요청한 값의 1/3만 움직였고 모양은 거의 그대로였다.
   - 눈 감기 표정 커브(`CTRL_expressions_eyeBlink`): 에디터에서도 시뮬레이트에서도 눈꺼풀 뼈가 0 mm 움직였다(측정).
   - 화장(아이라이너): 화면 크기에서는 거의 안 보였다.
   - 결론: **파라메트릭 얼굴 모델이 눈을 크게 뜬 쪽으로 되돌린다.**
5. **DNA 통째 가져오기**(`whole_rig.py`, `import_from_face_dna(import_whole_rig=True)`)로 맞춤 단계를 건너뛴다. 순서:
   1. 캐릭터 DNA를 내보낸다.
   2. 머리 메시를 감싼 템플릿 그대로로 옮긴다(MHLabTools `AddDNAMeshDeltas` = DNACalib, 아래 LOD는 다시 계산).
   3. 나머지 얼굴 메시 8개(치아, 눈알, 눈 덮개, 속눈썹…)는 가장 가까운 피부 정점을 따라 옮긴다.
   4. 통째로 가져온다.
   - 처음에는 피부만 옮겨서 눈알이 튀어나오고 치아가 비쳤다. 8개를 같이 옮긴 뒤로는 자연스럽다.
   - 단점: 얼굴이 «고정 리그»가 되어 크리에이터에서 얼굴 형태를 편집할 수 없다. 디자인이 정해진 영웅에는 문제없다.
   - 리그를 다시 요청하지 않는다(`MH_SKIP_RIG=1`).

### 7.3 유튜브 학습 — «AI 3D 얼굴을 메타휴먼에 래핑» (XU97a_Xoip0, 608 s)

- 흐름(우리와 같다): 얼굴 이미지 → AI 3D → (ZBrush 보정) → 위치·크기 맞춤 → OBJ → **Wrap(R3DS)에서 대응점** → 감싼 메타휴먼 메시를 UE로 → 표정 확인
- 화면에서 배운 것:
  - **눈꺼풀 위·아래 선을 따라 점을 촘촘히 찍는다.**
  - 눈 안쪽과 쇄골 아래는 감싸기에서 뺀다.
- 적용: 우리 자동 감싸기에 **눈꺼풀 선 대응**을 넣었다.
  - 템플릿 쪽은 피부 메시의 눈 경계 고리(안쪽 눈꼬리–바깥 눈꼬리로 위/아래를 나눔), Hi3D 쪽은 mediapipe 눈 윤곽 9점씩이다.
  - 둘 다 호 길이로 12점씩 다시 뽑아 48쌍을 만든다. 깊이는 주변 얼굴 쌍의 깊이 변화를 따른다.
- 겹쳐 보기(`ain_eyelid_overlay.png`, 빨강 = 템플릿, 파랑 = Hi3D): 위 눈꺼풀이 Hi3D 선에 붙고, 눈매가 길고 무거워졌다.

## 9. 디자인 머리카락 = Hi3D 영웅의 머리 메시 (2026-10-02)

- 메타휴먼 프리셋 머리 30종에는 아인의 숱 많은 헝클어진 단발도, 세라의 허리까지 오는 생머리도 없다.
- Hi3D 영웅 GLB(`art/3d/heroes/{ain,sera}.glb`)의 머리는 디자인 시트에서 나온 그 모양이다.
- `tools/metahuman/fit_hair.py`:
  1. 영웅에서 머리 면만 남긴다.
     - 아인(검은 머리): 텍스처가 어두운 면, 턱 아래(스카프)는 자른다.
     - 세라(`HAIR_MODE=light`): 밝고 무채색인 면. 피부는 붉은 기가 있고 옷은 어둡다. 허리까지 남긴다.
  2. 영웅 얼굴과 템플릿 얼굴을 mediapipe 468점으로 RBF 대응시킨다(더 매끈하게: λ 0.02).
  3. 머리 정점을 그 대응으로 옮긴다.
  4. 두피 안으로 들어간 점은 2 mm 밖으로 밀어낸다.

## 16. 통째 넣기의 축 버그 — 지금까지의 수정이 반쯤만 먹은 이유 (2026-10-02)

## 23. 디자인 머리 모양 → 진짜 털(그룸) (2026-10-03)

`make_hair_groom.py hair_placed.fbx out.abc - state_<영웅>.fbx` → 알렘빅 → 언리얼 그룸 → 머리 뼈에 붙임 (`lab_build.py`의 `MH_GROOM_ABC`).

1. **가이드 900가닥**: 디자인 머리 겉면을 따라 위로는 가운데 가르마 선까지, 아래로는 끝까지 따라간다. 10번 다듬는다.
2. **두피에 붙이기**
   - Hi3D 머리 덩어리는 정수리에서 **7 cm** 떠 있다.
   - 그래서 뿌리 쪽을 두피에서 0.7 cm(정수리)에서 3 cm(어깨) 사이로 당긴다(`GROOM_HUG`).
3. **자식 가닥**: 가이드마다 40가닥. 옆으로 퍼짐 6 mm, 떠오름 4 mm.
4. **두피 뿌리 6만 개**
   - 겉면만 따라가면 이마 위가 비어서, 두피 전체에 뿌리를 심었다.
   - 각 뿌리는 가장 가까운 가이드를 따라간다(8 cm에 걸쳐 합류).
   - 합류하는 길이 두개골 속을 직선으로 지나가서 털이 안 보였다 → 머리 밖으로 밀어낸다.
5. **두피 칠하기**
   - `scalp_mask.py`(머리 모델 텍스처 좌표의 두피 마스크)와 `scalp_paint.py`로 얼굴 텍스처의 두피를 머리색(은회색)으로 칠한다.
   - 가르마 틈이 덜 보인다.
6. 결과(`sera_v59_groom.png`)
   - 은발, 엉덩이까지 오는 길이, 가운데 가르마가 나왔다. 털 9만 4천 가닥.
   - 남은 것: 이마 위 가르마 자리의 V자 틈, 오른쪽이 어두운 조명.

언리얼 함정:
- 알렘빅을 일반 물체 가져오기가 집어 간다 → `HairStrandsFactory`를 지정하고, **AlembicHairImporter 플러그인을 켠다**(uproject).
- 블렌더 기본 곡선(캣멀롬)은 마디 오류가 나고 종잇장처럼 그려진다 → 직선 곡선 + 굵기(`radius`, 뿌리 0.09 mm).
- 빌드된 머리 재질은 프리셋 색이다(캐릭터의 멜라닌 값은 자기 그룸에만 간다) → 자식 재질에 `hairMelanin` / `hairRedness` / `WhiteAmount`를 직접 넣는다.

## 26. 세라 눈 아래·눈썹·앞머리 (v76–v79, 2026-10-03)

디렉터: «앞머리가 살짝 대머리처럼», «눈 아래쪽 눈꺼풀이 살짝 거멓고 이상», «윗눈썹이 눈두덩이랑 안 맞아».

- **눈 아래 갈색 반달**
  - 부속 메시(눈가 물기 띠, 눈물샘 살, 눈 껍질, 속눈썹)를 단색으로 칠해 봤다(`MH_DEBUG_SLOTS`). 범인은 아니었다.
  - 원인은 아래 눈꺼풀과 눈알 사이 틈으로 보이는 눈구멍 안쪽이었다.
  - 눈알을 내리니(v78, −1.2 mm) 더 넓어졌다 → 반대로 **눈알 +1.2 mm 올림**(`MH_EYE_DZ=0.12`, `whole_rig.py`) + 아래 눈꺼풀 +1 mm(`LOWER_LID_RAISE=1.0`) → v79에서 사라졌다.
  - 눈 껍질(mesh 5)도 눈알과 같이 옮긴다.
- **눈썹**
  - 33 px 아래로 내려 그려서, 3.5 mm 내린 눈꺼풀 주름 바로 위에 붙어 있었다 → 14 px로 올렸다.
  - 꽉 찬 막대 → 짧은 털을 한 올씩 그린다(`paint_brows.py … straighthair:20:7:2`). 안쪽은 서고 꼬리는 눕고, 안쪽 끝은 흐려진다.
- **앞머리**
  - «이마 앞 가닥 옆으로» 규칙이 정수리 앞 두피 가닥까지 밀고 있었다 → `GROOM_FOREHEAD_TOP=0.095`(이마에만 적용).
  - 헤어라인을 2 cm 낮췄다(`GROOM_HAIRLINE=0.095,0.17`, 가운데 0.095).
  - 두피는 0.5 회색으로 칠한다.
- 남은 것: 이마를 가로지르는 가닥 하나, 오른쪽 관자놀이의 어두운 두피 칠.
