# N01 v07 — 실제 전선 후퇴

## 전투 감각
플레이어가 밀릴수록 UI 숫자만 줄어드는 게 아니라 **전장이 실제로 뒤로 이동한다.**

```text
외곽 검문소
   ↓
MAIN GATE
   ↓ Gate 파괴
CENTRAL PLAZA
   ↓
COMMS FINAL
```

### Gate 파괴
패배가 아니다.
`CentralPlaza`로 방어선을 옮기고 살아 있는 몬스터의 목적지를 다시 계산한다.

### Generator 파괴
패배가 아니다.
조명/지원/자동장비 등 연결된 지원 기능을 끈다.

### Comms 파괴
남산의 존재 이유가 사라지므로 `Occupied`.
이것이 Prototype A의 핵심 패배 조건이다.

### 방어 성공
마지막 Wave가 등장한 시점이 아니다.

```text
5개 Wave 전부 Spawn 완료
+ 살아 있는 Wave Enemy = 0
+ Comms 생존
```

이때만 Recovery로 진입한다.

## 5급별 후퇴 후 행동
- 보행형: 전선을 따라 계속 압박.
- 질주형: 후방 플레이어 재탐색.
- 파괴형: 광장 진입 후 Generator, 최종선에서는 Comms.
- 추적형: 방어선과 무관하게 NPC를 계속 사냥.
- 철갑형: Gate 돌파 후 플레이어 진형을 밀고, 최종선에서는 Comms 압박.
- 공진형: 항상 주력 군집 후방을 따라 이동.

이 단계부터 6종은 단순 외형 차이가 아니라 실제로 전투의 모양을 바꾼다.
