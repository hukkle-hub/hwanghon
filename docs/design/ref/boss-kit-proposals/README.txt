이전 사용자 요청에 맞춰 신체 변형을 억제한 제안. 원작의 팔 비대는 적용하지 않았으며 작은 목덜미·척추 코어 중심이다.
이미지 생성으로 들어간 군복 글자·부대 표식은 확정 설정이 아님. 제작 시 제거/정리해야 한다.
