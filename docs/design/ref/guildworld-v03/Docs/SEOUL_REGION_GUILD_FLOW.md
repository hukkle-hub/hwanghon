# 서울권 길드 플레이 흐름 v0.2

## 서울 핵심 8거점

1. N01 남산 통신기지 — 정보
2. N02 서울역 피난거점 — 대형 허브
3. N03 용산 정비기지 — 제작
4. N04 한강 검문선 — 물류
5. N05 청계 수자원실 — 자원
6. N06 북악 관측소 — 정찰
7. N07 상암 방송중계소 — 통신
8. N08 구로 산업창고지 — 생산

## 길드의 주간 목표

길드가 모든 거점을 먹는 것이 목표가 아니다.
`우리 길드가 어떤 기능을 책임질 것인가`가 목표다.

예:
- 전투형 길드: 남산/북악 방어
- 제작형 길드: 용산/구로
- 물류형 길드: 한강/서울역
- 복합 길드: Strategic 1 + Local 1~2

## 남산-서울역 연쇄

남산 정상:
서울역 침공 경고 +10분

남산 경계:
+5분

남산 함락:
서울역은 기본 경고만 받음
일부 구조신호 UNKNOWN

서울역까지 함락:
서울권 `Pressure +20`
용산 보급량 감소
한강 검문선 난이도 상승

이런 연쇄가 길드간 협력을 강제하지 않고 자연스럽게 유도한다.

## 동시 침공 예

21:00 남산 경계
21:05 한강 검문선 경계
21:12 서울역 구조 요청

한 길드는 세 곳을 모두 지킬 수 없다.
길드/동맹 채널에서 전력을 분배해야 한다.

이것이 황혼 길드전의 핵심 판단이다.
