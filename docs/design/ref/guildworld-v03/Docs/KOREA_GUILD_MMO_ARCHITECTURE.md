# 황혼 — 대한민국 길드 중심 MMORPG 아키텍처 v0.2

## 1. 게임의 중심 단위

황혼의 성장 축은 개인 장비보다 다음 순서를 우선한다.

`개인 → 파티 → 분대 → 길드 → 거점 → 지역 → 전국 → 서버`

개인 캐릭터는 전투를 수행하지만 **세계 상태를 바꾸는 단위는 길드**다.

## 2. 대한민국 맵 사용 원칙

대한민국을 1:1 크기로 복제하지 않는다. 모바일 MMORPG에서 1:1 실측 연속 월드는 이동 피로와 서버/메모리 비용이 너무 크다.

대신:
- 실제 해안선·산맥·도시 위치·주요 교통축은 알아볼 수 있게 유지
- 플레이 구역은 압축
- MacroRegion → Sector → Strategic Node → Field Cell 구조
- 같은 지역 안은 최대한 연속적으로 느껴지게 구성
- 지역 간 이동은 고속도로·철도·터널·항만 구간을 로딩 은폐 지점으로 활용
- 서버는 지역/필드 셀 단위로 분리 가능하게 설계

**지도는 대한민국이지만 게임 공간은 전투와 길드 운영을 위해 재구성한다.**

## 3. 2026 현행 행정구역 반영

현행 행정체계는 2026-07-01 전남과 광주의 통합을 반영하여 `전남광주통합특별시`를 하나의 MacroRegion으로 둔다.

단, 플레이 구역은 행정구역과 동일할 필요가 없다. 예를 들어 통합특별시 안에서도 `광주 중심권`, `목포권`, `여수·순천권`, `도서권`을 별도 Sector로 운영한다.

이렇게 하면 실제 지리의 최신성을 유지하면서도 게임 콘텐츠 설계를 행정개편에 종속시키지 않는다.

## 4. 길드 관리권

거점에는 한 주기의 **관리 길드**가 존재한다.

관리 길드가 할 수 있는 것:
- 방어 정책 결정
- 거점 자원 배분
- 길드 집결 명령
- 분대/전선 제안
- 시설 업그레이드 우선순위
- 길드 공동 제작 프로젝트 제안
- 침공 전 예비물자 투입

관리 길드가 할 수 없는 것:
- 일반 플레이어 출입 금지
- 상점/제작 접근 차단
- 임의 세금 부과
- 거점 영구 소유
- 타 길드 유저 강제 추방

즉 `관리권 != 소유권`이다.

## 5. 독점 방지

길드는 `Administration Capacity`를 가진다.

초기 예시:
- 기본 80
- 성장 최대 160
- Local Node 25
- Strategic Node 40
- Regional Hub 60

한 길드가 Regional Hub를 동시에 여러 개 관리하지 못하게 제한한다.

따라서 강한 길드도 전국 모든 핵심 거점을 독점할 수 없다.

## 6. 길드 공헌도

관리권은 전투 DPS만으로 계산하지 않는다.

가중치:
- Combat 1.00
- Defense 1.25
- Repair 1.35
- Rescue 1.50
- Supply 1.20
- Boss 1.10
- Craft 1.00
- Command 0.80 (비전투 점수의 10%까지만 인정)

4종 이상의 행동에 실질적으로 기여하면 10% 다양성 보너스.

의도는 `싸움 잘하는 길드`보다 `거점을 잘 운영하는 길드`가 관리권에서 유리하게 만드는 것이다.

## 7. 대규모 전쟁을 모바일에서 구현하는 방법

50~100명이 한 화면에서 싸우게 하지 않는다.

하나의 작전을 여러 전선으로 분해한다.

예: 남산
- 정문 6명
- 서측 4명
- 동측 4명
- 발전시설 4명
- 보스 대응조 6명
- 민간인 대피 3명

각 전선은 다른 플레이 공간 또는 서버 셀에서 실행되지만 결과를 `Guild Operation`이 합산한다.

따라서 실제 렌더링은 소규모 전투 품질을 유지하면서 플레이어는 **길드 전체가 하나의 공성전을 수행한다는 느낌**을 받는다.

## 8. 길드전

길드 경쟁은 두 축이다.

### PvE 공헌 경쟁
거점 방어, 복구, 보급, 구조, 보스 공략.
이것이 관리권의 주축이다.

### 제한적 PvP 쟁탈전
공헌도 상위 길드의 도전자 보너스를 결정하는 8v8/12v12 목표전.
PvP 승리만으로 거점을 빼앗을 수 없다.

목표 예:
- 통신기 확보
- 발전기 유지
- 코어 운반
- 보급차 호위
- 지휘소 침투

## 9. 동맹

최대 3개 길드.
동맹의 목적은 거점 소유 합병이 아니라 **지역작전 분담**이다.

예:
- A길드: 남산
- B길드: 서울역
- C길드: 한강

동시 침공 시 세 길드가 같은 작전 채널에서 역할을 나눌 수 있다.

## 10. 지역 압력

각 MacroRegion은 0~100 `Pressure`를 가진다.

- 0~29 Stable
- 30~54 Tension
- 55~74 Invasion
- 75~94 Crisis
- 95~100 Collapsed

한 거점의 함락이 연결된 거점의 위협도를 올린다.

예:
남산 함락 → 서울 정보력 감소 → 서울역 침공 경고 시간 감소
한강 함락 → 용산 보급 효율 감소
서울역 함락 → 수도권 피난/거래 기능 축소

## 11. 전국 전쟁

지역이 여러 곳 Crisis에 들어가면 `National Campaign`이 발생한다.

예:
- 수도권 통신 붕괴
- 경부축 보급선 단절
- 동해 산악 감염 확산
- 남해 항만 봉쇄
- 제주 해상 고립

이때 서버 전체 길드가 서로 다른 지역 임무를 맡는다.

대규모 전쟁은 한 맵에서 200명이 싸우는 방식이 아니라 **전국 여러 전선이 동시에 움직이는 방식**으로 만든다.

## 12. 개인 플레이어 위치

길드 중심이라고 솔로 유저를 버리면 안 된다.

솔로/소규모 플레이어는:
- 정찰
- 구조
- 수리
- 보급
- 필드 소탕
- 재료 수집
- 지역 의뢰

를 통해 거점/길드 공헌도에 참가한다.

길드 가입자는 조직적 효율과 지휘 기능을 얻지만, 미가입자가 핵심 게임을 못 하게 만들지는 않는다.
