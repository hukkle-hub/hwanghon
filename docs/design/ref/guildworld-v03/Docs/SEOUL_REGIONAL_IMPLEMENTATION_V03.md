# 서울권 지역 서버/길드전 구현 v0.3

## 핵심 변화
v0.2가 길드 관리권과 전국 구조의 뼈대였다면, v0.3은 **서울 8거점이 서로 영향을 주며 실제 지역처럼 움직이게 하는 단계**다.

## 1. 거점은 HP가 아니라 서비스다
- 남산(N01): Intel
- 서울역(N02): SafeHub
- 용산(N03): Manufacturing
- 한강(N04): Logistics
- 청계(N05): Resource
- 북악(N06): Recon
- 상암(N07): Intel
- 구로(N08): Manufacturing

거점이 함락되면 단순 버프 -10%가 아니라 해당 지역 서비스가 내려간다.

## 2. 상태
`Online → Degraded → Occupied → Recovering → Online`

- Online: 100%
- Degraded: 기본 55%
- Occupied: 0%
- Recovering: 75%에서 시작해 단계적으로 100% 복구

## 3. 연쇄 영향
연결 거점의 위협이 일정 수준 이상이면 인접 거점 Threat가 올라간다.
단, 1회의 지역 시뮬레이션에서 한 거점이 받는 전파 Threat는 최대 12로 제한한다.

의도: 연쇄 위기는 만들되 한 번 패배가 서버 전체 영구 패배로 이어지지 않게 한다.

## 4. 길드 역할
길드는 관리권을 얻은 뒤 단순 보너스를 받는 게 아니라 전략 명령을 발행한다.
- Defend
- Reinforce
- Supply
- Repair
- Recon
- Evacuate
- PrepareRecapture

직책별로 발행 가능한 명령이 다르다.
명령은 플레이어를 강제하지 않는다. 집결 UI, 추천 전선, 해당 활동 공헌 보너스와 연결한다.

## 5. 서울 Crisis
Pressure 75 이상 + 2개 이상 핵심 거점 문제 발생 시 여러 거점에서 동시에 작전이 열린다.
예: 남산 방어/탈환 + 한강 물류 유지 + 서울역 대피 + 용산 복구.

한 화면에 50명이 모이는 게 아니라 각 길드/분대가 다른 전선을 수행하고 결과를 지역 작전이 합산한다.
