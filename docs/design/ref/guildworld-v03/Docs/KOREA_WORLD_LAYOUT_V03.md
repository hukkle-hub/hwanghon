# 대한민국 월드 레이아웃 v0.3

## 기본 단위
`대한민국 → MacroRegion → Sector → Strategic Node → Field/Instance`

한국 전체를 실측 1:1 오픈월드로 만들지 않는다. 실제 도시·산악·해안·교통축의 인지성은 유지하되 길드 운영과 전투 밀도를 위해 압축한다.

## v0.3 전국 시드
16개 MacroRegion 전부에 1개의 Regional Hub와 3~7개의 전략 거점 시드를 배치했다. 서울은 첫 구현 지역이라 8개, 다른 권역은 4~5개부터 시작한다.

전국 시드 수는 데이터 검증 스크립트 결과를 기준으로 관리한다.

## 지역별 길드 구조
- 한 길드: Regional Hub 최대 1개
- Alliance: 최대 3길드
- 따라서 한 지역의 Hub/전략/로컬 거점을 여러 길드가 나눠 운영하는 것이 기본
- 한 길드가 전국 핵심 허브를 독점하는 구조 금지

예: 수도권 동맹
- A 길드: 서울역 + 남산
- B 길드: 한강 + 용산
- C 길드: 상암 + 청계/구로

관리권은 주기적으로 공헌도로 재평가되고 소유권이 아니다.

## 전국 전쟁
`National Campaign`은 한 장소의 거대한 떼쟁이 아니다.
- 수도권 길드: 통신·대피
- 충청권 길드: 중앙 보급
- 영남권 길드: 산업·항만
- 서남권 길드: 식량·해상 보급
- 강원/동해권 길드: 산악 정찰
- 제주 길드: 해상 고립 대응

각 지역 결과가 전국 Campaign의 weighted objective로 합산된다.
