# 황혼 대한민국 길드 중심 MMORPG v0.3

이번 버전은 v0.2의 길드 관리권/전국 Campaign 골격 위에 **서울권 실제 전략 네트워크**를 추가한다.

추가:
- 서울 8거점 서비스 모델
- Online / Degraded / Occupied / Recovering
- 거점 간 Threat 전파 + death-spiral 방지 cap
- 지역 OperationalRatio / 역할별 서비스
- 길드 전략 명령 보드 및 직책별 권한
- 서울 Crisis 동시작전 샘플
- 백엔드 권위 상태 계약
- 서울 네트워크 시뮬레이터/테스트

이 패키지는 실제 Unreal 프로젝트에 이미 병합됐다는 뜻이 아니다. Claude/개발자가 현재 프로젝트를 감사하고 기존 구조와 중복 없는 부분만 적용해야 한다.

핵심 철학:
`개인 → 파티 → 분대 → 길드 → 거점 → 지역 → 대한민국 → 서버`

세계 상태를 바꾸는 중심 단위는 길드다.
