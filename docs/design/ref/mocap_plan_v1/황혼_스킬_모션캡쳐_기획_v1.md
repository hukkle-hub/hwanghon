# 황혼 스킬 애니메이션·모션캡처 제작 기획 v1

## 결론
황혼은 **원본 모캡을 그대로 쓰는 방식보다 `모캡 → 무기 제약/물리 정리 → 게임용 과장 → 이벤트 메타데이터 → GLB` 하이브리드 방식**이 적합하다.

현재 프로젝트의 장점은 이미 Mixamo 계열 공통 골격과 공통 클립 파이프라인이 있다는 점이다. 새 스킬은 기존 골격을 버리지 않고, 같은 골격에 캐릭터별 전용 클립을 추가한다.

## 권장 파이프라인
1. **스킬 락** — 각 스킬의 목적, 접점 수, 이동량, 무기 역할을 먼저 확정한다.
2. **키포즈 프리비즈** — 5개 핵심 자세(준비/가속/접점/여운/복귀)를 먼저 잡는다.
3. **퍼포먼스 캡처** — 안전한 경량 프록시 무기로 3~5 테이크를 촬영한다.
4. **리타게팅** — Mixamo 호환 골격으로 통일한다.
5. **Cascadeur/Blender 정리** — 발 미끄러짐, 무게중심, 손-무기 접촉, 과도한 관절속도를 수정한다.
6. **게임용 과장** — anticipation과 follow-through를 키우고 실루엣을 읽기 쉽게 한다.
7. **이벤트 태깅** — clip 내부의 contact/release/detonate/guard 이벤트를 정규화 시간으로 저장한다.
8. **GLB export** — 캐릭터별 전용 clip으로 굽고 Three.js에서 재생한다.
9. **자동 검수** — 손-무기 접촉, 발 접지, 바닥 관통, 무기 실제 접점, 관절 각속도를 검사한다.

## 캡처 방식 선택
- **최종 품질 우선**: Rokoko 계열 캡처 → Mixamo skeleton export → Cascadeur cleanup.
- **저비용 프리비즈**: 스마트폰 영상 → markerless AI mocap → Cascadeur/Blender cleanup.
- **다중카메라 스튜디오**: Move AI 계열은 강력하지만 황혼 현재 규모에는 과한 편. 필요할 때 최종 궁극기/복잡한 접촉만 사용.
- **중요**: 낫·대검·쌍단검·정제환은 영상 AI가 정확히 '무기 자체'를 추적한다고 가정하지 않는다. 몸은 모캡하고 무기는 별도 prop/constraint로 잡는다.

## 캐릭터별 원칙

### 아인
- 프록시: 1.9m 낫 프록시
- 원칙: 오른손이 무기 주도, 왼손은 자루 locator를 따라가게. 몸통 회전과 회수 관성 우선.

- **낫 베기** — 정밀 절단. `fullbody_weapon` / 이벤트: 단일 접점. 흐름: 준비→몸통 회전→날끝 가속→정밀 접촉→깊은 따라감→회수
- **그림자 걸음** — 회피/재진입. `fullbody_inplace` / 이벤트: 접점 없음. 흐름: 낮은 중심→측/후방 한 걸음→시선 유지→재진입 준비
- **피의 회전** — 광역 절단. `fullbody_weapon` / 이벤트: 1차 접점. 흐름: 큰 원호 준비→골반 선행→전신 회전→주 접점→자루 회수
- **결의** — 방어 버프. `upperbody_additive` / 이벤트: 접점 없음. 흐름: 방어 진입→플레이트/낫으로 중심선 보호→유지 루프→해제
- **낫의 황혼** — 궁극 강타. `fullbody_weapon` / 이벤트: 주 접점 1회. 흐름: 큰 예비→발/골반 고정→폭발적 회전→주 접점→긴 여운→복귀

### 카인
- 프록시: 1.6~1.8m 폼 대검 프록시
- 원칙: 실제 중량물 사용 금지. 발-골반-어깨-검 순서와 버티는 자세를 연기하고, 무게는 후처리 물리로 강화.

- **대검 내려치기** — 중량 파괴. `fullbody_weapon` / 이벤트: 단일 접점. 흐름: 발 넓힘→검 들어올림→골반 하강→수직 강타→반동 흡수
- **철벽** — 받아내기. `fullbody_hold` / 이벤트: 접점/가드 이벤트. 흐름: 검/몸으로 선 만들기→충격 대비→가드 유지→밀어내기→복귀
- **강철 회전** — 광역 중량 베기. `fullbody_weapon` / 이벤트: 주 접점 1회. 흐름: 옆으로 감기→축발 고정→큰 수평 회전→접점→검의 관성에 몸이 따라감
- **지면 강타** — 자세 파괴. `fullbody_weapon` / 이벤트: 지면 이벤트. 흐름: 무게 싣기→내려치기→지면 직전 정지→충격 반동→앵커 자세
- **모루의 심판** — 최대 중량 일격. `fullbody_weapon` / 이벤트: 주 접점 1회. 흐름: 긴 예비→응력 축적 표현→한 걸음 전진→강타→정지→느린 회수

### 류
- 프록시: 폼 쌍단검 2개
- 원칙: 빠른 몸동작은 60/120fps 촬영 권장. 손이 몸 뒤로 가려지지 않게 카메라 각도 확보.

- **쌍날 난무** — 연속 타격. `fullbody_dualweapon` / 이벤트: 3접점 권장. 흐름: 진입→R 베기→L 베기→교차 베기→짧은 이탈
- **그림자 도약** — 회피/축회전. `fullbody_inplace` / 이벤트: 접점 없음. 흐름: 보스 축 기준 측면 스텝→상체는 목표 고정→발 교체→재진입
- **칼날 폭풍** — 광역 연속. `fullbody_dualweapon` / 이벤트: 2~3접점 권장. 흐름: 낮은 자세→회전 베기→반대손 후속→방향 전환→회수
- **표식** — 타깃 지정. `upperbody_additive` / 이벤트: 표식 이벤트. 흐름: 시선 고정→한 손 표식→다른 손은 무기 준비→즉시 이동 가능
- **붉은 그림자** — 고속 연속 찌르기. `fullbody_dualweapon` / 이벤트: 3~5접점 권장. 흐름: 짧은 대시→교차 찌르기 연속→최종 관통 포즈→즉시 이탈

### 세라
- 프록시: 경량 정제환 2개 + 와이어는 디지털
- 원칙: 원래 정체성인 쌍 정제환/와이어를 유지. 와이어는 모캡하지 않고 런타임 곡선/VFX로 처리.

- **부식 시약** — 정제환 투척. `fullbody_prop` / 이벤트: release + impact. 흐름: 정제환 준비→한 손 투척→반대손 회수 준비→목표 확인
- **정제 안개** — 회피/장 설치. `fullbody_prop` / 이벤트: release 이벤트. 흐름: 환 위치 확인→와이어 당김 몸이동→낮은 착지→정제 자세
- **연쇄 폭발** — 다중 장치 연계. `fullbody_prop` / 이벤트: 2 release + detonate. 흐름: 양쪽 환 교차 투척→교차점 확인→손가락/손목 트리거→폭발
- **회복 결계** — 지원 유지. `upperbody_additive` / 이벤트: wardOn/wardOff. 흐름: 환 두 개 펼침→손을 작게 유지→장치가 크게 반응→해제
- **촉매 폭발** — 대형 정제 폭발. `fullbody_prop` / 이벤트: release + detonate. 흐름: 양환 회수→가슴 앞 압축→전방 방출→폭발 확인→후퇴

## 게임 코드에 필요한 다음 확장
현재처럼 `action()` 하나에 contact 하나만 두면 류의 난무나 궁극기를 자연스럽게 만들기 어렵다. 새 모션 시스템은 clip별 `events[]`를 읽어야 한다.

```json
{
  "clip": "ryu_skill1_mocap",
  "events": [
    {"t": 0.27, "type": "contact", "hand": "R", "mult": 0.65},
    {"t": 0.44, "type": "contact", "hand": "L", "mult": 0.65},
    {"t": 0.61, "type": "contact", "hand": "R", "mult": 0.70}
  ]
}
```

아인·카인은 대체로 단일 큰 접점, 류는 다중 접점, 세라는 `release → detonate` 이벤트가 핵심이다.

## 촬영 규칙
실제 날이나 중량 대검을 들고 촬영하지 않는다. 길이와 양손 간격만 맞춘 폼/PVC 프록시를 쓰고, 무게감은 배우의 자세와 후처리 물리로 만든다. 바닥 강타는 실제 바닥에 충돌시키지 않고 수 cm 위에서 멈춘다.

각 스킬은 기본적으로 `clean 3회 + 과장 1회 + 느린 참고 1회`를 남긴다. 영상 기반 캡처를 쓸 때는 전신과 손이 가려지지 않는 45도 보조 영상을 함께 남긴다.
