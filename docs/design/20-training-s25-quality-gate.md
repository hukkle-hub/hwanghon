# 황혼 — 아인 × 허수아비, S25 Ultra 기준 제작 게이트

## 디렉터 결정
- 1차 대상은 Galaxy S25 Ultra와 허수아비 훈련장. 모르버스 작업은 보존/후순위.
- 한 판: 입장 → 아인 조작 → 3단계 허수아비 공방 → 처형/격파 → 정산/재도전.
- 기존 아트/전투/클로드 UI를 보존. 기획 변경을 이유로 저장 데이터나 프로젝트를 폐기하지 않는다.
- 현재 GLB/절차 부착물은 개발 자산이다. AAA급 최종 아트로 승인하지 않는다.

## 이번 적용
- 온라인 허수아비에도 실제 견갑/사슬 표시. 서버 부위 상태로 표시/숨김.
- 캐릭터 1.14 배율을 보스에 적용하지 않음. 솔로 크기와 맞춤.
- 솔로 단계 복원 시 떨어져 나간 부위를 원래 뼈/변환으로 복원하고 잔해 처리 제거.
- 같은 부착 코드를 양쪽에서 사용. 온라인 생성 재질/지오메트리 수명 관리.
- 진단 화면에 프레임 계측: 준비 120프레임 제외, 평균 FPS, p95/p99,
  50ms 초과 횟수, 1분 구간 FPS. 탭 숨김/일시정지/오버레이는 제외.
- 수치는 rAF 간격이며 GPU 시간/터치 지연/온도 측정이 아니다.
  PC 브라우저 결과를 S25 Ultra 결과로 표기하지 않는다.
- 대사/컷신/클리어 화면과 비활성 구간 직후 프레임도 제외.
- 진단의 '측정 기록 저장'으로 빌드/설정/화면 크기/프레임 지표 JSON을
  기기에 저장한다. 서버 업로드는 하지 않는다.
- 관련 57개 테스트 통과, 두 렌더러 문법 검사 통과.
- PC 브라우저에서 3D 자산 로드→입장→대사/아인 화면까지 확인.
  전체 전투 완주 및 S25 Ultra 실기기 측정은 미실시.

## S25 Ultra 측정 절차 (아직 미실시)
1. 빌드 ID, 브라우저/앱, 화면 방향, 렌더 해상도, 그래픽 설정 기록.
2. 동일 설정으로 입장·이동·각 단계·이펙트 집중 상황 플레이.
3. 5분/10분/20분에 일시정지 → 진단 기록. 첫 구간과 후반 구간 FPS 비교.
4. 공격+이동, 회피+시점 회전, 락온 변경을 실제 두 엄지로 확인.
5. 기기 온도/불편한 발열과 터치 지연은 별도 실측/체감 기록.
6. 기준을 통과하기 전 최고 품질/안정 60fps 달성으로 발표하지 않는다.

## 공격 동기화 2차 검수
- tools/audit-training-motion.mjs로 실제 boss_anim.glb 양손/골반 위치 샘플링.
  찌르기 손 전방 신전은 클립 35% 부근, 기존 판정 기준은 45%였다.
- 공격 클립의 골반 수평 이동만 복제본에서 제거. 원본 GLB와 높이 변화 보존.
- 내려찍기 48%, 찌르기 35%, 회전 첫 전방 통과 30%를 잠정 모션 기준으로 설정.
  피해 시뮬레이션 타이밍/공격력/반격 창은 바꾸지 않고 렌더 시간 매핑을 수정.
- js/boss-motion.js의 공통 샘플러를 솔로/온라인에서 사용.
  연계 사이 link 상태에서 이전 예고 스크럽의 paused 상태가 남지 않도록 수정.
- training-motion-review.html: 실제 모델/아레나 설정으로 준비→기준→회복 재생,
  판정 순간 정지 및 양손 뼈 표시. 실제 훈련장으로 이동 가능.
- 화면에서 풍선처럼 보인 견갑 짚 구체를 얇은 받침/판재로 교체.
- 관련 63개 테스트 통과. 아인 기존 리그 샘플에서 손 목표 최대 오차 0.028m,
  발 목표 최대 오차 0.067m. 실제 손가락 접촉/발바닥 접지 합격 증거는 아님.
- 미합격: 현재 리타게팅 내려찍기는 양손 강타 실루엣이 약하고, 찌르기도
  상대를 향한 전신 공방 가독성이 부족하다. 기준 프레임 조정은 임시 보정이다.
  전용 공격 클립 제작과 실제 아인 상대 거리/충돌 대조가 필요하다.
- 이번 변경도 로컬이며 push/Render 배포/실기기 측정은 하지 않았다.
