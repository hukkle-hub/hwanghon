# 102 — 황혼의 장르 정의: 시네마틱 전투 액션 (기획 초안 v0.1, 2026-09-26)

디렉터: 「시네마틱 전투 액션게임으로 정의하려고 하는데 너도 기획해볼래?」
목표 그림(서한역, 눈뜬 허수아비 「거리와 반격」)을 기준 장면으로 삼는다. UI 는 GPT, 카메라·조명·연출 시스템은 Claude(101 번에서 시작).
수치는 모두 목표값이며 따로 적지 않은 것은 「근거 없음」 — 폰 실기로 맞춘다.

---

## 1. 한 줄 정의

> **«읽고, 받아치고, 끝낸다» — 한 번의 결투가 한 편의 액션 영화처럼 보이게 만드는 보스 결투 액션.**
> 영화처럼 보이게 하는 것은 컷신이 아니라 **플레이어의 입력**이다. 잘 받아칠수록 화면이 더 영화가 된다.

### 우리가 말하는 «시네마틱» 과 아닌 것

| 시네마틱이다 | 시네마틱이 아니다 |
|---|---|
| 내 튕기기가 성공한 순간 시간이 느려지고 카메라가 붙는다 | 보스가 나올 때마다 20 초 컷신 |
| 보스 자세가 무너지면 1 버튼 처형이 한 컷으로 이어진다 | 화면에 뜨는 QTE 버튼 연타 |
| 페이즈가 바뀔 때 조명·음악·보스 몸이 같이 바뀐다 | 로딩 화면 뒤 다른 방 |
| 카메라·조명이 상황을 설명해서 UI 가 적어도 된다 | 게이지와 팝업으로 설명 |

---

## 2. 네 기둥 (Pillars)

1. **읽는 결투** — 보스 몸짓(예고→접점→여운)만 보고 판단한다. 바닥 게이지로 알려 주지 않는다(18·90 번 방향 유지, 훈련장만 예외).
2. **입력이 연출을 부른다** — 흘림·튕김·맞대기(51)·완벽 회피(77)·자세 붕괴·처형이 각각 «정해진 연출 한 박자» 를 부른다. 연출은 실력의 보상이다.
3. **끊기지 않는 한 컷** — 입장부터 보스 격파까지 컷 전환·로딩 없이 게임 카메라가 그대로 이어서 찍는다(갓 오브 워 2018 의 «원 컷» 방식). 연출 카메라도 게임 카메라에서 출발해 게임 카메라로 돌아온다.
4. **폰에서 두 손으로 된다** — 이동 스틱 + 공격 + 카운터(방향=회피, 78) + 스킬. 연출은 조작을 빼앗는 시간이 짧고, 두 번째부터는 건너뛸 수 있다.

---

## 3. 연출 4 단계 — «연출 예산»

연출이 많으면 조작 게임이 아니라 영상이 된다. 단계마다 길이·빈도·조작 뺏김 한도를 둔다.

| 단계 | 언제 | 무엇 | 길이 | 조작 | 빈도 한도 |
|---|---|---|---|---|---|
| **L0 상시** | 항상 | 전투 카메라(3/4 등 뒤, 101), 조명 분위기, 히트스톱, 흔들림 | — | 그대로 | — |
| **L1 순간** | 흘림·튕김·맞대기·완벽 회피·연계 마무리 | 시간 느림(0.2~0.5 배), 카메라 밀착·살짝 돌기, 색·빛 번쩍, 소리 뚝 끊김 | 0.2~0.8 초 | 입력 받음(버퍼) | 연속 제한 없음, 대신 짧게 |
| **L2 흐름** | 자세 붕괴→처형, 궁극기, 보스 큰 기술 직전 | 전용 카메라 한 컷(2~3 방향 중 고름), 조명 변화, 배경 어두워짐 | 1.0~2.5 초 | 뺏김(무적) | 20 초에 1 번 |
| **L3 이야기** | 보스 등장·페이즈 전환·격파 | 보스 전용 동작 + 대사 한 줄 + 조명·음악 전환 | 2~4 초, 두 번째부터 건너뛰기 | 뺏김(무적) | 페이즈당 1 번 |

**지표(검수)**: 한 판 동안 조작을 뺏긴 시간 ≤ 8 %, L1 연출은 입력 후 100 ms 안에 시작, 연출 중 입력은 버퍼로 살아 있어야 한다.

## 4. 결투 한 판의 흐름 — 눈뜬 허수아비 「거리와 반격」(d01)

목표 그림의 장면을 설계로 옮긴 것. 보스 3 페이즈(88 번의 기술 구성 유지).

| 박자 | 플레이어가 하는 것 | 연출 |
|---|---|---|
| 입장 | 격벽을 지나 승강장으로 | L3: 붉은 비상등이 하나씩 켜지고, 허수아비의 «눈»(시계 머리)이 열린다. 보스 이름 한 줄 |
| 1 페이즈 «거리» | 앞차기·원투 훅을 읽고 튕긴다 | 튕김마다 L1. 맞대기(완벽)는 시간 0.25 배 + 카메라가 두 무기 사이로 붙는다 |
| 자세 붕괴 | 튕김이 쌓여 보스가 무릎 꿇음 | L2: 처형 한 컷(카메라가 옆으로 돌아 들어감) → 게임 카메라 복귀 |
| 페이즈 전환 | — | L3: 보스가 일어나며 눈이 붉게 타오르고 조명이 더 붉어짐, 바닥에 물이 번짐 |
| 2·3 페이즈 «반격» | 돌진(옆으로 피함)·회전(막기 불가)·도약을 구분 | 큰 기술 직전 L2 짧은 예고 컷(0.8 초, 조작 유지 가능한 «슬로 예고» 로 대체 가능) |
| 격파 | 마지막 처형 | L3: 느린 마지막 일격 → 비상등이 꺼지고 형광등이 돌아옴(승리 = 빛) |

## 5. 연출 언어 (카메라 · 시간 · 빛 · 소리)

### 5-1. 카메라

| 모드 | 쓰는 때 | 규칙 |
|---|---|---|
| 탐색 | 걸을 때 | 어깨 너머, 스스로 거의 안 돎(84 멀미 기준) |
| 전투 | 락온 | 3/4 등 뒤, 캐릭터 왼쪽·보스 오른쪽(101) |
| 순간(L1) | 받아친 순간 | 거리 -15~25 %, 화각 -4°, 흔들림은 타격 방향으로 한 번. 0.3 초 안에 복귀 |
| 흐름(L2) | 처형·궁극기 | 미리 정한 2~3 개 구도 중 벽에 안 막히는 것 자동 선택. 컷 없이 날아가서 찍고 돌아옴 |
| 이야기(L3) | 등장·전환·격파 | 보스 정면 낮은 구도 → 전투 카메라로 이어짐 |

금지: 화면 기울기 상시 사용, 1 초 넘는 흔들림, 플레이어가 안 돌린 180° 회전(멀미).

### 5-2. 시간

- 히트스톱(66·74)·카운터 3 단 멈춤(51)은 그대로.
- **느린 시간은 «판정 확정 뒤» 에만** — 판정 전 슬로는 난이도를 바꾼다(0.16 초 입력 버퍼 계약 유지).

### 5-3. 빛 (조명이 게임 상태를 말한다)

- 보스 분노 = 비상등 맥동이 빨라짐. 페이즈가 오를수록 붉은 빛이 늘고 형광등이 더 꺼진다.
- 맞대기 성공 = 한 프레임 흰 빛 + 비상등 순간 꺼짐.
- 격파 = 형광등이 다시 켜진다. **빛이 돌아오는 것이 승리의 보상.**

### 5-4. 소리

- 받아친 순간 배경음 0.2 초 뚝 끊김 → 금속음만. 처형 때 음악 한 박 쉼.

## 6. 캐릭터별 «시네마틱 시그니처»

91 번의 캐릭터 전투 언어를 연출로 확장한다.

| | 전투 언어(91) | 시그니처 연출 |
|---|---|---|
| 아인 | 월광 유도형, 큰 원호 | 맞대기 성공 시 낫 궤적이 달빛 반원으로 남는다 · 처형: 보스 뒤로 돌아 들어가 한 번에 벤다 |
| 카인 | 철괴 압축형 | 튕김 때 바닥이 갈라지고 먼지 · 처형: 대검을 머리 위에서 내리꽂는 «멈춤이 가장 긴» 한 컷 |
| 류 | 연속 탄성형 | 완벽 회피 뒤 잔상 3 개가 동시에 벤다 · 처형: 짧은 컷 여러 개(연속 베기) |
| 세라 | 정밀 제어형 | 시약 폭발 순간 느린 시간 + 연기 속 실루엣 · 처형: 거리를 두고 투척 → 폭발 역광 |

## 7. 시스템 — «연출 감독(Cinematic Director)»

지금은 히트스톱·슬로·카메라 킥·페이즈 컷이 `game3d.js` 곳곳에 따로 있다. 하나로 모은다.

```
전투 이벤트(combat.js / raid.cjs 가 이미 내는 것)
  deflect / repel / clash / perfectDodge / poiseBreak / execute / phase / ult / bossBigTell
        ↓
연출 감독  ── 예산 검사(단계별 길이·빈도·조작 뺏김 누적 8 %)
        ↓ 통과하면 «연출 한 박자» 를 재생
  카메라 트랙 · 시간 배율 · 조명 큐 · 소리 큐 · 후처리(블룸·비네트)
```

- 판정·수치는 절대 안 바꾼다(연출은 보이는 것만). 온라인은 서버 이벤트를 받아 같은 연출을 각자 화면에서 재생.
- 연출 정의는 데이터(표)로: `{ id:'clash', tier:'L1', time:0.25, dur:0.35, cam:'push', light:'flashWhite', sound:'cutBgm' }` — 기획이 표만 고쳐 조정.
- 설정: «연출 강도» 3 단계(영화 / 기본 / 최소) — 최소는 L1·L0 만.

## 9. 순서 제안

1. **연출 감독 + L1** (받아친 순간 연출) — 가장 자주 보이고 «시네마틱» 이 체감되는 곳. 아인·카인부터.
2. **L2 처형 구도 선택기** + 카인·아인 처형 컷.
3. **조명 큐**(분노·페이즈·격파 빛).
4. 서한역 배경 미술 → 보스 모델 → 모션 교체(100 번).

## 10. 디렉터가 정할 것

1. 한 줄 정의(1 장) 문구 — 이대로 갈지, 고칠지.
2. 연출 강도 기본값: «기본»(L0~L2, L3 첫 회만) 이 맞는지.
3. L2 에서 조작을 뺏는 것 허용 범위(지금 안: 최대 2.5 초·무적).
4. 격파 때 «빛이 돌아온다» 같은 조명 서사를 게임 전체 규칙으로 할지(던전마다 «꺼진 빛을 되찾는» 구조).
