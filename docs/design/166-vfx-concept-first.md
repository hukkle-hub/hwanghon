## 1. 영상의 방법

| 단계 | 영상에서 한 것 | 우리 쪽 |
|---|---|---|
| 1. 콘티 | 기술마다 **인터랙티브 2D 콘티**를 먼저 만든다. 컨셉 위키에 V01…V09로 버전을 쌓는다. «Motion study» 탭에는 효과 계열별 무대, 재생·일시정지·속도, 단계 마커(Cast → Bind → Channel → Complete → Clear)가 있는 타임라인이 있다 | `tools/vfx/scarecrow-motion-study.html` |
| 2. 참고 라이브러리 | Cartoon FX(Jean Moreno) 같은 기성 이펙트 팩을 보고 원하는 효과를 **말로** 정확히 지정한다 | Fab에 추가한 팩: Niagara Examples, Realistic Starter VFX, Easy Shockwaves, M5 Fire, 소리는 Whoosh·Low End Impacts |
| 3. 부위를 따로 | 캐릭터를 몸통·머리·가지로 **나눠서** 생성하고 잎은 별도 재질로 둔다. 그래야 따로 움직이고 떨어진다 | 허수아비의 머리 자루, 가슴판·밧줄, 팔뚝, 다리 짚을 **별도 메시**로 둔다(절단·부위파괴의 전제) |
| 4. 애니메이션 | Mixamo 기본 클립을 가져와 교정한다. 영상 참고로 자세를 고친다 | Mutant(거구) + Injured(부상) 세트 — 디렉터 로그인 대기 |
| 5. 여러 층 | 3D 오브젝트(뼈대 애니) + 게임 안 입자 + 화면 효과를 겹친다 | 레이어 주문서: 몸 동작 · 몸의 머티리얼(문양) · 입자 · 바닥 예고 · 화면(흔들림·슬로·색) · 소리 |
| 6. 타이밍 문장 | 최종 콘티를 «꽝 → 뿌리 연결 → 해제»처럼 시간과 함께 적어서 에이전트에게 넘긴다 | 탭마다 단계 표(시점 s)와 UE 구현 열 |

핵심은 순서다. **엔진에서 만들어 보고 고치는 게 아니라, 2D에서 타이밍을 합의한 뒤 엔진으로 간다.** 우리가 문서 162–163에서 실패한 이유(결과물을 먼저 만들고 디렉터가 «의미가 없다»고 판정)와 정확히 반대 방향이다.

## 2. 적용: 허수아비 모션 스터디

페이지: https://claude.ai/artifact/HGEDPj9ys3LEVXKDrfgNno (원본 `tools/vfx/scarecrow-motion-study.html`)

- 시간은 전부 코드의 값이다.
  - `HWBossCanonRules.cpp` Spin: 예고 1.3 s, 타격 0.55 s(1.42 · 1.59 · 1.76), 회복 0.9 s, 반경 260 cm
  - Elbow: 0.28 / 0.3 / 0.8 s, 타격 +0.1 s
  - 숨 한 번 2.0 s, 낫 하나 길이 150–240 cm
  - 절단: `HWStoryDirector` 0.25배속 실시간 1.2 s, 채도 1.45 · 대비 1.15 · 색수차 2.5
  - 부위: `HWBossSystemComponent` head 90 / armor 135 / limb 115
- 탭 7개
  1. 회전 · 숨 예고
  2. 팔꿈치 반격
  3. 카인 되받아치기 · 숨 한 번
  4. 절단 · 결정 이탈
  5. 부위파괴 · 머리
  6. 부위파괴 · 갑주
  7. 부위파괴 · 팔다리(다리/팔 전환)
- 부위파괴 탭은 «파괴 전 동작 겹쳐 보기»로 걸음·대기가 어떻게 달라지는지 같은 화면에서 비교한다(디렉터: «부분파괴후의 걸음걸이라던가 모션도 달라야돼»).
- 입자는 시간의 순수 함수라서 타임라인을 끌어도 같은 장면이 나온다.
- 확인: Playwright로 7탭 × 핵심 시점을 렌더했다. 콘솔 오류 0, 폭 400 px에서 가로 넘침 0.

## 3. 콘티에서 정한 것(승인 대기)

- **예고는 크기로 말한다.** 큰 기술(회전)은 온몸의 문양 + 바닥 원 + 숨(무음·흡입·비네트)이다. 짧은 기술(팔꿈치)은 팔꿈치 한 점만 켠다.
- **문양은 힘이 흐르는 길(어깨 → 팔꿈치 → 손끝)을 따라 찬다.** 되받아치기에서는 반대로 손끝부터 꺼진다. 약점(이음매)은 그 길 위에서 주황으로 맥동한다. 소설 L551을 화면 규칙으로 옮긴 것이다.
- **절단은 부위가 따로 떨어진다.** 팔뚝은 처음부터 별도 메시로 둔다. 쓰러진 뒤에는 결말대로 회색 가루로 흩어진다.
- **제안:** 코드의 `limb` 부위를 팔·다리 둘로 나눈다. 다리는 절뚝임(보폭 45 %, 속도 0.6배), 팔은 한 팔 반 바퀴 회전으로 동작이 서로 다르기 때문이다.
