# 173 — 붉은사막 타격 VFX 분석 (2026-10-01)

디렉터가 보낸 쇼츠 «붉은사막 타격감 고트 웅카»(@GyangJust, 33초, 보스 Hemon Beindel)를 프레임 단위로 읽었다. 받은 영상은 분석용 임시 파일이고 저장소에는 넣지 않았다. 생각만 가져오고 그림은 베끼지 않는다.

## 1. 장면 순서 (시간·구성)

| 시각 | 장면 | 구성 |
|---|---|---|
| 2.8–3.2 | 예고 0.4 s | 몸에 서리 갑옷이 덮이고 발밑이 언다(캐릭터 자체가 바뀐다) |
| 3.2–6.6 | 회전 3.4 s | **가는 붉은 고리 여러 겹**이 바닥 가까이에서 돈다. 0.3–0.5 s마다 **흰 바늘 방사** + 흙덩이 |
| 6.8–7.0 | 마무리 | 세로 붉은 호 하나 + 큰 바늘 폭발 |
| 7.3–7.8 | 여운 0.5 s | 얼음 안개가 퍼지고 바닥에 얼음 조각이 남는다 |
| 15.1 | 일격 1프레임 | 점 섬광 + **가는 빛줄기 하나**(렌즈 스트릭) |
| 15.25–15.4 | 0.13 s 뒤 | 불꽃 **줄기**(점이 아니라 늘어난 선)가 고리 모양으로 퍼지며 꺼진다 |
| 15.8–16.3 | 띄우기 | 땅에서 흙 파편이 튀고 적이 공중으로 날아간다. 카메라가 물러난다 |
| 25.1–25.7 | 얼음 타격 | 청백 파편 + 회색 안개 0.5 s |
| 26.9–28.5 | 연타 1.6 s | 카메라가 바짝 붙고 **불꽃 샤워가 끊기지 않는다**(그라인더처럼). 가로 빛줄기가 섞인다 |
| 28.9 | 연타 끝 | 검은 파편 + 흰 줄기 폭발 |
| 29.7 → 32 | 잔불 | 타격점 화염, 바닥 불씨 2–3 s |

## 2. 원리 — 우리 1차 이펙트(문서 171)와 비교

1. **타격은 «줄기»다.** 짧고 빠르고 가는 선 불꽃(속도 방향으로 늘린 스프라이트)이 0.2–0.4 s 산다.
   - 우리는 부드러운 빛 고리와 블룸이라 «번쩍»은 있지만 «쨍»이 없다.
2. **한 프레임 렌즈 스트릭.** 맞는 순간 가로(또는 사선) 빛줄기 하나가 한 프레임만 나온다. 우리는 없다.
3. **두 색을 나눈다.** 기술의 색(붉은 고리)과 맞은 재질의 반응 색(얼음은 청백, 갑옷은 주황 불꽃, 땅은 흙색)이 다르다.
   - 우리는 영웅 색 하나로 다 칠했다. 몬헌 원칙(문서 167 «예고 빨강, 타격은 다른 색»)과 같은 이야기다.
4. **재질 반응.**
   - 땅: 흙덩이 + 먼지
   - 갑옷: 불꽃
   - 얼음: 파편 + 안개
   - 허수아비라면 지푸라기와 먼지일 것이다.
   - 우리는 대상과 상관없이 같은 효과를 쓴다.
5. **지속형 궤적은 가늘다.** 회전기는 굵은 초승달 하나가 아니라 가는 고리 여러 겹이 기술 시간 내내 돈다.
   - 우리 궤적은 두껍고 크림색으로 번진다.
6. **연타는 이어진 흐름이다.** 1.6 s 동안 섬광을 따로따로 터뜨리지 않고 샤워 하나로 이어 간다. 류 «난무»·«붉은그림자»에 그대로 맞는다.
7. **여운과 잔여물.** 안개 0.5 s, 바닥에 얼음 조각이나 불씨가 2–3 s 남는다. 허수아비(문서 167)에는 넣었지만 영웅에는 없다.
8. **카메라도 연출이다.** 연타 때 바짝 붙고, 띄우기 때 물러난다. 경직은 짧다.

## 3. 적용안 (디렉터 승인 뒤 엔진)

| 순서 | 무엇 | 어디에 | 재료 |
|---|---|---|---|
| 1 | 줄기 불꽃 + 1프레임 스트릭 | 모든 타격 | Niagara 방향성 버스트(엔진 템플릿 복제, 색·수·속도는 C++ 사용자 파라미터) |
| 2 | 재질 반응 표 | 맞은 대상(허수아비=지푸라기·먼지, 갑옷 보스=불꽃, 땅=흙) | 보스 프로필에 `HitMaterial`을 추가하고 Grux 잔해·먼지 재사용 |
| 3 | 가는 고리 여러 겹 | 아인·카인 «회전» | 링 메시 + `M_HW_TrailAdditive`(얇게), 기술 시간 내내 회전 |
| 4 | 연타 샤워 | 류 «난무», «붉은그림자» | 1번 버스트를 타격 간격보다 촘촘히 이어 붙인다 |
| 5 | 여운·잔여물 | 세라 병 터짐(안개 0.5 s), 카인 «모루»(흙덩이·바닥 균열), 아인 궁극(바닥 불씨) | 허수아비 residue 방식 |
| 6 | 카메라 | 궁극 연타는 붙고, 띄우기는 물러남 | 기존 카메라 셰이크/거리 |

하지 말 것:
- 화면 전체 블룸. 1차에서 이미 겪었다.
- 기술마다 다른 색을 다섯 가지 넘게 쓰는 것. 기술 색 하나 + 반응 색 하나로 한다.
- 휴대폰에서 버스트 하나에 파티클 수백 개. 1번은 Android에서 개수를 먼저 잰다.
