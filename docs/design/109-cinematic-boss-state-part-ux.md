# 109 — 보스 상태 · 자세 · 부위 내구도 UX v08 (2026-09-27)

## 목적

보스의 상태 정보를 화면 오른쪽의 범용 상태 카드에 반복 표시하지 않고, **보스에게 속한 정보는 보스바와 선택 부위 줄에서 읽히게** 정리한다. 전투 규칙은 바꾸지 않는다.

## 변경

- `출혈 ×N`은 기존 보스 HP 옆 `b-stack`에만 남긴다. 우측 status에서는 제거한다.
- 자세 게이지 왼쪽에 `STAGGER`, 다운 상태에서는 `BREAK`를 표시한다.
- 평상시 자세 게이지는 기존 `enemy.posture / R.posture.max`, 다운 중에는 기존 `enemy.downT / R.posture.downDur`의 **남은 시간 비율**만 표시한다. `downDur` 자체는 변경하지 않는다.
- 선택 부위 줄 하단에 1px 내구도 선을 추가한다. 기존 part HP 비율을 그대로 사용하고 35% 이하에서 붉게, 파괴 시 흐리게 표시한다.
- 우측 status에는 `튕기기 불가`, `반격 기회`, `방어`, `결의`, `치명타 확정`, `경직`처럼 플레이어가 **지금 바로 반응해야 하는 정보**만 남긴다.

## 금지

- `combat.js` 변경 금지.
- 피해량, 자세 증가량, `R.posture.max`, `R.posture.downDur`, 처형 가능 조건, 부위 HP, 타겟 선택 규칙 변경 금지.
- 새로운 상태 타이머를 만들지 않는다. 기존 snapshot 값을 표시만 한다.
