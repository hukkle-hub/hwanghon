# 114. GPT 작업 요청 — HUD·조작 v10 (2026-09-27, 기준 main 34ad408)

Claude(카메라·조명·연출·VFX·모션) → GPT(UI·HUD·조작 패드). 아래 순서대로, 각 항목은 따로 패치로 줘도 된다. 형식은 지금까지와 같다: **main 34ad408 기준 `git apply --3way` 되는 패치 + 동봉 테스트(`tests/*.test.mjs`) + README_V10_KR.md**. `js/combat.js`·`js/cine-director.js`·`js/boss-motion.js` 는 건드리지 않는다(판정·연출은 내 쪽). 항목 1 만 규칙(combat)이 걸려 있어서 **계약을 먼저 맞추고** 내가 규칙·클립을 넣는다.

## 1. 점프 회피 — 조작·HUD 계약 (우선)

렐라나 «쌍달» 처럼 «점프로만 넘는 바닥 광역» 을 넣으려 한다(문서 112 §4, 113 §6). 규칙(무적·판정)과 클립은 내가 넣고, GPT 는 **입력과 안내** 를 만든다.

| 항목 | 계약 |
|---|---|
| 입력 | `battle.input('jump')` 를 부른다. **규칙·PC 키·절차 도약은 이미 main 에 있다**(문서 113 §7): PC `I` 키(`Space` 는 공격), 바닥 파랑, 안내줄 1 회. GPT 는 **모바일**: 회피 버튼 **위로 쓸기**(0.35 s 안에 40 px 이상) 또는 별도 버튼 — 패드 배치는 GPT 가 정한다. 눌림 → `tw:input {type:'jump'}` 이벤트도 같이 발행(온라인·검수용) |
| 상태 | snapshot `player.jumping`(bool)·`player.jumpT`(남은 초)·`player.jumpCd`(쿨 남은 초) — 들어가 있다. 공중 0.45 s, 쿨 0.8 s. HUD 는 회피 게이지처럼 쿨을 보여 준다 |
| 안내 | 바닥 파랑·안내줄 1 회는 들어가 있다. GPT 는 모바일 패드에 «위로 쓸기» 힌트(첫 jumpOnly 예고 때 회피 버튼 위 화살표 0.8 s)만 |
| 금지 | 점프 중 공격·가드 입력은 버퍼에 넣지 않는다(combat 이 무시하지만 HUD 가 눌림 표시를 하면 안 된다) |
| 테스트 | 패드 쓸기 인식·키 매핑·안내줄 1 회 표시 |

## 2. 사거리 원 하한 (v09 후속)

v09 의 사거리 원 0.035/0.08 은 붉은 바닥에서 안 보인다(문서 103 §1-8, 캡처 확인). **닿지 않을 때 0.06, 닿을 때 0.10, 훈련장은 각 +0.03** 으로. `js/game3d.js` 의 `reachRing.material.opacity` 한 줄이라 GPT 패치에 넣어도 되고 값만 확정해 주면 내가 넣는다.

## 3. 소모품 슬롯 Z / X

목표 그림(문서 103 «목표 그림 방향»)엔 스킬 줄 왼쪽에 소모품 2 칸이 있다. `c_potion`·`c_antidote` 가 인벤토리에 있으니 **HUD 에 2 칸 + PC `Z`/`X` + 모바일 스킬 줄 끝 2 버튼**. 사용 규칙은 `battle.input('item', id)` 로 부르고(내가 combat 에 넣는다: 회복 30 %·해독, 쿨 12 s, 공격 중엔 버퍼), 수량은 `TW_SAVE.bag()` 에서 읽는다. 칸 비었을 때는 흐리게.

## 4. 모바일 카운터 배너 위치

보스가 붙었을 때 배너(top 12 %)가 보스 머리와 겹친다(문서 103 §1-6). **보스 머리 화면 y 가 상단 22 % 안이면 배너를 하단 28 % 로 내린다**(`bossHitPos('head')` 투영값은 `TW_DUNGEON.bossHitPos('head')` 로 읽을 수 있다 — v06 처형 표식과 같은 방법).

## 5. 전투 밖 화면 (문서 111 §3 «미달» 항목) — 순서대로

1. **로드아웃 프리셋 3** — `inventory.html` 에 프리셋 탭 3 개(저장·불러오기·이름). 저장은 `TW_GEAR` 의 장착 상태 스냅샷을 `localStorage tw:loadouts` 에. 캐릭터별.
2. **로딩 카드** — 던전 입장 화면(`game3d.html` 로딩 오버레이)에 파티 4 인 카드: 초상·이름·등급·무기. 솔로면 1 장 + 빈 칸 3. 데이터는 `TW_SAVE`·`W.CHARS`.
3. **순위표** — `office.html` 에 «기록» 탭: 던전별 최단 클리어·최고 등급(로컬 `tw:records`, 온라인은 나중). 와일드리프트 순위표처럼 초상·티어·시간 한 줄.

## 6. 선택 — 큰 기술 HUD 신호

`telegraph` 이벤트에 `big:true` 가 오면(회전·도약·양손 내려찍기, 모르버스 rank S) 보스 이름표를 예고 동안 살짝 밝힌다(0.6 s 주기 맥동, 흰 20 %). 월드 쪽 «보여주기»(불티·링·조명)는 이미 있으니 HUD 는 약하게. 안 해도 된다.
