# 206 — 3D 필드: 구운 2D 맵의 원본 장면을 실시간 3D로 (2026-10-08)

디렉터: «일단은 지피티가 하고 있으니 겹치지 않게 맵을 좀 3d로 구현하고 뽑아보자» · «위에 사진보면 무기도 제대로 못 잡고 있네?»

## 1. 무엇을 — `world3d.html?zone=<id>&char=<id>`

2D 필드(`mmo.html`)의 맵은 원본 3D 장면(`js/mmo/env-*.js` — OSM 실측 건물·도로·소품·결정)을 55° 고정 정사영으로 **구운 그림**이다.
그 원본 장면을 굽기(`tools/2d/bake-map.html`)와 **같은 빌더**로 실시간에 세우고, 3인칭 카메라로 걷는다. 자리·충돌·보스 위치가 2D 필드와 1:1 이다.

| | |
|---|---|
| 장면 | 굽기와 같은 `ENV_FILE` 표 (시험으로 묶음) · 지역 표 `ZONES` |
| 걷기 | `js/mmo/field-collide.js` — mmo.html 의 띠·상자·건물 윤곽·강 띠 규칙을 그대로 옮김 (시험이 두 본문을 대조 — 한쪽만 고치면 실패) |
| 영웅 | 온라인 레이드와 같은 `Animated`(js/party-avatar.js): 아인 바인드·클립 교정 + 양손 쥠 리그 + 솔로와 같은 낫 장착 |
| 2급 지배형 | 같은 자리 · 같은 임시 몸 (문서 204) |
| 카메라 | 오른쪽 끌기 회전 · 휠/두 손가락 거리 · 사이에 1.2 m 넘는 것이 있으면 그 앞까지 당김 (당길 땐 빠르게, 물러날 땐 천천히) |
| 휴대폰 | 왼쪽 45% = 이동 스틱 · 나머지 = 카메라. Pixel 7 가로·세로 가로 넘침 0 |
| 안개 | 70~230 m 노을 안개 — 굽기엔 없던 지평선·띠 끝을 덮는다 |

## 2. 실시간으로 돌리려고 바꾼 것 (장면 빌더는 그대로)

- **점광**: 장면에 수십 개(강남 95) — 실시간이면 셰이더가 터진다. 빼고 데이터만 두어 가까운 8개(휴대폰 4)만 옮긴다 (mmo.html nearLights 와 같은 수법).
- **정적 합치기** `js/mmo/static-merge.js`: 같은 값 재질을 하나로(강남 재질 1,610 → 대부분 중복) · 같은 재질 + 48 m 칸끼리 한 메시. 칸으로 나눠야 화면 밖 덩어리가 빠진다.

| 지역 | 메시 | 그리기 호출 | 삼각형 |
|---|---|---|---|
| 강남대로 | 11,110 → 1,380 | 2,521 → 546 | 37만~60만 |
| 서귀포 | 4,889 → 632 | 1,920 → 372 | 48만~110만 |
| 남산 | 7,842 → 562 | — → 176 | 61만 |

  같은 시점에서 합치기 전·후 그림이 같다 (`.node-shots/w3d/merge-compare.png`).
- **해 그림자**: 내 둘레 ±34 m 만 (휴대폰 1024²).

## 3. 무기 쥠

처음엔 영웅 GLB 에 장비만 달아 낫을 **지팡이처럼 끝을 잡고 왼손이 놀았다** (디렉터 지적). 솔로·레이드는 아인 전용 교정(바인드·클립)과 양손 쥠 리그를
따로 거는데, 필드는 그걸 안 탔다. 3D 필드는 레이드 아바타를 그대로 써서 고쳤다 — 낫을 몸 앞에서 양손으로, 카인은 대검을 어깨에.
**2D 필드(mmo.html)는 아직 같은 문제가 있다** — 영웅 생성부에 같은 리그를 붙여야 한다 (장비 갈아입기 TW_LOOKS 와 겹쳐 따로 손볼 일).

## 4. 검수

- `tests/world3d.test.mjs` — 합치기(같은 재질·칸, 정점 수 보존, 월드 자리), 카메라 막이(낮은 턱 제외, 벽 앞 정지), 충돌(띠·윤곽 + mmo.html 본문 대조), 배선(빌더 표·점광·아바타·리그 순서).
  돌연변이 4종(재질 중복 제거 끔 · 칸 무시 · 높이 거르기 끔 · 밀어내기 거리 틀림) 모두 실패 확인.
- 검수 API `window.__W3D` — `hold`(찍는 동안 시간 정지) · `dtCap` · `view(pos, at)` 고정 시점 · `orbit` · `teleport` · `info()`(호출·삼각형·합치기 수).

## 5. 남은 것

- 원본 장면은 «위에서 보는 그림» 용 로우폴리라 3인칭 가까이선 건물이 상자, 바위가 큰 다면체로 보인다 — 3D 로 갈 거면 건물 외벽·잔해 에셋이 필요하다.
- 카메라 막이는 축 정렬 상자라 비스듬한 건물 옆에선 조금 일찍 당겨진다.
- 2D 필드의 무기 쥠 · 몬스터·전투(아직 걷기와 보기만).
