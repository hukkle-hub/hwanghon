# 169 — 4인 캐릭터 스킬: 현황과 콘티 (2026-10-01)

디렉터 순서(2026-09-30): 허수아비 → **4인 캐릭터 스킬** → 나머지 보스 스킬·모션 → 보스 던전 → 4인 캐릭터 외형(디자인 시트)

## 1. 현황 — 조사 결과

- **기준 데이터는 웹 게임 하나다.**
  - 스킬: `js/dungeons.js` SKILLS 173–204
  - 규칙: 45–75(타격 0.42/1.00 s, 아인 전용 박자), 135–140(무기 리듬 카인 1.2·류 0.82·세라 1.06)
  - `game_content.json`에 그대로 복사돼 있지만, UE는 `combat_rules.json`을 실행 중에 읽지 않는다.
- **UE는 스킬 20개를 코드로 다 갖고 있다**(`HWCharacterKitComponent`, `HWSystemRulesLibrary`). 그런데:
  - 네 명이 같은 Countess 동작 5개를 돌려 쓴다. 회피 스킬 셋이 전부 «앞으로 찌르기»이고, 세라에게 투척 동작이 없다.
  - **스킬 이펙트가 하나도 없다.**
  - 클립 비율(0.24 등)을 **초로** 써서 타격이 웹·서버와 어긋난다. 웹 아인 1번은 0.58 s, UE는 0.24 s.
  - 사거리·방향 판정이 없고(락온 대상에 무조건 맞음), 히트스톱도 없다. 스킬이 전투 상태 기계 밖에서 돈다. 출혈과 부위 파괴 배율은 일부만 있다.
  - 각자의 웹 동작 29개(`/Game/Heroes/*`)는 캐릭터 선택 화면에서만 쓴다.
  - 무기는 Countess 쌍검뿐이다. 낫·대검·단검·봉이 없다.
  - **폰 HUD에 스킬 버튼이 없었다** → 이번에 추가(§2).
- 소설과 데이터가 어긋나는 곳:
  - 세라: 소설은 봉 + 봉인, 게임은 시약병.
  - 류 «표식»: 효과가 방어 버프다.
  - 소설의 신호(아인 거리 띠, 카인 되받아치기)가 EP01 스토리 규칙에만 있다.

## 2. 이번에 한 것

- **폰 스킬 버튼**
  - 스킬 1–4 + 궁극기를 공격 버튼 위·왼쪽 호에 놓았다(`HWCombatHUD`).
  - 영웅별 스킬 이름(아인: 베기·걸음·회전·결의·황혼)을 쓰고, 쿨타임 중에는 남은 초를 보이며 흐리게 한다.
  - 키보드와 같은 경로를 탄다: 온라인이면 서버 먼저, 아니면 로컬 스킬(`AHWAinCharacter::PressAbility`).
  - EP01 전투 캡처로 배치를 확인했다.
- **콘티**: https://claude.ai/artifact/5thJgfcibLgFqQEoZxELiQ (원본 `tools/vfx/hero-skill-study.html`)
  - 20개 스킬을 웹 규칙 시간 그대로 재생한다. 다단 타격은 웹의 `timeOf`(clipHit → hitAt 재배치)를 쓴다.
  - 몬스터헌터식 층: 예고 섬광(0.42×타격 시점부터) → 궤적 → 타격 섬광·불똥·히트스톱(무기 리듬 배율) → 잔향
  - 영웅 색: 아인 주황, 카인 강철, 류 붉음, 세라 파랑. 세라 병 색은 효과별로 다르다(초록·주황·보라).
  - «결정이 필요한 것» 세 가지에 권장안을 붙였다.
  - 확인: Playwright로 20개를 타격 순간에 렌더. 콘솔 오류 0, 폭 400 px에서 가로 넘침 0.

## 2.5 타이밍·판정 (승인과 무관한 버그 수정, 같은 날)

- **타격 시각**: 웹의 `timeOf`를 그대로 옮겼다(`UHWCharacterKitComponent::AbilityClock / AbilityTimeOf`).
  - 웹 스킬 규칙 + 아인 전용 박자 + 무기 리듬 + 영웅·스킬별 클립 접점(`clipContactsByChar`)
  - 예: 아인 1번 0.24 s → 0.58 s. 세라 투척 = 놓는 시점 + 비행 + 폭발 간격.
- **카인 4번 자세 피해**: 24 → 30 (웹 값)
- **동작 맞추기**: 스킬 클립의 접점 프레임이 첫 타격 시각에 오도록 재생 속도를 계산한다(0.5–2.5배, 공격 속도 반영).
- **판정**
  - 단일 대상: 사거리 안(아인 310 · 카인 330 · 류 250 · 세라 1200 cm, 보스 캡슐 반지름 포함)이고 앞쪽 ±75°일 때만 맞는다. 예전에는 락온 대상이면 어디서든 맞았다.
  - 광역: 650 cm → 340–420 cm
- **히트스톱**: 스킬에도 넣었다. 0.10 / 0.13 / 0.18 s × 무기 리듬(카인 1.28 · 류 0.74 · 세라 0.86).
- `system-core-qa local` 전 게이트 통과
  - 류로 던전 완주
  - 스킬 1–4 사용 4/4/4/3회, 피해 15096/0/3485/1019
  - 궁극기 8회, 21600
