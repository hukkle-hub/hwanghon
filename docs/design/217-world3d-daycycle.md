# 217 · 3D 필드 시간대 — 황혼 · 밤 · 새벽 · 낮 (2026-10-09)

디렉터: «시간에 따라 배경이 좀 바뀌었으면». 분위기는 «우리 느낌 그대로» — 그래서 **황혼(지금 모습)이 기본이고 가장 길다**.

## 1. 바퀴
48분에 한 바퀴 (`js/mmo/daycycle.js` · `DAY_LEN`).

| 바퀴 위치 | 시간대 | 실제 시간 |
|---|---|---|
| 0.92 → 0.26 (이어서) | **황혼** — 존이 정한 값 그대로 | 약 16분 |
| 0.26 → 0.34 | 황혼 → 밤 | 4분 |
| 0.34 → 0.56 | **밤** — 남보라 하늘, 달빛(푸른 해·약함), 가로등 1.9배 | 약 10.5분 |
| 0.56 → 0.62 → 0.66 | 새벽 — 동쪽 분홍 지평선, 가로등 0.6배 | 약 5분 |
| 0.66 → 0.74 → 0.92 | **낮** — 잿빛 흐린 하늘(파란 하늘 아님), 해가 높다, 가로등 꺼짐 | 약 12분 |

- 시계: 온라인 = 서버 시각(`sclock`, 보스 패킷의 `bossNow`), 혼자 = 기기 시각 → **같은 필드의 사람은 같은 하늘**. 서버는 바꾸지 않았다.
- 해는 새벽 동쪽 → 낮 높이 → 황혼 서쪽으로 돈다. 밤의 «달» 은 같은 그림자 빛을 푸르고 약하게.
- 바꾸는 것: 하늘 돔(위·지평선·안개·빛무리), 안개색, 해(방향·색·세기), 반구광, 얼굴 비춤 빛, 노출, 가로등(점광) 세기. 0.5초마다.
- 안 바꾸는 것: 자리·막이·장면 난수. **실내(던전·벙커)는 돌리지 않는다.** 2D(`mmo.html`)는 손대지 않음.
- 존마다 결: 황혼 열쇠는 존 값 그대로, 다른 열쇠는 절대 색에 존 안개를 30% 섞는다(여의도 «안개 협곡» 은 밤에도 흐리다).
- 화면 왼쪽 위 «3D 필드 시험판 · 밤» 처럼 지금 시간대를 적는다.
- 해 보기: `world3d.html?tod=밤` (또는 `night` · `dawn` · `day` · `0~1` 숫자), 콘솔 `__W3D.tod('낮')`, 되돌리기 `__W3D.tod(null)`.

## 2. 잰 것
화면 평균 밝기(0~255, 휴대폰 가로 Pixel 7, 같은 자리):

| | 황혼 | 밤 | 새벽 | 낮 |
|---|---|---|---|---|
| 대전 | 55.7 | 43.0 (77%) | 65.3 | 81.0 |
| 강남 | 49.5 | 37.5 (76%) | 74.0 | 70.8 |

해 쪽을 바라볼 때 하얗게 날아간 픽셀(강남): 황혼 0.04% · 새벽 **1.12% → 0.05%** · 낮 0.01%.
- 함정: 강남 새벽 첫판에 화면 한가운데 큰 빛 덩이 — 하늘이 아니라 **젖은 도로(거칠기 0.34)에 비친 낮은 해**. 점광을 다 꺼도 그대로여서 알았다. 황혼에도 같은 반사가 있지만 서쪽은 건물이 해를 가려 안 보였고, 동쪽은 대로가 트여 있었다 → 새벽 해를 26° · 세기 0.35배로.
- 낮 첫판은 하늘이 너무 하얘 글씨가 묻혔다 → 하늘을 잿빛으로 낮추고 노출 1.0. 지역 이름·부제 글씨 그림자 보강.
