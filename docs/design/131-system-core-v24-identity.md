## 2. 고친 것 (최신 main 문맥, 최소 수정)

### 2-1. 서버: 치명·이속이 캐릭터 시트를 덮어썼다

- `server/rpg-store.cjs` 가 `stats()` 를 감싸면서 치명을 `5% + 장비`, 치피를 `150% + 장비`, `moveMult` 를 1 로 다시 썼다.
- 게다가 시작 무기의 치명(예: 습지 낫 6.5%)이 시트 값(이미 포함) 위에 한 번 더 붙었다.
- 수정:
  - 치명·치피는 **캐릭터 기본값 + 장비 보너스** 로 계산한다.
  - 주무기는 ATK 배율처럼 **시작 무기 대비** 로 센다.
  - `moveMult` 는 캐릭터 이속 × 장비로 계산한다.

### 2-2. UE: 수명주기 테스트 5 개가 깨졌다

아래 다섯 테스트가 깨졌다. 모두 보존 대상인 사망 수명주기 테스트다.

- `PlayerDeathLifecycle`
- `PlayerReentrantDeath`
- `PlayerLivingCombatPreserved`
- `BossReentrantDeath`
- `GameModeQuestOutcome`

원인은 두 가지다.

- 테스트는 원시 수치를 가정한다: `체력 + 100 = 치명`, `HitAt - 0.01 이면 접촉 전`.
- 델타가 DEF 25% 감소와 공속 시계를 실제로 적용했다. 그래서 치명타가 치명이 아니게 되었다.
- `HWCombatComponent` 기본값도 Ain 의 DEF·치명(1780, 18.2%)이었다. 그래서 설정 전 폰에도 무작위 치명이 들어갔다.

수정:

- 기본값을 중립(DEF 0, 치명 0, 치피 1)으로 바꿨다.
- 시트는 `ConfigureCharacterStats` 로만 들어간다.
- `UseNeutralCharacterModifiers()` 를 추가했다. 세 수명주기 테스트 픽스처에서만 부른다.
  - **단언은 한 줄도 바꾸지 않았다.**
  - 캐릭터 차이는 §1 의 실측 테스트가 따로 본다.
- `ResolveBaseDamage` 가 시트 미적용일 때 1 을 돌려주지 않게 했다(기존 Attack1 피해로 폴백).

### 2-3. UE: 로컬 보스 HUD 최대 HP

- 델타의 `GetMaxHealth()` 는 로컬에서 280000 으로 고정이었다.
- 던전 디렉터가 `ConfigureSystemHealth` 로 바꾼 보스는 막대가 틀렸다.
- 이제 로컬에서도 설정값을 돌려준다.
