## 2. 전략 — 준비, 정책, 전력, 보급

### 준비 단계
침공 전 **준비 시간 = 20초 + 정찰병 10초 + 정찰 강화 정책 20초** (`PrepSeconds`).
정찰이 살아 있으면(또는 정책이 있으면) 다음 웨이브 구성이 미리 보인다 (`WavePreview`).
준비 중에 할 수 있는 일:

- **바리케이드 짓기**: 자리에서 G, 보급 3 소모. 길드 권한 `InvestFacility` 또는 `AllocateSupply` 가 필요하다.
- **기술자 명령**: 정문 → 발전기 → 통신 → 복귀 순서로 바꾼다 (`OrderNpc`).
- 침공이 시작되면 바리케이드는 더 못 짓는다.

### 정책 (관리 길드가 고른다 — 예산 10, 전부는 못 고른다)

| 정책 | 비용 | 효과 |
|---|---|---|
| 정문 강화 | 4 | 정문 체력 ×1.5 |
| 발전기 강화 | 4 | 발전기·포탑 체력 ×1.5 |
| NPC 무장 | 3 | 경비병이 정문에서 사격(150/s) |
| 정찰 강화 | 3 | 준비 +20초, 웨이브 예보 |
| 의료 비축 | 3 | 의무실 회복 ×1.6, 회복약 +3 |
| 예비 전력 | 4 | 발전기가 무너져도 90초 비상 전력 |

### 전력
포탑은 발전기 전력으로 돈다 (`EffectivePower`). 발전기가 무너지면 포탑이 멈춘다. 단, 예비 전력
정책이 있으면 90초를 버틴다. 그래서 «파괴자가 숲길로 발전동을 노린다» 가 실제 위협이 된다.

### 적의 판단
역할마다 길과 목표가 다르다 (`ChooseTarget`, `role_routes`).

- 일반·엘리트: 정면 대로. 플레이어가 600 안에 없으면 380 안의 포탑을 친다.
- 질주형: 서·동 우회로. 길 위의 바리케이드를 먼저 부순다.
- 파괴자: 동측 숲길로 가서 발전기를 노린다.
- 추적자: 서측 순환로로 돌아 NPC 를 노린다.

정문이 서 있으면 정문 줄을 넘지 못한다 (`BlockedByGate`).

## 3. NPC — 상점이 아니라 거점의 일부

| 역할 | 하는 일 | 잃으면 |
|---|---|---|
| 기술자 | 명령받은 시설로 걸어가 400/s 수리 | 수리 없음 |
| 의무병 | 의무실(3 m)에서 초당 최대 체력 8% 회복 | 회복 없음 |
| 정찰병 | 준비 +10초, 웨이브 예보 | 예보 없음 |
| 통신병 | 구조 신호 | 구조 신호 꺼짐 |
| 경비병 | (NPC 무장 정책 시) 정문 사격 | 사격 없음 |

**상태는 정상 → 부상 → 실종 순서로 떨어진다.** 기능은 정상 1, 부상 0.5, 구조 직후 0.6, 실종 0 이다.

- 실종된 NPC 는 포로 자리로 끌려간다.
- 플레이어가 그 자리에서 G 를 누르면 구조된다. 구조된 NPC 는 집으로 돌아가 60초 회복한다.
- 추적자가 NPC 를 노리는 이유가 이것이다. 지키지 못하면 거점의 기능이 하나씩 꺼진다.

## 4. 길드 — 직책은 실제 권한이다

| 직책 | 권한 |
|---|---|
| 길드장 | 전부 + 대장 임명 |
| 부길드장 (기존 «임원») | 대장 임명 빼고 전부 — 정책 선택 포함 |
| 전투대장 | 핑·집결·NPC 명령 |
| 보급대장 | 보급 배정 |
| 제작대장 | 시설 투자(바리케이드)·NPC 명령 |
| 길드원 | 없음 (싸우는 건 누구나) |

- **핑**(전투대장 이상): 15초 안에 800 cm 안에서 나온 처치가 핑을 찍은 사람의 «지휘» 공헌이 된다.
- **공헌 장부** (한 판):
  - 처치: 역할 가중 (질주 1.2 · 파괴자 2 · 추적자 1.5 · 엘리트 5).
  - 방어: 시설·NPC 1500 cm 안에서 나온 처치.
  - 수리: 수리량 ÷ 100.
  - 구조, 보급, 지휘, 보스 딜.
  - 포탑·경비병 처치는 플레이어 공헌이 아니다 (`bLastHitByPlayer`).
- **점수**: 항목마다 «그 항목 1등 대비 몇 %» × 가중치(방어·구조 1.2, 보급·지휘 0.8, 나머지 1)로 매긴다.
  보스 딜만 많은 길드가 관리권을 가져가지 못하게 하려는 것이다.

## 5. 길드전 — 처치가 아니라 목표

8대8 또는 12대12, 15분 안에 1000점을 먼저 따는 쪽이 이긴다 (`FWarMatch`).

- 점수: 발전기·통신 지점을 쥐고 있으면 초당 1점, 코어 운반 +150, 지휘관 호위 +200, 시설 파괴 +100.
- **처치는 점수가 아니다** (통계로만 센다).
- 규칙과 시험까지만 있다. 맵·매칭은 아직 없다.

## 6. 서버 거점 상태 · 쉘터 화면

`server/node-store.cjs` 를 `store.cjs` 에 붙였다. `{type:'node', action}` 이 info / report / policy / supply / role
다섯 가지를 처리한다. 서버는 200ms 간격으로만 받는다.

- **함락은 실제 시간으로 흐른다.** 함락 후 2시간은 탈환할 수 없다. 이후 시간이 지날수록 단계가 오른다:
  기본(2h) → 엘리트 증가(6h) → 요새화(12h) → 감염 핵심지(24h). 난이도와 보상도 같이 오른다.
- **관리권은 지난 주기(1주)의 공헌으로 정한다.** 돈 입찰은 없다. 동점이면 먼저 만든 길드다.
  관리 길드가 바뀌면 정책은 비워진다.
- **관리권은 소유권이 아니다.** 누구나 거점을 보고, 누구나 쓴다. 관리 길드는 정책·보급만 정한다.
- **권한 검사:**
  - 정책: 관리 길드의 길드장·부길드장만, 예산 안에서.
  - 대장 임명: 길드장만.
  - 보급: 보급대장, 주기당 12까지. 배정한 만큼 «보급» 공헌이 쌓인다.
- **판 결과 보고:** held / fallen / retaken / retake_failed. 한 사람이 1분에 한 번만 보낼 수 있고,
  항목별 최대치에서 잘린다. UE 는 판이 끝나면 `Saved/HWNode/last_report.json` 을 이 형식으로 쓴다.
  아직 서버로 보내지는 않는다 — 온라인 연결은 다음 단계다.

**쉘터 «거점 관리» 카드** (`shelter.html` · `js/shelter.js`):

- 명단 옆(372px)에 놓인다. 휴대폰에서는 명단 아래에 쌓인다.
- 표시: 상태, 점령 단계, 관리 길드, 정책, 보급, 정보 서비스, 내 직책.
- 길드장·부길드장에게만 정책 칸이 보인다. 예산을 넘기면 «넘었습니다» 가 뜨고 확정 버튼이 잠긴다.
- 보급대장에게만 «보급 +3» 이 보인다. 12/12 가 되면 버튼이 잠긴다.
- 길드장은 명단에서 대장(전투·보급·제작)을 고른다.
- 다른 길드에는 «관리 길드 아님 (보기만)» 이 뜬다. 화면을 우회해도 서버가 거절한다.
