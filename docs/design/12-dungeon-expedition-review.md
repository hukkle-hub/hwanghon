# 황혼 — 던전 탐색·보스 공략 구현 기록

2026-09-18. 기준: main `cacc562` 위에 정밀 전투 커밋 `a530ad4` 및 이번 던전 변경을 통합했다.

## 플레이 흐름

사무소에서 훈련장을 완료하면 갈대습지가, 갈대습지를 완료하면 2경구 정화장이 열린다. 의뢰 페이지와 사무소에서 같은 진입 조건을 사용하고, 주소를 직접 열어도 이전 임무 완료 여부를 검사한다.

| 구역 | 탐색과 공략 | 결과 |
|---|---|---|
| 지하 훈련장 | 정비 지점, 3단계 허수아비, 카운터·회피·파괴 | 기술 등급 기록, 늪지 의뢰 개방 |
| 갈대습지 | 보급품, 정찰 기록, 배수 레버, 망루 야영지 | 모르버스 토벌, 정화장 의뢰 개방 |
| 2경구 정화장 | 북·중앙·남측 밸브, 주기적 분출, 정화 장치 회수 | 격벽 개방, 수문기 2단계, 전리품과 의뢰 정산 |

정비 지점은 체력·스태미나를 회복하고 재도전 위치를 기록한다. 조사한 지점과 차단한 밸브는 새로고침·사망 후에도 남는다. 정산 후에는 다음 출격을 새 탐색으로 시작한다. F/조사 버튼과 M/지도 버튼을 제공한다. 발견한 지점은 지도에 표시한다.

## 공략이 바뀌는 전투

공격 예고를 시작할 때 방향과 도착 지점을 확정한다. 공격 종류별로 예고 후반에 실제 보스가 전진한다. 이동과 타격 판정은 같은 10ms 전투 시계를 사용하며, 카운터·파괴로 중단하면 전진도 멎는다. 벽을 관통하는 이동·공격·조사·아이템 회수를 차단했다.

| 파괴 부위 | 이번에 추가한 패턴 변화 | 기존 약화 |
|---|---|---|
| 모르버스 앞다리 | 해당 단계의 돌진 베기 봉쇄 | 이동 속도 감소 |
| 모르버스 꼬리 | 해당 단계의 꼬리 휘두르기 봉쇄 | 공격 범위 축소 |
| 수문기 배출관 | 1단계 고압 분사·배출관 쓸기 봉쇄 | 공격 범위 축소 |
| 수문기 흡입관 | 배출관과 함께 파괴하면 핵 보호 해제 | 이동 속도 감소 |

변화는 해당 단계의 부위 상태를 기준으로 한다. 과압 단계는 새 패턴 구성이므로 1단계 봉쇄를 그대로 유지하지 않는다. 일반 타격은 공격 예고 클립을 끊지 않고 섬광으로 반응하며, 실제 경직·카운터·파괴에서 공격을 중단한다. 가까이 붙었을 때 같은 패턴만 반복하던 선택 로직도 교체했다.

모바일용 조준 부위 전환 버튼에 선택 부위의 내구도·노출 여부를 표시했다. 부위 선택은 공격 시작 때 고정되며 피해는 타격 시점에 계산한다. 현재 실제 플레이어 공격 판정은 거리·전방 각도·벽 검사다. 칼날 궤적과 각 부위 메시의 정밀 충돌은 아직 구현하지 않았다.

## 보존한 기반과 추가 모듈

기존 아인·허수아비·모르버스 GLB, 장비 외형 모듈, 등급·제작·강화·전리품을 사용한다. 수문기는 이름 있는 관절과 분리 가능한 배관으로 구성한 절차적 3D 모델이며 상용 캐릭터 에셋 수준으로 제작된 것은 아니다.

- `dungeon-content.js`: 탐색 데이터, 정화장 지도·보스·패턴.
- `dungeon-run.js`: 탐색 진행·조사·위험 구역·저장.
- `boss-director.js`: 공격 선택, 방향 고정, 충돌을 고려한 전진.
- `pump-boss.js`, `dungeon-props.js`: 수문기 관절 애니메이션과 조사 지점 시각화.
- `combat.js`, `world-sim.js`, `game3d.js`: 전투 시계, 충돌, 입력·연출·흐름 연결.

누락된 희귀 전리품 확률표 참조와 0회 카운터가 1회로 저장되는 오류를 수정했다. 늪지 지도 폭 정규화는 2D·3D 공용 데이터에서 처리한다. 컷신·페이즈 전환·사망 대기 중 일시정지가 동작하도록 게임 시계에 예약 작업을 연결했다.

정화장 통합 시뮬레이션은 실제 지도에서 정비대·밸브 3개·회수품까지 이동한 뒤 2단계 보스를 처치하고 결과를 산출했다. 해당 입력 정책에서 이동 38.9초, 보스 79.9/46.7초, 카운터 18회, 파괴 2회였다. 보스 전투 구간은 사거리 안에 있다는 가정의 규칙 테스트다. 인간의 평균 클리어 시간이나 브라우저 전체 플레이 검증으로 해석하면 안 된다.

수치상 아인 낫 그립 최대 오차 0.029m, 발 목표 오차 0.067m. 이 검사는 움직임이 자연스럽다는 시각적 판정을 대신하지 않는다. 다른 무기의 전용 그립·동작 검수도 필요하다.

변경 JS 18개와 HTML 인라인 스크립트 7개, import map JSON의 구문을 확인했다. 이 환경의 브라우저는 로컬 게임 주소에 `ERR_BLOCKED_BY_CLIENT`를 반환했다. 실제 화면·터치 조작·모바일 프레임 성능은 검수 완료로 표시하지 않는다.

## 실행과 반영

저장소 루트에서 `npm start` 또는 `START_WINDOWS.bat`. Node.js 24에서 검증했으며 서버 실행에 추가 패키지는 필요 없다. `http://127.0.0.1:8777`을 연다. 저장은 해당 브라우저의 로컬 저장소에 이루어진다.

GitHub 업로드는 사용자 승인과 별개로 현재 CLI 인증 부재 및 연결 앱의 쓰기 권한 403으로 완료되지 않았다. 전달하는 누적 패치는 main `cacc562` 기준이며 정밀 전투 커밋도 포함한다. 다른 도구에서 후속 수정이 진행됐다면 새 작업 브랜치에서 `git apply --3way`로 병합 검토한다. 기존 브랜치에 같은 정밀 전투 패치를 중복 적용하지 않는다.
