# 황혼 3D 에셋 제작 지시서 (GPT/Hi3D 작업자용) v1

이 문서는 그대로 GPT 에게 붙여 넣어 시키는 용도다. 결과물은 아래 **공통 규약**을 지켜야 코드 수정 없이 게임에 들어간다. 규약을 못 지키면 다시 만들지 말고 어긴 항목을 적어서 넘긴다(변환은 이쪽에서 한다).

## 0. 공통 규약 (모든 3D 파일)

| 항목 | 값 |
|---|---|
| 포맷 | glTF 2.0 **GLB 단일 파일**, Draco/메시옵트 압축 금지, 텍스처 내장 |
| 단위 | **1 unit = 1 m** |
| 축 | **Y-up**, 캐릭터 정면 **+Z**, 발바닥이 y=0, 좌우 중심 x=0 |
| 자세 | 캐릭터는 **A 포즈**(팔을 몸에서 15~20° 벌림, 손바닥 안쪽), 다리 어깨너비, 입 다물고 무표정 |
| 재질 | PBR metallic-roughness 1개(캐릭터) / 최대 3개(보스). **baseColor 필수**, normal·metallicRoughness 권장, emissive 는 발광 부위만 |
| 텍스처 | PNG, 2048² (소품은 1024²), UV 겹침 없음 |
| 폴리곤 | 캐릭터 ≤ 60k 삼각형, 보스 ≤ 90k, 소품 ≤ 5k, 무기 ≤ 15k |
| 이름 | 파일명 소문자 스네이크: `ain_pbr.glb`, `scarecrow_iron.glb`. 노드 이름은 아래 표대로 |
| 금지 | 리깅·애니메이션 넣지 말 것(이쪽 스크립트가 함), 씬에 카메라·조명 넣지 말 것, 바닥판 넣지 말 것 |
| 검수 | https://hukkle-hub.github.io/hwanghon/viewer.html 에 파일 선택 → 높이·원점→바닥 0.00·머티리얼 수가 표로 나온다. 스크린샷 첨부 |

## 1. 【최우선】 아인 컬러 텍스처 — `ain_pbr.glb`

지금 게임의 아인은 Hi3D 메시(37,679 정점)에 **컬러가 없다**(노멀맵만 있음). 색이 들어오는 순간 화질이 한 단계 올라간다.

- 원본: Hi3D 기록 `dark-fantasy-anime-female-assassin` (공유 링크 `hi3d.ai/share/...80cbc49c218e4038b3c0501ade6f9c67`). **이 모델에 "PBR 텍스처 생성"만 추가**한다. 새로 생성하지 말 것(메시가 바뀌면 리깅을 다시 해야 한다).
- 참조 원화: 4방향 시트(정면·좌·후·우). 검은 누더기 코트, 왼쪽 어깨 금속 견갑, 오른손 건틀릿, 붉은 안감, 검은 단발, 창백한 피부, 무릎 위 부츠에 붉은 선.
- 요구: baseColor + normal + metallicRoughness, 2048². 금속(견갑·건틀릿·버클)은 metallic 0.9, 천은 0, 피부 roughness 0.6.
- 납품: GLB 1개 + 텍스처 PNG 3장 따로.
- 합격선: 뷰어에서 정면 캡처 시 원화와 색 배치가 같을 것. 얼굴은 이 단계에서 따지지 않는다.

## 2. 허수아비 보스 3종 — `scarecrow_straw.glb`, `scarecrow_iron.glb`, `scarecrow_clock.glb`

훈련장 보스. 디자인 시트(허수아비 턴어라운드)를 기준으로 **정적 메시**를 만든다. 세 단계가 같은 골격을 공유하므로 **같은 뼈대 위치**로 만든다(짚 → 철갑 → 태엽 순으로 갑옷·부품이 붙는 식).

| 항목 | 값 |
|---|---|
| 크기 | 전체 높이 **2.8 m**(말뚝 포함), 몸통 폭 1.1 m |
| 포즈 | 십자 말뚝에 팔 벌린 T 자. 정면 +Z |
| 부위 분리 (노드 이름 고정) | `post`(말뚝) `core`(가슴 핵, 붉은 발광) `head` `arm_l` `arm_r` `hand_l` `hand_r` `chain_l` `chain_r`(사슬, 2·3단계) `plate_chest` `plate_shoulder_l` `plate_shoulder_r`(철갑, 2단계) `gear_back` `key`(태엽, 3단계) |
| 재질 | 짚: 마른 짚+삼베 / 철갑: 녹슨 철+가죽끈 / 태엽: 놋쇠 톱니+검은 기름때. core 는 emissive 붉은색 |
| 이유 | 부위 파괴 시 노드 단위로 떼어내고, 약점(core)을 코드가 이름으로 찾는다 |

## 3. 짚 인형 (잡몹) — `straw_doll.glb`

- 높이 1.4 m, 삼각형 ≤ 8k, 십자 막대에 짚 뭉치, 삼베 자루 머리에 X 자 눈. 노드 `body` `head` `arm_l` `arm_r` 분리. 정면 +Z, A 포즈.

## 4. 훈련장 환경 — 소품 GLB + 타일 텍스처

소품(각각 ≤ 5k 삼각형, 1024² 텍스처, 원점은 바닥 중심): `barrel.glb`(0.9 m) `crate.glb`(0.8 m) `fence_post.glb`(1.6 m, 갈대 울타리 기둥) `fence_rail.glb`(2 m 가로대) `torch.glb`(2.2 m 횃불대, 불꽃 메시 없이 `flame` 이름의 빈 노드만) `gate.glb`(3 m×3.2 m 녹슨 철문, `door_l` `door_r` 분리) `sign.glb`(1.8 m 표지판) `stake_ring.glb`(허수아비 발치 돌 링 4 m).

타일 텍스처(2048², **상하좌우 이어짐**, PNG): `ground_yard`(밟힌 흙+짚 부스러기) `wall_reed`(갈대 울타리) `wall_stone`(젖은 검은 돌담) — 각각 baseColor · normal · roughness 3장.

## 5. 낫 전용 공격 참고 (선택, 애니메이션 아님)

낫 공격 3종(베기·내려찍기·회전)의 **키 포즈 6장씩** 그림으로. 아인 3면도 스타일, 자루 궤적을 화살표로. 이쪽에서 자루 궤적을 그대로 IK 로 옮긴다.

## 6. 납품 순서와 확인

1 → 2(짚) → 3 → 4 → 2(철갑·태엽) → 5. 하나 끝날 때마다 GLB 와 뷰어 스크린샷을 이 대화에 올린다. 규약 위반은 "어긴 항목"만 적는다.
