# 199 · 일반 몬스터 — GPT 에게 맡기는 브리프 (2026-10-07)

디렉터: «1번 이미지로 구워야 되는데 힘들잖아. 지피티에게 시키게».
지금 필드에는 **보스만 있고 일반 몬스터가 없다.** 사냥터는 이름표뿐이다. 이 문서는 GPT 가 몬스터를 넣을 때 쓸 자리·연결점·규칙을 모은다.
보스 작업(문서 188·194~196)처럼 **모델·동작·서버 AI 는 GPT 몫**, 맵 자리·가방·안전 지대(문서 198)는 Claude 몫이다.

## 1. 자리는 이미 있다 — `map.json` areas `kind:'hunt'`

```json
{"kind":"hunt","id":"left","name":"중앙로 폐허 거리","lv":[23,26],"mobs":"감염체 무리 (가안)","danger":2,
 "poly":[[14.08,26.49],[131.52,-35.95],[18.84,-247.86],[-98.59,-185.42]]}
```

- 좌표는 월드 미터 (x, z). `poly`(사각형) 또는 `circle:[x,z,r]`. 서버 `field.cjs` 가 같은 `map.json` 을 읽는다 (`loadZone` — 지금은 rest·siege 만 들고 있음. hunt 도 같은 자리에서 읽으면 된다).
- 사람이 걷는 곳은 `walk` 띠 안뿐이다 (`Field.clamp`). 몬스터도 같은 띠로 묶어야 플레이어가 닿는다.
- 안전 지대(`kind:'rest'`, 문서 198) 안에는 **몬스터가 들어오지 않게**. 판정은 `js/mmo/safe-zones.js` `safeArea()` 그대로 — 단 거점 마을은 보스가 차지한 동안 안전 지대가 아니다 (거기엔 몬스터가 있어도 된다 = 점령전의 졸개).
- `mobs` 문자열은 지금 이름표다. `(가안)` 은 이름이 아직 없다는 뜻. 지역 생성기(`tools/2d/new-zone.mjs`)가 정하고, 이름만 바꿀 때는 `tools/2d/patch-areas.mjs` (다시 굽지 않는다).

### 지금 이름표 (구운 지역 기준)

| `mobs` | 사냥터 수 | 레벨 | 지역 |
|---|---|---|---|
| 쇼윈도 리퍼 · 감염체 · 광장의 감염체 | 3 | 1~10 | 강남 (원작 1장) |
| (가안) | 10 | 12~49 | 남산·판교·계룡 … |
| 탈영병 · 탈영병 무리 · 방호복 병사 · 클레이브 둘 | 5 | 30~35 | 남태령 |
| 정비창 기계들 | 1 | 48~52 | 계룡 |
| 집행관 의장대 | 2 | 52~60 | 고흥 |
| 감염체 무리 (가안) | 4 | 23~58 | 대전·경포·해운대 |
| 갯가 감염체 (가안) | 4 | 27~58 | 경포·해운대 |

새로 굽는 10곳(부산·전주·제주·수원·춘천·속초·경주·여수·목포·서귀포)이 끝나면 «감염체 무리 (가안)» 류가 30개쯤 늘어난다.

## 2. 제안 — 적은 종류로 많이 쓴다

리니지처럼 **종류는 적게, 색·크기·이름만 바꿔 레벨대별로**. 모델 하나에 변형 3~4개.

| 종류 (모델 1개) | 변형 예 | 쓰는 곳 |
|---|---|---|
| 감염체 (사람형, 느림·무리) | 감염체 / 광장의 감염체 / 갯가 감염체 / 감염체 무리 | 강남·대전·해운대·경포·새 지역 대부분 |
| 쇼윈도 리퍼 (마네킹형, 빠름) | 리퍼 / 깨진 리퍼 | 강남 |
| 탈영병 (총·칼 든 사람형) | 탈영병 / 방호복 병사 / 집행관 의장대 | 남태령·고흥 |
| 기계 (네발·드론) | 정비창 기계 / 순찰 드론 | 계룡·판교 |

→ **모델 4개면 지금 사냥터 전부를 덮는다.** 동작은 idle · walk · attack · hit · die 다섯.

## 3. 연결점 (지금 있는 코드)

| | 어디 | 메모 |
|---|---|---|
| 서버 틱·관심 반경 | `server/field.cjs` `bossView`·`AOI 28 m`·초당 10번 | 몬스터도 같은 메시지(`field`)에 `mobs:[[id,kind,x,z,hp%,anim]]` 처럼 얹으면 된다 |
| 플레이어 공격 | `fieldHit {boss}` → `Field.hit` | 대상이 보스 id 로만 되어 있다. `{mob}` 을 받게 넓히거나 `fieldHitMob` 따로. 스킬 배율(`opt.mult`)·치명타(`critNext`)·`HIT_GAP` 은 그대로 쓴다 |
| 몬스터 공격 | `Field.bossStrike(o,p,hit,now)` | 방어력 감소·회피·결의 버프(`buffMul`)가 이미 들어 있다. 몬스터용으로 같은 식을 쓰면 스킬 3·4 가 몬스터에도 먹는다 |
| 쓰러짐·부활 | `RESPAWN_TIME 5 s` · 출발점 | 그대로 |
| 드롭 | `killBoss` → `loot` → `fieldLoot` → `store.bossLoot` | **`bossLoot` 은 보스 장비만 받는다** (`src==='boss'`). 몬스터 드롭(재료·회복약·골드)은 `store.addItems`/`mutate` 로 따로. 바닥에 떨굴지, 바로 가방에 넣을지는 GPT 결정 (리니지는 바닥) |
| 가방 | 문서 198 `fieldBag` | 드롭이 들어오면 가방·회복약 단추가 `profile` 으로 바로 갱신된다 — 화면 쪽 일 없음 |
| 클라 모델 | `mmo.html` 보스 로더 (`visualH` 로 키 맞춤 · 발을 바닥에) | 보스와 같은 길. **보스 다섯이 바닥에 파묻혔던 일**(CLAUDE.md §1) 때문에 키·발 기준은 꼭 `tools/3d/pose-sheet.html` 로 찍어 확인 |
| 경험치 | `profile.xp` (1,200 = 1레벨) | 필드에서 xp 를 주는 길이 아직 없다 — 몬스터가 처음이 된다 |

## 4. 지켜 줄 것

- 이미지·모델 생성(Hi3D 등) 자격증명은 환경변수로만, 커밋 금지 (CLAUDE.md §5).
- 헤드리스는 초당 1~2프레임 — 몬스터 AI·동작을 찍을 때 벽시계 말고 프레임을 센다.
- 휴대폰에서 몬스터 20마리 + 사람 10명이 초당 30프레임을 지키는지 잰다 (디렉터는 안드로이드).
- 몬스터 수·리스폰은 서버가 정하고, 클라는 보이기만 (보스와 같은 권위 구조).

## 5. Claude 가 받쳐 줄 것

- 지역 생성기에서 사냥터 이름·레벨을 GPT 의 몬스터 표에 맞춰 바꾸기 (`patch-areas`, 다시 굽기 없음).
- 서버 `loadZone` 에 hunt 다각형 넘기기, 안전 지대 판정 공유 (이미 있음).
- 가방·상점 쪽 드롭 표시 · 회복약 소비 (이미 있음).
