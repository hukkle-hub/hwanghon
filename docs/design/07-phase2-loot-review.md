# 황혼 — 2단계(드랍·보상) 검수: 실제 게임과 비교 v0.1

> 작성일 2026-09-17 · 근거: 마영전 코어 부스트 가이드·나무위키 시스템, 블소 던전 룰렛(나무위키 던전), 검은사막 아이템 획득 확률 증가·아그리스의 열기(인벤 팁).

## 1. 참고작의 규칙
| 항목 | 마비노기 영웅전 | 블레이드앤소울 | 검은사막 |
|---|---|---|---|
| 드랍 시점 | 전투 완수 후 보상 창에서 정산(주요 보상·부가 보상) | 던전 보상은 입찰, 필드 보스는 피해량 비례 '정수' → 룰렛 | 처치 즉시 바닥 드랍, 자동 습득 |
| 확률 보정 | 코어 부스트: 지정 횟수 동안 주요 보상 확률 2배 | — | 아이템 획득 확률 증가 스탯(최대 +300%), 아그리스의 열기(잡템 +100~150%) |
| 잘 싸운 보상 | 부위 파괴·무손상 등 전투 조건 달성 시 추가 보상 | 피해 기여 비례 | 행운 등급 |
| 최초 클리어 | 미혹의 탑 층별 달성 보상 | 최초 클리어 업적 | 지식·업적 보상 |

## 2. 우리 구현과 비교해 찾은 문제 → 조치
| # | 문제 | 참고작 | 조치 |
|---|---|---|---|
| 1 | 클리어 보상이 결과 화면에 표시만 되고 실제로 안 들어옴 | 전부 정산 지급 | **finish 에서 골드·재료·장비 실제 지급**, 첫 클리어 표시 |
| 2 | 바닥에 남긴 전리품은 정산으로 넘어가면 사라짐 | 마영전 종료 정산 | **정산 전 자동 회수** |
| 3 | 드랍이 잡몹당 고정(섬유 2) | 확률·수량 표 | **드랍 표**(확률·수량 범위), 부위 파괴 보너스 드랍, 클리어 희귀 표 |
| 4 | 잘 싸워도 보상이 같음 | 마영전 조건 보상, 검사 확률 스탯 | **행운** = 1 + 0.35×카운터율 + 0.25×파괴율. 등급별 골드 배율 S 1.5 / A 1.25 / C 0.75. 결과 화면에 행운 표시 |
| 5 | 희귀 드랍을 알아채기 어려움 | 참고작 전부 색·소리 | 등급 색 발광 픽업, 등급 색 토스트, 영웅 이상·장비는 효과음 |
| 6 | 최초 클리어 보상 없음 | 공통 | +1,000 골드 · 보조제 ×2 · 심장 결정 |
| 7 | 드랍 정보를 미리 볼 수 없음 | 도감·툴팁 | 인력사무실 준비 카드에 드랍·부위 파괴·희귀 목록 |

## 3. 보류
- 코어 부스트(소모형 확률 2배)와 검사식 '획득 확률' 스탯은 3단계(던전 02)에서 소모품·장비 옵션으로.
- 파티 입찰·룰렛은 멀티플레이 이후.
