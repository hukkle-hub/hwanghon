# 225 · 스킨 다시 묶기 — «모션에 다 늘어나서 붙었네»

디렉터(클레이브 셔터·폭풍 화면을 보고): «클레이브도 그렇고 모션에 다 늘어나서 붙었네. 제대로 잡고 가야지».

준비 동작(문서 224) 탓이 아니었다. 그 전 캡처(02:28, 폭풍)에도 같은 흰 판이 있다. 원인은 **몸에 박힌 스킨 가중치**다.

## 1. 재기 — `tools/3d/stretch-audit.mjs`

지표: 삼각형 변 길이가 쉬는 자세(바인드) 대비 **2배 넘게** 늘어나는 변의 비율(클립 전체 0.1 s 간격 최대). 바인드 공간끼리 견준다.

| 보스 | 원본 평균 | 원본 최악 클립 |
|---|---|---|
| 클레이브 | 1.93 % | 셔터 들기 **11.4 %** · 폭풍 **11.3 %** (대기 0.07 %) |
| 섀도우 팽 | 0.63 % | 연격 5.9 % · 개화 2.7 % |
| 정 장관 | 0.83 % | 원 4.2 % · 등 뒤 3.2 % · 3합 3.0 % · 지휘 2.7 % |

## 2. 무엇이 엉켜 있었나 (클레이브를 칠해 보고 안 것)

- 정점의 **24 %** 가 위계로 3칸 넘게 먼 뼈끼리 나눠 묶여 있었다 — 왼손+왼종아리 1119 · 오른허벅지+오른아래팔 884 · 오른허벅지+오른손 677 …
  자동 리깅이 늘어뜨린 손과 허벅지처럼 «쉬는 자세에서 가까운» 뼈끼리 섞었다. 팔을 들면 그 정점이 손과 다리 사이에서 엿가락이 된다.
- **셔터 아래 절반**(따로 떨어진 3898 정점 조각)이 왼손 70 %·왼발·발끝 20 % 로 묶여, 손을 들면 바닥까지 판자처럼 늘어났다 — 화면의 «세워진 흰 판».
  셔터 위 절반(`Boss_HeldPart`)은 왼손 100 % 라 멀쩡했다.
- 코트 뒤 자투리 조각들(13 cm 짜리가 왼손 15 % 를 쥐어 1.5 m 로)이 «/» 모양으로 허공에 섰다.
- 메시가 손·허벅지 닿는 곳에서 **실제로 이어져** 있다(AI 생성 메시). 정점만 갈라 묶으면 그 사이 삼각형이 찢어진다.

`tools/3d/stretch-heat.html` — 늘어나는 정점을 쉬는 자세 위에 빨갛게 / `&color=label` 이면 갈래별로 칠한다(`&pose=클립:시각` 으로 그 자세).

## 3. 고친 방법 — `js/mmo/skin-fix.js` `rebindModel`

1. **떨어진 조각 굳히기** (`rigidIslands`): 몸통과 이어지지 않은 조각(같은 자리 정점 용접 뒤)인데 한 뼈가 60 % 넘게 끌면 그 뼈에 100 %. — 셔터 아래 절반이 손을 따라간다.
2. **갈래 다시 묶기** (`rebind`): 갈래 = 왼팔(위팔·아래팔·손) · 오른팔 · 왼다리 · 오른다리 · 몸통(골반·척추·**빗장**·목·머리).
   정점의 주인 갈래 = 원래 가중치 × exp(−뼈 마디까지 거리 / σ), σ = 키의 8 %. 남기는 가중치 = 주인 갈래 + 몸통
   (+ 몸통 주인이면 σ×2 안의 팔다리 하나 — 어깨·골반 이음새만). 남는 게 없으면 그 갈래의 가장 가까운 뼈.
   - 빗장을 몸통에 넣은 까닭: 믹사모 어깨뼈는 목 옆에서 시작해 빗장 마디가 머리 옆을 지난다 → 머리 오른쪽 반이 «오른팔» 이 됐다.
3. **붙은 살 끊기**: 서로 다른 팔다리 갈래를 잇는 삼각형만 지운다(몸통과의 이음은 남긴다). 끊어서 생길 작은 조각(정점 2 % 미만)은 건너편 갈래로 보내고 다시 잇는다 — 끊은 자투리가 팔에 딸려 허공에 뜨지 않게(조각 수 172 → 63, 원래 49).

해 보고 버린 것(재서 더 나빴다):

| 시도 | 결과 |
|---|---|
| 위계 2칸 밖 가중치 버리기 | 2배↑ 2.9 % 이지만 최악 ×874 — 이어진 삼각형이 찢어짐, 셔터가 조각남 |
| 앞섶(좌우 다리 반반)을 골반으로 | 골반↔골반 늘어남 증가 (4.8 %) |
| 표면 거리(geodesic) 갈래 | 소매와 옆구리 코트가 표면으로 이어져 있어 오른팔이 밑단까지 번짐 (3.1 %) |
| 팔 관(tube) 밖은 몸통으로 | 손 둘레와 골반 사이 이음새가 늘어남 (2.7 %) |

## 4. 결과 — GLB 에 굽기 (`tools/3d/skin-rebind.mjs`)

가중치·뼈 번호·삼각형을 **같은 자리·같은 크기** 로 덮어쓴다(끊은 몫은 넓이 0 삼각형). 런타임 비용 0, GLB 는 표(`asset.extras.skinRebind`) 몫 100 B 남짓만 는다.
원본은 `.node-shots/skin-rebind/orig/` 에 받아 두었다. `tools/3d/jeong-clips.mjs` 는 원본에서 다시 구운 뒤 이걸 부른다.

| 보스 | 평균 | 최악 클립 |
|---|---|---|
| 클레이브 | 1.93 → **0.33 %** | 셔터 들기 11.4 → **2.4 %** · 내려찍기 1.77 → **0.07 %** · 걷기 0.72 → **0.04 %** |
| 섀도우 팽 | 0.63 → **0.21 %** | 연격 5.9 → **2.3 %** |
| 정 장관 | 0.83 → **0.13 %** | 원 4.2 → **0.8 %** (코트 소매가 날개처럼 부풀던 것) |
| 실험체 09호 | 0.17 → **0.14 %** | 폭주 1.8 → **1.5 %** (원래 덜 엉켜 있던 몸) |

남은 것: 클레이브가 두 팔을 머리 위로 다 드는 순간 어깨·가슴이 늘어나는 것(2.4 %)과, 오른쪽 옆구리 코트가 오른팔과 함께 들리는 것.
소매와 옆구리 코트가 한 덩어리로 이어진 메시라 가중치로는 더 못 가른다 — 메시를 갈라 다시 만들거나(Hi3D) 클립에서 팔을 덜 드는 수밖에.
