# 171 — 4인 스킬 이펙트 1차 (2026-10-01)

콘티(문서 169, `tools/vfx/hero-skill-study.html`)의 층을 엔진에 붙였다. 결정 대기 세 가지(세라 무기, 류 표식, 신규 시그니처)는 건드리지 않았다.

## 1. 층과 시점

모든 층은 클립이 아니라 **키트의 시계**를 따른다(문서 169 §2.5).

| 층 | 언제 | 무엇 |
|---|---|---|
| 예고 | 스킬 시작 | 칼끝 섬광(빛 0.05 s에 올라 0.3 s에 꺼짐) + 불티 |
| 궤적 | 시작부터 마지막 타격 + 0.18 s | `FX_WeaponBase_R`–`FX_WeaponTip_R` 사이 애님 트레일(류는 양손), 영웅 색 |
| 타격 | 타격이 실제로 맞은 순간 | 대상 앞면, 칼 높이에 충격파 고리 + 빛. 강타·궁극은 X자 베기가 더해진다 |
| 광역 | 광역 타격 순간(헛쳐도) | 발밑 고리 + 빛, 궁극은 불기둥 |
| 세라 | 손에서 놓는 프레임 | 빛나는 구슬이 비행시간 동안 날아가 타격 시각에 도착해 터진다. 광역은 포물선으로 날아간다 |
| 회피 | 누른 순간 | 떠난 자리에 연기(류는 그림자 분신) |
| 버프 | 누른 순간 | 몸 전체 오버레이가 버프 시간만큼 숨 쉬며 빛난다(아인·류 2 s, 카인·세라 3 s) |

- 키트에 `OnAbilityHitResolved` 델리게이트를 추가했다. 모든 스킬 타격이 맞았든 헛쳤든 그 시점에 알린다.
- 타격마다 슬롯과 «마지막 타격» 표시가 붙는다.

## 2. 색 — 팩에 없는 색 만들기

Paragon 팩 세 개는 빨강(Countess), 불(Grux), 초록(Sevarog)뿐이다. 강철색·파랑은 없다.

- `M_HW_ParticleTint`
  - 이미터의 원래 텍스처(모양·플립북)와 파티클 색의 밝기·수명 페이드는 그대로 둔다.
  - 색상만 영웅 색으로 바꾼다.
  - 바꿔 끼우는 일은 런타임에 이미터별로 한다(`UHWHeroFxComponent::Tint`).
- 1차 시도는 화면 전체가 하얗게 날아갔다. 원인은 둘이었다.
  1. 반투명 연기 층까지 가산으로 바뀌었다 → **원래 가산인 층만** 색을 바꾸고, 나머지 층(연기, 팩의 빨간 리본)은 끈다.
  2. `Flare` 스프라이트(T_blue_sharp)가 거대한 별빛이 되었다 → 끈다.
- 밝기는 색 성분의 합으로 나눠 맞춘다. 같은 값이면 옅은 색(카인)이 흰색으로 타 버린다.
  - 카인 색도 (0.55, 0.72, 1) → (0.32, 0.5, 1) 강철 청색으로 옮겼다.
- 영웅별 처리
  - 류: 원본 빨강 그대로
  - 아인: Grux 불(주황)은 그대로 쓰고 Countess 쪽만 주황으로 바꾼다
  - 카인·세라: 전부 바꾼다
- 궤적: `M_HW_TrailAdditive`(파티클 색 × 수명, 폭 방향 1-|2v-1| 중심선)
- 머티리얼 생성: `Scripts/ue_fx_trail_material.py`

## 3. 측정과 함정

- 빛 세기를 로그로 찍었다(`Describe()` lights=…).
  - 1.2 s 뒤에는 모두 0인데도 바닥에 빛웅덩이가 남았다. Lumen GI가 약 1 s 늦게 따라오기 때문이다.
  - → 이펙트 빛은 `IndirectLightingIntensity = 0`. 모바일에는 Lumen이 없다.
- 첫 값은 너무 셌다(칼끝 30000, 타격 40000). 바닥을 하얗게 덮어서 8000 / 7000 / 16000으로 낮췄다.
- 버프 오버레이 Glow 2.2는 몸을 흰 석상으로 만들었다 → 0.2

## 4. QA — `-HWQA=skillfx`

- 선택한 영웅이 키트를 거쳐 실제로 스킬을 쓴다. 대상은 사정거리 안에 얼려 둔 보스다.
- 스킬마다 다섯 컷을 찍는다: 시작, 접점 전, 접점 직후, 접점 뒤, 늦게.
- 컷마다 이펙트 상태를 로그로 남긴다. 게이트는 `skill_fx_fired`.
- 시트: `python Scripts/skillfx_sheet.py Saved/SkillFx6`
- 네 명 모두 `ok=1`이다. 류의 한 사이클 기록: 예고 3, 궤적 3, 타격 11, 고리 3.

## 5. 남은 것

- 궁극기 타격 섬광이 아직 크다(류 붉은그림자는 화면을 거의 붉게 덮는다). 의도된 «한 방»인지 디렉터에게 묻는다.
- 휴대폰 빌드에서 Cascade 애님 트레일, 틴트, 오버레이 비용을 확인해야 한다.
- 세라 무기 결정 뒤에는 발사체 모양을 바꾼다(지금은 구슬).
