# 215 · 3D 필드 소품 다듬기 (바위 · 덤불 · 나무 잎 · 콘크리트 덩이)

디렉터 «3D 만» 이후 지도 쪽 첫 일. 3D 필드 장면은 위에서 내려다보는 2D 굽기용 장면 빌더(`js/mmo/env-lib.js` 등)를 그대로 쓴다 — 가까이서 보면 다면체·상자.

- `setView3d(true)` — world3d 가 장면 빌더(공용)에 3D 라고 알린다. **3D 일 때만** 모양을 바꾸고 굽기(2D)는 그대로.
- `lumpy()` — 꼭짓점을 «자리로 만든 해시» 로 흔든다. **장면 난수(R)를 안 쓴다** → 뒤따르는 모든 자리·막이가 그대로 (대전 막이 725 · 수원 623, 전·후 같음 · `dress()` 의 R() 호출 37 그대로).
  바위 = 정이십면체 한 번 쪼갬 + 흔들기 · 덤불·나무 잎 = 흔들기만 · 콘크리트 덩이 = 세 축 흔들기.
- `gritTex()` — 바위·콘크리트 덩이에 거친 표면 무늬(고정 씨앗, 128²) — 삼각형 없이 잔무늬.
- 무게 (Pixel 7 가로 · 휴대폰 모델): 처음 판(전부 한 번 쪼갬)은 대전 72만 → **119만** 삼각형이라 버렸다. 지금: 대전 72.2만 → 77.6만 (+7%) · 강남 58.4만 → 61.0만 · 수원 60.7만 → 66.0만. 호출 수는 거의 그대로.
- 그림: `.node-shots/w3d/look-*-before.png` · `look-*-after2.png`, 확대 `rock-zoom.png`.
