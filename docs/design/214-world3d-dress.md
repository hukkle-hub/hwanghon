# 214 · 3D 필드 장비 겉모습

3D 영웅(레이드 아바타 `party-avatar Animated`)이 이제 장비를 입는다. 2D 필드·솔로와 같은 `TW_LOOKS.attach` (갑옷·장신구·머리카락 정리) — 무기는 아바타가 이미 쥐고 있어(양손 쥠 리그) **갑옷만** 입힌다(`noMain`, `js/looks.js` 에 새 선택지 — 다른 화면은 그대로).

- 온라인: 서버 장착(`profile.equipment`, 강화 단계 포함). 입장 때와 profile 이 올 때마다 다시 입는다 — 가방에서 장착·해제하면 바로 바뀐다. 같은 옷이면 다시 만들지 않는다.
- 혼자 연습: 2D 필드와 같은 시작 세트(아인 갈대 · 카인 수문 · 류 감시자 · 세라 없음). 검수용 `?look=0~3`, `__W3D.dress({...})`.
- **고친 버그 (공용 `js/looks.js`):** 코트(몸에 감기는 옷)가 «코트 밑 몸 삼각형» 을 숨길 때 몸 지오메트리를 새로 만들면서 `morphTargetsRelative` 를 빠뜨렸다. 쥔 손 모프(hand-grip)는 상대값이라, 절대값으로 읽히자 몸 정점이 원점(발밑)으로 끌려가 **몸·머리·다리가 통째로 사라지고 발밑에 조각**이 남았다. 류 감시자 코트로 부위별(머리 · 코트 · 장갑 · 다리)로 하나씩 입혀 코트만 그렇다는 걸 찾았다. 2D 필드에도 같은 길이라 같이 고쳐진다.
- 확인: 네 영웅 정면·측면 (`.node-shots/w3d/dress-sheet2.png`), 류 부위별 고치기 전·후 (`dp-ryu.png` → `dp-ryu-fixed.png`), 서버로 카인이 가방에서 두건 장착 → 겉모습 조각 0 → 두건 (`equip-online.png`).
- 시험 `tests/world3d-dress.test.mjs` — morphTargetsRelative 옮기기(지우면 실패 확인) · noMain · 다시 입기 연결.
## 기록 — 여기서 멈춤 (디렉터 «장비는 여러 장비를 더 구현해야 하니 여기서 마무리해 기록», 2026-10-09)

| 항목 | 상태 |
|---|---|
| 내 영웅 갑옷·장신구 (온라인 = 서버 장착 · 혼자 연습 = 시작 세트) | 됨 · 화면 확인 |
| 가방에서 장착·해제 → 겉모습 바로 반영 | 됨 · 서버로 확인 (카인 두건) |
| 코트(몸에 감기는 옷)가 몸을 지우던 버그 | 고침 · 확인 (공용 looks.js — 2D 도 같이) |
| **다른 사람 장비** (`dressRemote` — 서버 infos 의 eq·enh, 내 영웅과 같은 길) | **넣었지만 화면 확인 못 함.** 3D 두 명을 헤드리스로 띄우면 두 번째 사람이 접속 직후 끊긴다(소켓 1006). 이 코드를 꺼도 똑같아서 시험 환경(무거운 3D 탭 둘) 문제로 보지만, 실제 접속 문제일 수도 있어 다음에 장비 일을 다시 잡을 때 먼저 가린다. 2D 한 명 + 3D 한 명은 끊기지 않았다(문서 210 §7). |
| 주무기 바꾸기 | 안 됨 — 3D 손엔 캐릭터 기본 무기 그대로 (아바타가 무기·양손 쥠을 생성자에서 한 번 단다 — 바꾸려면 다시 달고 쥠 리그도 다시) |
| 장비 종류 늘리기 | 디렉터: 더 만들어야 한다 — 그때 이어서 |
