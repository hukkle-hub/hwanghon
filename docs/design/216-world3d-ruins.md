## 1. 무엇을 바꿨나
걷는 구역 안의 건물은 굽기 때부터 «무너진 저층»(높이 4.5~9 m 로 깎음, `o.ruin` · `o.ruinH`)이었다. 2D 굽기(위에서 본 그림)에서는 그걸로 충분했지만 3인칭 3D 에서는 **창문 무늬를 바른 반듯한 상자**였다.

3D 필드(`setView3d(true)`)에서만 `buildings()` 가 그 상자 대신 `ruinShell()` 을 세운다 (`js/mmo/env-lib.js`):

| 부품 | 모양 |
|---|---|
| 벽체 | 윤곽을 따라 두께 0.4 m · 약 2.6 m 토막. **속이 비었다** (지붕 없음) |
| 부서진 윗선 | 토막마다 왼끝·오른끝 높이가 달라 비스듬히 잘린 판 (`wallPiece`). 마디 높이는 이웃과 이어지고, 30% 는 뚝 끊긴다. 높이는 폐허 한도의 30~100% |
| 빠진 벽 | 토막 3개 넘는 벽에서 14% 는 통째로 없음 — 안이 들여다보인다 |
| 2층 바닥판 조각 | 벽이 3.6 m 넘게 남은 곳의 55% 에 안쪽으로 1~2.5 m 삐져나와 살짝 처진 판 (높이 3.2 m) |
| 잔해 | 벽 밑 덩이(35%) · 안쪽 가운데 더미 5개, 울퉁불퉁(`lumpy`) |
| 재질 | 폐허 벽 전용 — 같은 파사드 텍스처, 빛(emissive) 0.3 · 거칠기 0.75 (불 켜진 창의 «멀쩡한 건물» 느낌을 뺌) |

UV 는 벽을 따라 잰 거리 × 높이(1 m = 1) — 토막이 바뀌어도 창 무늬가 이어진다. 재질별로 한 메시로 합친다(건물 하나 = 호출 3).

## 2. 지킨 것
- **장면 난수 `R()` 를 안 쓴다.** 흔들림은 전부 건물 id 해시(`hashU`). 폐허 높이 뽑기(`R()`)는 3D 갈래보다 먼저 그대로 → 뒤 자리(나무·잔해·막이)가 2D 굽기 · 서버 `map.json` 과 같다.
- **막이 = 윤곽 그대로.** 벽·바닥판 꼭짓점은 전부 윤곽 안. 사람은 예전처럼 폐허 안에 못 들어간다.
