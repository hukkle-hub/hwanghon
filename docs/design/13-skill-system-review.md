# 황혼 — 스킬 성장 검수 v0.1

> 작성일 2026-09-18 · 디렉터 지시: "(장비) 그 후에 스킬 들어가자" · 근거: 마비노기 영웅전(AP 로 스킬 랭크 F→9, 랭크마다 수치 상승 + 특정 랭크에서 효과 추가), 블레이드 앤 소울(스킬별 분기 트리 — 같은 스킬을 다른 성질로 바꿈), 검은사막(스킬 부가 효과·각성 스킬), 몬스터 헌터(무기 숙련보다 장비·스킬 보석).

## 0. 만든 것
| 항목 | 내용 |
|---|---|
| 포인트 | `TW_SKILLS.points` — 기본 4 + 요원 등급 단계×3 + 보스 격파(runs)×1, 상한 30. 캐릭터마다 따로 쓰고 초기화 무료(마영전의 AP 재분배 비용은 두지 않음 — 초반 실험을 막지 않기 위해) |
| 레벨 1~5 | 배율 +12%/lv, 쿨타임 −6%/lv, 스태미나 −4%/lv, 버프는 감소율 +5%p·지속 +0.4초/lv, 궁극기 배율 +10%/lv (`skills.js scaled`) |
| 분기 (Lv3, 1포인트) | A 강화(배율 +25% / 버프 감소율 +15%p / 회피 무적 ×1.5) · B 효과(피해기 출혈 1중첩 / 광역 자세 +20 / 버프 지속 +1초 / 회피 쿨 −25% / 궁극기 자세 +35) — 블소식 "같은 스킬, 다른 성질" |
| 전투 반영 | `game3d.js` 가 `TW_SKILLS.apply` 로 스킬·궁극기 사본을 만들어 `combat.js` 에 넘김. combat 은 `k.bleed`·`k.posture`·`k.iframes` 를 처리. HUD 스킬 버튼에 `Lv·분기` 배지 |
| 화면 | `skills.html` — 캐릭터 4인 탭, 스킬 노드(핍 5 + 분기 핍), 상세(현재 → 다음 레벨 수치, 분기 카드, 레벨 업·초기화). 로비 「스킬」 메뉴 연결 |

## 1. 참고작 비교 → 조치
| # | 항목 | 참고작 | 우리 |
|---|---|---|---|
| 1 | 스킬 랭크 성장 | 마영전 AP 랭크 | 포인트 → 레벨 5단계. 수치 상승은 랭크당 소폭(12%)으로 하고 큰 변화는 분기에 둠 |
| 2 | 분기 | 블소 트리 | 스킬당 2분기, 3레벨 해금. 궁극기도 분기 |
| 3 | 포인트 출처 | 마영전(AP=전투), 검사(레벨) | 요원 등급(= 누적 XP) + 보스 격파 횟수 → 던전을 돌수록 자란다 |
| 4 | 전투 표시 | 마영전 HUD 스킬 랭크 | 스킬 버튼 배지 |
| 5 | 캐릭터별 | 전부 | 4인 각자 포인트·트리 |

## 2. 검증
- 화면: 캐릭터 전환, 레벨 업(포인트 차감·수치 갱신), 분기 잠금(Lv3 미만) → 해금 후 선택, 초기화 환급. 저장 `skills` 유지.
- 던전: 아인 낫 베기 Lv3·분기 B 로 입장 → HUD 배지 표시, 스킬 사용 시 출혈 스택 증가 확인. 봇 완주 + QA.

## 3. 알려진 한계
- 스킬별 전용 이펙트·동작 변화는 없음(분기는 수치·상태 효과). 다음 단계 후보: 분기별 VFX 색, 궁극기 연출 분기.
- 스킬 포인트 상한 30 은 5스킬 × (4레벨 + 분기 1) = 25 를 조금 넘는 수준 — 등급 SS + 보스 14회면 전부 찍는다.
