## 5. 레비아탄 — EP09 (가둠)

1. **전투 순서**
   - 수위는 가슴께(전화보다 높음, L7942) → 넷이 배치: 내측 기계실=류, 외측 기계실=아인, 물 한가운데=카인(미끼), 입구 윈치=오정길(L7944). 카인 "…미끼가 제일 편해. 생각을 안 해도 되거든."(L7948).
   - 카인이 대검으로 수면을 반복 타격("콰앙" ×3), 진동을 유인 → 터널 안쪽에서 낮은 울음이 응답(L7960–L7970).
   - 외측 기계실 아인이 눈을 감고 고정핀에 낫날을 댄 채 청음 — 카인의 파문·류의 숨·오정길 윈치의 미세 마찰음·다가오는 질량(L7976–L7980) → 물살이 안→밖으로 급변, 수면이 부풀어 오르며 접근(L7986–L7990).
   - 질량이 카인 지점을 지나 내측 차수문 라인을 넘자 아인이 눈을 뜨고 배관을 두 번 두드림("깡. 깡.", L8001–L8011) → 내측 기계실 류가 진동 2회를 감지, 쌍단검을 교차해 고정핀 2개를 동시 절단 → 평형추 낙하, 내측 차수문이 "콰아아앙—" 낙하(L8015–L8031).
   - 반 박자 정적 → 문이 닫힌 것을 안 덩어리가 돌아섬 → 터널 물 전체가 해일이 되어 외측으로 밀려옴 → 카인이 반은 헤엄·반은 떠밀리며 유일한 출구로 달아나고 간격이 좁아짐(L8037–L8049) → 외측 기계실 아인이 핀에 낫날을 댄 채 카인·놈 두 거리를 동시에 재며 대기(지금 베면 카인이 못 나오고, 기다리면 놈이 나간다, L8053–L8063).
   - 카인이 문턱 아래로 미끄러져 통과 → 아인이 베려는 순간, 갈라진 물 사이로 비상등 빛이 놈 내부를 관통해 눈 감은 여러 얼굴이 겹쳐 스침(L8069–L8083) → 낫이 핀 위에서 한순간 멈췄다가, 아인은 눈을 뜬 채 핀을 절단("서걱", L8085–L8095).

2. **외형/무기/크기**: EP08과 동일 개체(연속 조우). 이 화에서는 구체적 형상 대신 "덩어리"·"벽 같은 질량"으로 묘사되며, 내부에 눈 감은 여러 얼굴이 겹쳐 있다는 신규 정보가 드러난다(L8081–L8083).
