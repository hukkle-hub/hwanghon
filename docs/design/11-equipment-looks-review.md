## 1. 참고작 비교 → 조치
| # | 항목 | 참고작 | 우리 |
|---|---|---|---|
| 1 | 무기 종류가 바뀌면 손에 든 모델이 바뀐다 | 전부 | 주무기 5종 모델 교체. 공격 동작은 낫 기준 양손 동작을 공유(검·창도 대형 무기로 취급) |

| 4 | 장착 즉시 미리보기 | 마영전 인벤토리 | 3D 토글 미리보기, 교체 즉시 갱신 |
| 5 | 제작 자유도가 외형에 | 검사 염색 | 재료 색조가 무기·조각에 |

## 2. 알려진 한계
- 방어구 조각은 프리미티브라 원화의 디테일(가죽 결·리벳)은 없다. 후드는 머리를 감싸는 천 실루엣 수준.
- 공격 애니메이션은 무기 종류와 무관(낫 기준). 검·창 전용 동작은 5단계 이후.
- 2D 페이퍼돌 원화(`full-ain.webp`)는 고정. 3D 토글로 대체.

## 3. 검증
- 뷰어 장착 모드에서 5세트(전체 장착 · 검 · 창 · 검창 · 집행자) 3방향 렌더 확인, 인벤토리 3D 토글 → 장착 교체 시 미리보기 갱신 확인, 던전 입장(전체 장착) 오류 0.

## 4. v0.2 외형 검수 (2026-09-18) — 디렉터: "렌더가 제대로 안 된 것 같다. 외형을 검수해서 예쁘게"
v0.1 렌더를 4방향·근접으로 다시 찍어 보니 실제로 문제가 있었다. 원인과 조치:

| # | 문제(v0.1) | 원인 | 조치(v0.2) |
|---|---|---|---|
| 1 | 후드가 머리 위에 검은 공처럼 떠 있음 | 구 하나를 머리 위에 얹음 | 구 껍질(`shell`, 앞 120° 개방)로 머리를 감싸고 앞을 튼 카울 + 목 뒤 드레이프. 얼굴이 보인다 |
| 2 | 흉갑이 어깨 높이의 회색 상자, 끈이 형광 연두 | 상자 프리미티브, 무광 단색 | 가슴에 맞춘 부분 원통 앞판(갈대색 천) + 등판(가죽) + 가운데 가죽 띠 + 어깨 견갑(반구) + 허리띠·청동 버클. 형광 끈 삭제 |
| 3 | 각반·건틀릿이 통짜 원기둥 | 단색 | 정강이 곡률에 맞춘 부분 원통 + 무릎 반구 + 강철 테. 팔뚝은 강철 원통 + 검은 테 |
| 4 | 갈고리 낫이 허리 옆 공중에 떠 있음 | 뼈·오프셋 오류 | `Spine2` 등에 대각으로, 크기 0.75 |
| 5 | 모든 조각이 단색 플라스틱 | 재질에 텍스처 없음 | `art/3d/tex/`(wood·steel·rust·leather·cloth·olive, 절차 생성 256²)를 조각·무기 재질에 곱함. 무기 GLB는 bpy에서 스마트 UV 후 UV ×3 |
| 6 | 무기 4종이 주황색 덩어리(집행자·집행검·창 깃발) | 녹 텍스처 × 밝은 주황 색상, 깃발에 발광 | 녹 = 텍스처 × (0.62,0.56,0.52) 어두운 쇠빛, 깃발은 발광 없는 어두운 붉은 천, 집행자 날은 낫처럼 옆으로 뻗어 아래로 휘게(이 빠진 자국도 날 위로) |
| 7 | 미리보기가 너무 어두움 | 뷰어 기본 조명(반구 0.9 + 키 1) | `fit` 모드에 채움광(청백)·역광(주황) 추가, 노출 1.5 |

## 5. v0.3 장비 뽑기 (2026-09-18) — 디렉터: "장비가 너무 안 이쁘다. 장비 먼저 뽑자"
프리미티브 조각을 버리고 실제 3D 모델을 뽑았다.

| 단계 | 내용 |
|---|---|
| 컨셉 | Higgsfield `z_image` 로 장비 컨셉 시트 4장(무기 3+3, 방어구 3+2, 어두운 회색 배경·정면/측면). 시트에서 항목별로 잘라 정사각 참조 이미지 |
| 3D | Hi3D 웹 세션(이미지→3D v3.0, 고품질, PBR, 200만 면) 단일 이미지 제출. `scratchpad/hi3d-gear.mjs` 가 UI 를 대신 눌러 제출, `hi3d_q.py` 로 batch-result 조회·다운로드 |
| 후처리 | `tools/3d/gear_post.py` — 크롭 찌꺼기 잘라내기(`--keep` 바운딩), 데시메이트(무기 1~1.6만 면, 방어구 2~3만 면), 텍스처 8K→1K JPEG, 무기 규약 정렬(원점 자루 끝·+Y 칼끝·`--butt` 로 검 손잡이 위치), 방어구는 높이(`--len`) 기준 정규화 + 원점 중심 |
| 장착 | `js/looks.js` `ARMOR` 에 `['뼈','glb',경로,위치,회전,배율]` 조각 종류 추가. 후드 = Head, 흉갑 = Spine1, 건틀릿 = RightForeArm(π 회전으로 손가락이 뼈 방향). 검·단도는 `WEAPON` 경로만 교체 |

### 뽑은 것 (11/11)
| 항목 | 후처리 | 장착 |
|---|---|---|
| 녹슨 집행검 | 뒤집기(`--axis=-y`), 길이 1.1, 자루 끝 0.55 | 주무기 슬롯 |
| 재의 단도 | 옆 항목 찌꺼기 제거, 길이 0.42 | 왼 허리 |
| 부식된 사형 집행자 | 길이 1.9, 양날 | 주무기 |
| 메마른 갈대밭 검창 | 길이 1.5, 자루 끝 0.5 | 주무기 |
| 폐허의 장창 | 길이 2.1 | 주무기 |
| 갈고리 낫 | 길이 0.75 | 등(Spine2) |
| 낡은 후드 | 튜닉 원본에서 어깨 망토 위만(`--keep` y>0.12), 높이 0.36 | Head |

| 강철 건틀릿 | 높이 0.36, π 회전 | RightForeArm |
| 검은 각반 | 무릎~정강이 위 55%만(`--keep` y>-0.05), `--pair` 로 L/R, 높이 0.32 | LeftLeg/RightLeg (배율 1.02) |
| 순찰자의 장화 | `--pair` L/R, 높이 0.5 | LeftLeg/RightLeg (배율 0.97, 각반 안쪽) |

장신구 3종(반지·목걸이·밴드)은 화면에서 작아 프리미티브 유지. 옛 절차 생성 무기(`art/3d/weapons/`)는 삭제, `tools/3d/build_weapons.py` 는 예비로 남김.
검수: 뷰어 4방향(집행자 풀세트) + 검창·장창·집행검 옆면, 던전 입장, 인벤토리 3D 미리보기.

### 배운 것
- Hi3D 출력은 이미지 위쪽 = glTF +Y. 칼끝이 아래인 컨셉은 `--axis=-y` 로 뒤집는다(`o.data.transform` 로 직접 적용해야 확실히 먹는다).
- 시트를 잘라 쓰면 옆 항목 조각이 딸려 온다 → 생성 후 `--keep` 바운딩으로 제거. 다음부터는 항목당 시트 1장이 낫다(크레딧 여유가 있을 때).
- 200만 면 메시는 연결 요소가 수십~수백 개라 "가장 큰 덩어리만 남기기" 로는 찌꺼기를 못 거른다.

## 6. v0.4 장비 전면 구현 (2026-09-18) — 4인 공용
| 항목 | 내용 |
|---|---|
| 장신구 3종 | `tools/3d/build_acc.py` 절차 생성(이미지 크레딧 소진 → 프리미티브지만 실제 모델): 핏빛 인장 반지(금 링 + 붉은 인장면, 왼손 약지), 부적 목걸이(가죽 목줄 + 주머니 + 붉은 실 + 청동 방울, 목 앞), 구리 밴드(녹 텍스처 링) |
| 캐릭터별 체격 스케일 | `looks.js CHARFIT` — `body-metrics`(가슴폭·팔뚝·정강이·키 실측)로 조각 크기·오프셋을 캐릭터마다 곱한다. 카인 가슴 1.12·건틀릿 1.3·다리 1.1, 류 가슴 1.07·건틀릿 0.92, 세라 머리 0.95 |
| 캐릭터별 로드아웃 | `gear.js` 저장 `gear.chars[캐릭터]` — `equipped` 는 편집 중 캐릭터(`TW_GEAR.setChar`)의 로드아웃을 가리키는 접근자(옛 저장은 아인 로드아웃으로 이전). 가방·강화·내구도는 공용. 인벤토리 캐릭터 칩 = 로드아웃 전환, 3D 미리보기도 그 캐릭터 |
| 무기 클래스 | `items.js usableBy` — 낫→아인, 검·검창·장창→카인·아인, 대검→카인, 단검→류·아인, 쌍단검→류, 시약→세라. 인벤토리에서 「장착 불가」 |
| 기본 무기 아이템 | 모루의 대검(카인, 부위 파괴 +12%), 붉은 그림자 쌍단검(류, 배후 치명 +6%, 왼손 슬롯에도 같은 모델), 촉매 시약병(세라, 스킬 +8%·파티 회복 +5%) |

검증: 4인 풀세트 3방향 렌더, 인벤토리 전환·클래스 제한 브라우저 테스트(카인 낫 불가·집행검 가능, 류 집행자 불가·후드 가능), 던전 입장 스모크, QA.
