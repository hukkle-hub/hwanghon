## 0. 뺀 것 — 게임의 카메라 컷 등장씬

v10 등장씬(문서 162 파일럿 + 오늘 02–12 배치)을 **18개 스토리 월드에서 모두 걷어냈다**.
- 방법: `HW_INTRO_CLEAR=1` 로 `Scripts/ue_boss_intro_set.py` 를 돌린다.
- 결과: 아레나에 등장 감독이 없으면 스토리 감독이 예전 핸드오프 그대로 바로 전투에 들어간다. C++ 는 남겨 두었고 쓰이지 않는다.
- 다시 켜려면 같은 스크립트를 변수 없이 돌린다.

오늘 그 과정에서 고친 것 두 가지는 남긴다.
- 짧은 판 판정: «앞에 컷신이 없으면 재도전»이던 것을 «이 전투의 등장을 이미 봤으면 재도전»으로 고쳤다. EP23 은 화의 첫 장면이 전투다.
- QA 박자 샷: 프레임이 끊겨도 박자 마지막 프레임을 찍는다.

## 3. 모양·움직임

- **아인**: 흑발 단발(잿빛 기), 붉은 눈, 오른팔 전투 의체, 왼쪽 견갑, 사신의 낫(자루 172 cm, 녹슨 칼날). 시트 그대로.
- **카인**: 188 cm 거구, 대검(190 cm), 어깨 갑주, 검은 코트. 대검을 키보다 길게 과장하지 않는다.
- **허수아비(변신 전)**: 사람 키의 낡은 짚단. 나무 뼈대가 기울었고 철사슬에 묶여 있다. 「지극히 평범했다」.
- **놈(변신 후)**: 턴어라운드 시트 — 통나무 머리통, 붉은 안광 2점, 가슴의 엠버 룬, 사슬·철띠·강선으로 감긴 몸. 3 m, 긴 팔.
- **움직임**:
  - 타격은 키포즈로 한다: 짧은 추적 → 멈춘 타격 프레임 1–2장 → 잔진동.
  - 그 밖의 컷은 고정숏에 먼지·형광등·호흡만 미세하게 움직인다.

## 4. 하지 말 것

- 청록·보라·게임 UI 이펙트. 초자연 발광은 **엠버 오렌지 하나뿐**이다.
- 판타지 목각 골렘으로 단순화하지 않는다(강선·강철 구조).
- 변신 전 허수아비를 처음부터 무섭게 그리지 않는다.
- 높은 천장.
- 원문에 없는 대사·설명 자막.
- 카인의 대검을 키보다 길게 그리지 않는다.
- 아인의 의체는 오른팔이다. 좌우를 바꾸지 않는다.

## 5. 만드는 법·비용

1. **키프레임 이미지 5장**(클립 A–E 첫 장): 이미지 모델에 캐릭터 시트 3장과 화풍 참조를 넣는다. 먼저 이것만 보여 드리고 고른다.
2. **영상 5개**:
   - 모델: Seedance 2.0(참조 인물 유지형, 4–15 초).
   - 입력: 키프레임을 시작 이미지로 넣고, 시트는 인물 참조로 넣는다. 한 클립이 8–10 초이고, 클립 안에서 여러 컷을 나눈다.
3. 이어 붙이기: ffmpeg 로 자막(원문 대사)과 SFX 를 넣는다.

- 예상 생성 횟수: 이미지 5 + 다시 뽑기 ~5, 영상 5 + 다시 뽑기 ~5.
- **2026-09-30 힉스필드 잔액 0 크레딧**(Plus 요금제) — 충전 전에는 생성할 수 없다.
