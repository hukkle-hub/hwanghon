# 204 — 1급·2급 감염체를 필드 몬스터로 (2026-10-08)

디렉터: «이 두 개체를 필드 몬스터로 지정» (1급 · 2급 컨셉 모델 시트 두 장).

## 1. 등급 사다리

| 등급 | 어디 | 상태 |
|---|---|---|
| 5급 6종 | 거점 웨이브 (남산 N01) | 넣음 — 문서 203 |
| 4급 · 3급 | 거점 웨이브에 등급별로 더해진다 (디렉터: «웨이브는 등급에 따라 추가로 넣을 거고 지금보다 충원될거야») | 아직 |
| **2급 · 1급** | **필드 전용** | **지정함 — 이 문서** |

웨이브와 필드의 등급이 겹치지 않게 시험으로 묶었다 (`tests/field-monsters.test.cjs`: 필드 등급에 5급이 들어가면 실패).

## 2. 외형 기준 — 승인 시트, 재해석 금지

`docs/design/ref/field-monsters-grade12/grade1-reference.png` · `grade2-reference.png` 를 그대로 3D 제작 기준으로 쓴다
(정면·옆·뒤·3/4 액션 + 얼굴·손·옷·부츠 상세 + 실루엣 + 색표). 5급 시트(문서 203)와 같은 결: 인간형·귀족적, 괴물화 금지, 붉은 감염 혈관은 보조.

| | 1급 | 2급 |
|---|---|---|
| 몸 | 여성형 · 은발 장발 · 가시 왕관 | 남성형 · 흑발 장발 · 가시 머리장식 |
| 옷 | 찢긴 검은 드레스(옆트임) · 금빛 사슬과 십자 | 검은 롱코트(붉은 안감) · 사슬·십자·술 |
| 손·발 | 붉은 손톱 · 감염 혈관 · 가시 굽 부츠(밑창에 붉은 십자) | 감염 혈관이 감긴 손 · 반지 · 전투화(밑창에 붉은 십자) |
| 색 | 회백 · 회색 셋 · 검정 · **핏빛 빨강** (두 장 같은 색표, 배경에 남산타워와 붉은 달) | |

정면·옆·뒤가 한 장에 다 있어서 Hi3D 다시점 생성에 바로 넣을 수 있다 (문서 04 파이프라인, 자격증명은 환경변수로만).

## 3. 자리 — 가안 (레벨 사다리 기준)

`server/field-monsters.cjs` (보스 표 `boss-table.cjs` 처럼 «한 곳에서»):

| | 등급 | 레벨 | 사냥터 |
|---|---|---|---|
| `t1_infected` | 1급 | 78~83 | 서귀포 중정로·중앙로·폐허 거리 (지금 가장 높은 필드) |
| `t2_infected` | 2급 | 75~78 | 제주 중앙로·폐허 거리 (그 아래) |

- 시험이 자리마다 «실제 사냥터인가(안전 지대 아님) · 레벨대가 겹치나» 를 본다.
- 이름은 «1급 감염체 / 2급 감염체» — 고유 이름이 정해지면 바꾼다 (`nameDraft`).
- 시트 배경의 남산타워·붉은 달을 «남산에 둔다» 로 읽을 수도 있다. 남산 필드는 지금 레벨 10~16 이라 그쪽이면 사다리를 다시 짜야 한다 — 디렉터 결정.

## 4. 아직 없는 것 — 런타임

필드엔 **보스만** 있고 일반 몬스터 런타임(서버 스폰·AI·타격·드롭, 클라 모델)이 아직 없다 — 문서 199 가 GPT 에 맡긴 몫이다.
이 표가 그 연결점(`field.cjs` 의 `mobs:[[id,kind,x,z,hp%,anim]]`, `fieldHit {mob}`, `bossStrike` 식 재사용)에 물리는 «무엇을 · 어디에» 다.

디렉터 결정이 필요한 것:
1. 자리 — 레벨 사다리(서귀포·제주)로 둘지, 남산(시트 배경)으로 둘지
2. 성격 — 사냥터에 늘 도는 «정예 일반 몬스터» 인지, 드물게 나오는 «떠도는 강자»(보스 주기 창처럼) 인지
3. 런타임을 누가 — 문서 199 대로 GPT 인지, Claude 가 서버 스폰·AI 부터 넣을지
