# 209 · 필드 몬스터 — 혼자 연습에서 먼저 (2026-10-09)

GPT v10 생태 모듈(`server/field-ecology.cjs`, 문서 207 §6)이 왔고, 서버 연결(`field.cjs`)·몸(GLB)은 아직이다.
그 사이 **혼자 연습(2D `mmo.html` · 3D `world3d.html`)** 에서 같은 모듈을 브라우저로 돌려 몬스터를 처음 화면에 띄웠다.

## 1. 무엇이 도나

| | 누가 | 메모 |
|---|---|---|
| 자리·무리·순찰·드문 종·부활(30초)·세대 | GPT 생태 모듈 그대로 (`loadCjs`) | 지도 `areas[].pool` · `areas[].eco` (문서 208) — 대전 8무리 25~27마리 |
| 그리기 | `js/mmo/field-mobs.js` (2D·3D 같이) | snapshot 칸 `{id, catalogId, x, z, alive, anim, generation}` 을 따라 그린다. 무리마다 이름표 하나(«잔향자 외 ×4») |
| 치기 | 2D `hitMob` · 3D `hitMob` | 보스가 닿지 않을 때 2.8 m 안 가장 가까운 몬스터. 연습 체력 5급 1.2만 · 4급 4.5만 · 3급 12만(근거 없음) → 0 이면 `defeat()` 한 번 |
| 몬스터 공격 | **아직 없음** | 서버 몬스터 AI(GPT) 가 오면 — `bossStrike` 식 · hurt `h[6]` (완벽 회피가 먹는다) |
| 몸 | **임시** | 사람형 가벼운 몸(류)을 등급색으로 물들임(5급 잿빛 초록 · 4급 보라 · 3급 검붉음), 이름표에 «임시 몸». 키는 등급과 상관없이 1.85 m(캐논: 거대화 금지) |

- 3D 는 걷기 충돌을 장면 빌더의 막이(`env.blockers`)로 하는데, 생태에는 **서버와 같은 `map.json` 충돌**을 준다 — 장면 막이로 주면 «둥지가 막혔다» 며 생태가 서지 않았다(대전 `left`).
- 온라인(서버 방)에서는 혼자 연습 생태를 돌리지 않는다 — 서버가 `mobs` 를 보내면 같은 `field-mobs.js` 로 그린다(지시서 `docs/gpt/2026-10-09-monster-v10-followup.md` §1 에 칸 순서를 맞춰 적었다).
