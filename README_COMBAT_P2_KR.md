# 황혼 v12 — 전투 질감 P2: 접점 위계

P0/P1 뒤 적용.

## 목적
같은 hit 효과의 크기만 바꾸는 구조에서 벗어나 평타/치명/3타/스매시/카운터가 서로 다른 무게로 읽히게 한다.

## VFX
- `light`: 0.30 / 0.085 s / 5 particles
- `crit`: 0.43 / 0.105 s / 8
- `finish`(3타): 0.53 / 0.120 s / 10
- `smash`: 0.68 / 0.145 s / 14
- `counter`: 0.82~1.00 / 0.160 s / 16~20
- 일반 평타에는 재질 2차효과를 추가하지 않는다.
- finish/smash에서만 straw는 짧은 먼지, metal은 얇은 백색 스파크를 보탠다.

## SFX
같은 organic sample pack을 유지하지만 두 축으로 변형:
- tier: 무거울수록 조금 낮은 pitch, 조금 높은 gain.
- material: metal은 고역 보존, straw는 중저역, core는 중역.
- smash/counter만 배경음 duck을 조금 더 깊게.

## 금지
피해량·판정·hitAt·히트스톱·무적·스태미나를 바꾸지 않는다.

## 검수
HUD를 가린 20초 영상에서도 평타와 3타, 스매시, 카운터를 소리와 접점만으로 구분할 수 있어야 한다.
