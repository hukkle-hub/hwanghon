엔진 자동화는 Combat 8개, Content 2개, Progression 14개다.
기존 10개에 플레이어 사망 3개, 의뢰 보상·저장 7개, 출격·GameMode 결과 4개를 추가했다.

새 검사는 128가지 클리어 조합 × 6개 의뢰의 상태 우선순위, 일회 보수와 범위형 보상,
실패 저장 후보 재사용, 재실행 중복 방지, v1 마이그레이션, 손상 저장 보존,
잘못된 출격 토큰·arena·dungeon·맵 거부, 미확인 맵 로드 중단, 패배 후 늦은 보스 처치,
저장 알림 재진입, 플레이어 사망 후 예약 공격 차단을 확인한다.
프로필 통합 검사는 메모리 저장 어댑터에서 실제 UE 직렬화/역직렬화를 사용한다.
기존 `SaveRoundTrip` 검사는 별도 임시 디스크 슬롯을 사용한다. 사용자 슬롯을 시험용으로 덮어쓰지 않았다.

고의 오류는 사망 시 예약 행동 취소 누락, 출격 토큰 비교 누락, 랜덤 보상 최댓값 제외였다.
각각 PlayerDeathLifecycle, EncounterLifecycle, QuestInclusiveRandomRewards가 실패했고
엔진도 255 종료 코드를 반환했다. 원본 파일을 바이트 단위로 복원·확인한 뒤 다시 빌드했다.

첫 통합 실행에서는 손상 검사 어댑터가 재사용한 직렬화 버퍼의 오래된 꼬리를 잘라
유효한 파일을 손상 파일로 취급했다. 버퍼 초기화와 실제 본문 절단으로 테스트를 고쳤다.
GameMode 테스트의 임시 월드에는 WorldContext도 등록하여 DestroyActor 경고를 없앴다.
마지막 보고서는 두 수정 이후의 새 실행 결과다.

5.8 빌드 중 설치된 MSVC가 권장 버전보다 새롭다는 안내와 엔진 헤더의 deprecated 경고는 있었다.
이는 위의 **엔진 테스트 경고 0**과 구분한다. 목표 엔진을 5.8로 바꾸거나 해당 경고를 숨기지 않았다.
에디터가 자동 생성한 5.8 전용 설정은 최종 변경에서 제외했다.

현재 활성 Routes는 없고, 실제 의뢰 맵과 화면은 후속 작업이다.
현재 GetGold/GetExperience/GetItemCount는 사무소 보수의 누적 지급 기록이며
상점·제작에서 소비할 수 있는 전체 경제 시스템으로 보고하지 않는다.
이 검증은 게임 전체 완성, UE 5.5 호환 확정, Android 실플레이 검증을 뜻하지 않는다.
