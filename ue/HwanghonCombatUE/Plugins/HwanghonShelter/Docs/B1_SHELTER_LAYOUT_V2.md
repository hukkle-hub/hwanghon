# B-1 Shelter Layout v2

```text
                     [마태오 직무실]
                           │
                    [01 인력사무소]
                           │
     [02 등급측정소] ── [중앙 코어] ── [04 훈련소]
            │              │                │
      [03 장인 공방]       │          [05 의뢰소]
                           │
             [06 치료실] ──┼── [07 배급소]
                           │
                     [외부 통로]
                           │
                  [가로 슬랫 방폭 셔터]

오른쪽 별도 분기 → [벙커끼리 연결 통로 / 후속 확장]
```

- 넓은 광장 금지.
- 중앙 코어에서 시야가 모두 뚫리지 않는다.
- 각 실은 짧은 통로를 지나야 보인다.
- '던전의 안전지대'처럼 탐색하게 만든다.
