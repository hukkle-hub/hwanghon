# 황혼 v6 — 쉘터는 시작 마을, 던전 귀환은 인력사무소

## 공간 정의

강남 B-1 쉘터는 메뉴용 로비가 아니다.

**게임의 시작 마을 / 생활 허브 / 파티 준비 거점**이다.

```text
게임 시작
→ 캐릭터 선택
→ 강남 B-1 쉘터
→ 의뢰 / 장비 / 치료 / 배급 / 훈련
→ 인력사무소에서 파티
→ 출격 셔터
→ 던전
→ 던전 종료
→ 인력사무소 귀환
→ 마태오 결과 보고 / 정산
→ 수리 / 치료 / 다음 의뢰
→ 다시 출격
```

## Spawn rule

최초 접속:
```text
ticket.spawnPoint = TownStart
PlayerStartTag = HH_TownStart
```

던전 귀환:
```text
ticket.spawnPoint = ManpowerOfficeReturn
PlayerStartTag = HH_ManpowerOffice_Return
```

귀환 지점은 마태오가 있는 인력사무소 내부/입구 접근축이다.

## 쉘터 인스턴스 연속성

던전 출정 시 `originShelterInstanceId`를 ticket에 보존한다.

귀환 시:
1. 원래 쉘터가 살아 있고 파티 전체 슬롯이 있으면 원래 인스턴스로 복귀
2. 그렇지 않으면 다른 쉘터로 fallback
3. 어느 인스턴스든 도착 위치는 인력사무소

즉 서버 확장 때문에 실제 프로세스는 바뀔 수 있어도 플레이 경험의 귀환점은 고정된다.

## 귀환 후 루프

인력사무소:
- 결과 보고 / 파티 유지·해체 / 다음 출정

장인:
- 파손 / 수리 / 제작 / 강화

치료실:
- 부상 / 회복약 / 억제제

배급소:
- 다음 출격 버프

등급측정소:
- 스킬 / 각인 / 성장 확인

훈련소:
- 새 스킬 / 카운터 연습

의뢰소:
- 다음 지역 / 보스 / 구조 임무 확인
